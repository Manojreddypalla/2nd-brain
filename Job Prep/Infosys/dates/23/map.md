# 📝 Revision Notes

After each problem, write only:

- **Pattern**
    
- **Time Complexity**
    
- **One key trick**
    
- **Mistake (if any)**
    

Example:

```text
Problem: Move Zeroes

Pattern:
Two Pointers

Time:
O(n)

Trick:
Maintain position of the next non-zero element.

Mistake:
Swapped unnecessarily instead of overwriting.
```

### For Infosys specifically

This is a better use of your revision day than trying to cover all six topics. Companies like Infosys frequently test:

- Arrays
    
- Strings
    
- Basic Hashing
    
- Simple searching/sorting
    
- Basic logic and implementation
    

Mastering Arrays and Strings first gives you the biggest return. On the next revision day, you can focus on **Hashing, Prefix Sum, Two Pointers, and Sliding Window** together, since those patterns naturally build on Arrays and Strings.
