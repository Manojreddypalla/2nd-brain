## Definition

A **Palindrome** is a string that reads the **same forward and backward**.

> **Think:** The first character should match the last, the second should match the second-last, and so on.

---

# Examples

Palindrome

```text
madam

racecar

level

noon
```

Not Palindrome

```text
hello

coding

apple
```

# Approaches

## 1. Two Pointers ⭐⭐⭐⭐⭐ (Most Preferred)

Maintain two pointers.

```text
left → Start

right → End
```

Compare both characters.

If equal

```text
left++

right--
```

If not equal

```text
Not Palindrome
```

---

## Algorithm

```text
madam

m a d a m

↑       ↑

↓

Equal

↓

 a d a

 ↑   ↑

↓

Equal

↓

 d

Done
```

---

## Code

```cpp
#include <iostream>
using namespace std;

bool isPalindrome(string s)
{
    int left = 0;
    int right = s.size() - 1;

    while(left < right)
    {
        if(s[left] != s[right])
            return false;

        left++;
        right--;
    }

    return true;
}
```

# 2. Reverse String Method

Reverse the string and compare.

```cpp
#include <algorithm>

bool isPalindrome(string s)
{
    string temp = s;

    reverse(temp.begin(), temp.end());

    return s == temp;
}
```

---

# 3. Recursive Approach

```cpp
bool palindrome(string &s, int left, int right)
{
    if(left >= right)
        return true;

    if(s[left] != s[right])
        return false;

    return palindrome(s, left + 1, right - 1);
}
```

Call

```cpp
palindrome(s, 0, s.size() - 1);
```

# Case-Insensitive Palindrome

Sometimes interviews ignore uppercase/lowercase.

Example

```text
Madam
```

Convert to lowercase first.

```cpp
transform(s.begin(), s.end(), s.begin(), ::tolower);
```

Then apply the two-pointer method.

# Ignoring Spaces & Special Characters

Example

```text
"A man, a plan, a canal: Panama"
```

Expected Output

```text
Palindrome
```

Code

```cpp
#include <cctype>

bool isPalindrome(string s)
{
    int left = 0;
    int right = s.size() - 1;

    while(left < right)
    {
        while(left < right && !isalnum(s[left]))
            left++;

        while(left < right && !isalnum(s[right]))
            right--;

        if(tolower(s[left]) != tolower(s[right]))
            return false;

        left++;
        right--;
    }

    return true;
}
```

This is the solution commonly asked in **LeetCode 125**.

# Common Mistakes

## Using `<=`

Wrong

```cpp
while(left <= right)
```

Better

```cpp
while(left < right)
```

The middle character doesn't need comparison.

---

## Forgetting Case Sensitivity

```text
Madam
```

Without converting case

```text
False
```

Use

```cpp
tolower()
```

---

## Comparing the Wrong Indices

Wrong

```cpp
s[left] == s[left]
```

Correct

```cpp
s[left] == s[right]
```

# Common Interview Questions

### Q1. Best approach?

**Two Pointers**

---

### Q2. Time Complexity?

```text
O(N)
```

---

### Q3. Space Complexity?

Two Pointers

```text
O(1)
```

Reverse String

```text
O(N)
```

---

### Q4. Can Palindrome be checked recursively?

Yes.

Compare the first and last characters, then recursively check the remaining substring.

---

### Q5. What if spaces and punctuation should be ignored?

Skip non-alphanumeric characters using

```cpp
isalnum()
```

and compare using

```cpp
tolower()
```

---

### Q6. What if the string length is odd?

The middle character doesn't affect the result.

Example

```text
madam

Middle = d
```

# Interview Summary

- A **Palindrome** reads the same forwards and backwards.
    
- The **Two Pointer** approach is the most efficient and interview-preferred solution.
    
- Compare the first and last characters, moving inward until the pointers meet.
    
- For advanced questions, normalize the string by ignoring **case**, **spaces**, and **special characters**.
    
- This pattern is the basis for many problems like **Valid Palindrome**, **Longest Palindromic Substring**, and **Palindrome Partitioning**.
