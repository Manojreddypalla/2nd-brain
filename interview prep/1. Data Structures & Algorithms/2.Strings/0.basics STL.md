# C++ `std::string` STL Cheat Sheet

```cpp
#include <string>
using namespace std;
```

---

# 1. Creating Strings

```cpp
string s;

string s = "Hello";

string s("Hello");

string s(5, 'A');     // AAAAA

string s2 = s;
```

---

# 2. Input / Output

```cpp
cin >> s;                 // One word

getline(cin, s);          // Entire line

cout << s;
```

---

# 3. Size & Capacity

|Function|Description|Complexity|
|---|---|---|
|`s.size()`|Length|O(1)|
|`s.length()`|Same as size()|O(1)|
|`s.empty()`|Is empty?|O(1)|
|`s.capacity()`|Allocated memory|O(1)|
|`s.resize(n)`|Resize string|O(n)|
|`s.max_size()`|Maximum possible size|O(1)|
|`s.clear()`|Remove all characters|O(n)|

Example

```cpp
s.size();

s.empty();

s.clear();
```

---

# 5. Traversing

### Index

```cpp
for(int i=0;i<s.size();i++)
    cout<<s[i];
```

---

### Range Loop

```cpp
for(char c:s)
    cout<<c;
```

---

### Iterator

```cpp
for(auto it=s.begin();it!=s.end();it++)
    cout<<*it;
```

---

### Reverse Iterator

```cpp
for(auto it=s.rbegin();it!=s.rend();it++)
    cout<<*it;
```
