## Definition

**Reverse String** means rearranging the characters of a string in the opposite order.

Example:

```text
Input

"hello"

Output

"olleh"
```

---

# Why Reverse a String?

Used in:

- Palindrome Checking
    
- String Manipulation
    
- Data Processing
    
- Cryptography Basics
    
- Interview Questions
    

---

# Approaches

### 1. Using Two Pointers ⭐⭐⭐⭐⭐ (Most Preferred)

Start one pointer from the beginning and one from the end.

Swap both characters.

Move inward until they meet.

```text
h e l l o
^       ^

↓

Swap

o e l l h

 ^     ^

↓

Swap

o l l e h
```

---

### Code

```cpp
#include <iostream>
using namespace std;

void reverseString(string &s)
{
    int left = 0;
    int right = s.size() - 1;

    while(left < right)
    {
        swap(s[left], s[right]);
        left++;
        right--;
    }
}
```

# 2. Using STL ⭐⭐⭐⭐⭐

The easiest interview solution.

```cpp
#include <algorithm>

reverse(s.begin(), s.end());
```

Example

```cpp
string s = "hello";

reverse(s.begin(), s.end());

cout << s;
```

Output

```text
olleh
```

# 3. Using Extra String

```cpp
string ans="";

for(int i=s.size()-1;i>=0;i--)
    ans+=s[i];
```

Time

```text
O(N)
```

Space

```text
O(N)
```

---

# 4. Using Stack

```cpp
stack<char> st;

for(char c:s)
    st.push(c);

string ans="";

while(!st.empty())
{
    ans+=st.top();
    st.pop();
}
```

# Common Mistakes

## Forgetting Reference

Wrong

```cpp
void reverseString(string s)
```

Changes happen on a copy.

Correct

```cpp
void reverseString(string &s)
```

---

## Wrong Loop

Wrong

```cpp
while(left <= right)
```

Better

```cpp
while(left < right)
```

---

## Using `+=` in Large Loops

Creating a new reversed string uses extra memory.

If modification is allowed, prefer **two pointers** or **`std::reverse()`**.

# Interview Summary

- Reverse String is a **fundamental string manipulation problem**.
    
- The **Two Pointer** approach is the classic interview solution and works in-place.
    
- The STL solution `reverse(s.begin(), s.end())` is concise and equally efficient.
    
- Be careful to pass the string by **reference** if you want to modify the original.
    
- Reverse String is commonly used as a building block for **Palindrome**, **String Rotation**, and other string problems.
