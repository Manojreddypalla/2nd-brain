## Definition

**Pattern Matching** is the process of finding whether a **pattern (substring)** exists inside a **text**, and if it does, finding its starting position(s).

> **Think:** Slide the pattern over the text one character at a time and compare.

---

# Problem Statement

Given

```text
Text    = "AABAACAADAABAABA"

Pattern = "AABA"
```

Find all occurrences of the pattern.

Output

```text
0

9

12
```

---

# Why Pattern Matching?

Used in:

- Text Editors (Find)
    
- Search Engines
    
- DNA Sequence Matching
    
- Malware Detection

# Approach 1: Naive Pattern Matching ⭐⭐⭐⭐⭐

## Idea

Compare the pattern with every possible starting position in the text.

```text
Text

AABAACAADAABAABA

Pattern

AABA

↓

Start at index 0

↓

Compare

↓

Move one step

↓

Compare again
```

---

# Algorithm

```text
For every index i

↓

Compare pattern with text

↓

If every character matches

↓

Pattern Found
```

---

# Code

```cpp
#include <iostream>
using namespace std;

void patternSearch(string text, string pattern)
{
    int n = text.size();
    int m = pattern.size();

    for(int i = 0; i <= n - m; i++)
    {
        int j;

        for(j = 0; j < m; j++)
        {
            if(text[i + j] != pattern[j])
                break;
        }

        if(j == m)
            cout << "Found at Index " << i << endl;
    }
}
```

# Approach 2: Using `find()` STL ⭐⭐⭐⭐☆

If you only need the **first occurrence**.

```cpp
size_t pos = text.find(pattern);

if(pos != string::npos)
    cout << pos;
```

---

## Finding All Occurrences

```cpp
size_t pos = text.find(pattern);

while(pos != string::npos)
{
    cout << pos << endl;

    pos = text.find(pattern, pos + 1);
}
```

# Common Mistakes

## Wrong Loop Condition

Wrong

```cpp
for(int i=0;i<n;i++)
```

Correct

```cpp
for(int i=0;i<=n-m;i++)
```

Otherwise

```text
text[i+j]
```

may go out of bounds.

---

## Forgetting `break`

Wrong

```cpp
if(text[i+j]!=pattern[j])
{
}
```

Always stop comparing after the first mismatch.

---

## Ignoring Overlapping Matches

Wrong

```cpp
i += m;
```

This skips valid matches.

Example

```text
AAAAA

AAA
```

# Common Interview Questions

### Q1. What is Pattern Matching?

Finding whether a substring exists inside another string.

---

### Q2. Time Complexity of Naive Algorithm?

Worst Case

```text
O(N × M)
```

where

- **N** = text length
    
- **M** = pattern length
    

---

### Q3. Space Complexity?

```text
O(1)
```

---

### Q4. What does `find()` return?

```cpp
text.find(pattern)
```

Returns

```text
Starting Index

or

string::npos
```

---

### Q5. Can `find()` find all occurrences?

Yes.

Use

```cpp
find(pattern,pos+1)
```

inside a loop.

---

### Q6. What are the limitations of the Naive algorithm?

It repeatedly compares the same characters, making it inefficient for large texts or repetitive patterns.

Algorithms like **KMP** and **Rabin-Karp** improve this.

---

# Time & Space Complexity

|Approach|Time|Space|
|---|---|---|
|Naive|`O(N × M)`|`O(1)`|
|`find()` (implementation-dependent)|Typically efficient|`O(1)`|

---

# Interview Summary

- **Pattern Matching** searches for a pattern inside a larger text.
    
- The **Naive algorithm** checks every possible starting position.
    
- It correctly handles **overlapping matches**.
    
- The STL function **`find()`** is the simplest way to find a pattern in C++.
    
- The main drawback of the naive approach is its **`O(N × M)`** worst-case complexity.
    
- More efficient algorithms like **KMP (`O(N + M)`)** and **Rabin-Karp** avoid unnecessary comparisons.
