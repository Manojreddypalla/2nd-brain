## Definition

Two strings are **Anagrams** if they contain **exactly the same characters with the same frequency**, but possibly in a different order.

> **Think:** The order doesn't matter, only the **character counts**.

---

# Examples

Anagrams

```text
listen

silent
```

```text
triangle

integral
```

```text
evil

vile
```

Not Anagrams

```text
hello

world
```

```text
rat

car
```

# Approach 1: Sorting ⭐⭐⭐⭐☆

## Idea

If two strings are anagrams, then after sorting both strings, they become identical.

Example

```text
listen

↓

eilnst

silent

↓

eilnst
```

Both are equal.

---

## Code

```cpp
#include <algorithm>
using namespace std;

bool isAnagram(string s1, string s2)
{
    if(s1.size() != s2.size())
        return false;

    sort(s1.begin(), s1.end());
    sort(s2.begin(), s2.end());

    return s1 == s2;
}
```

# Approach 2: Frequency Array ⭐⭐⭐⭐⭐ (Most Preferred)

## Idea

Count the frequency of each character.

If both strings have identical frequencies, they are anagrams.

---

## Algorithm

Create an array of size **26**.

Increase count for first string.

Decrease count for second string.

If every frequency becomes **0**, they are anagrams.

---

## Code (Lowercase English Letters)

```cpp
#include <iostream>
using namespace std;

bool isAnagram(string s1, string s2)
{
    if(s1.size() != s2.size())
        return false;

    int freq[26] = {0};

    for(char c : s1)
        freq[c - 'a']++;

    for(char c : s2)
        freq[c - 'a']--;

    for(int i = 0; i < 26; i++)
    {
        if(freq[i] != 0)
            return false;
    }

    return true;
}
```

# Approach 3: HashMap (General Characters)

Useful when strings contain:

- Uppercase letters
    
- Digits
    
- Unicode
    
- Special characters
    

```cpp
#include <unordered_map>
using namespace std;

bool isAnagram(string s1, string s2)
{
    if(s1.size() != s2.size())
        return false;

    unordered_map<char,int> mp;

    for(char c : s1)
        mp[c]++;

    for(char c : s2)
    {
        mp[c]--;

        if(mp[c] < 0)
            return false;
    }

    return true;
}
```

# Common Mistakes

## Forgetting Length Check

Wrong

```cpp
listen

listens
```

Always check

```cpp
if(s1.size()!=s2.size())
    return false;
```

---

## Assuming Sorting is Optimal

Sorting

```text
O(N log N)
```

Frequency Array

```text
O(N)
```

For lowercase letters, the frequency array is the better solution.

---

## Wrong Frequency Index

Wrong

```cpp
freq[c]++;
```

Correct

```cpp
freq[c-'a']++;
```

---

## Ignoring Uppercase

Example

```text
Listen

Silent
```

Convert both to lowercase first if the comparison should be case-insensitive.

```cpp
transform(s.begin(), s.end(), s.begin(), ::tolower);
```

# Common Interview Questions

### Q1. What is an Anagram?

Two strings containing the same characters with the same frequencies, regardless of order.

---

### Q2. Which is the optimal solution?

For lowercase English letters:

**Frequency Array**

---

### Q3. What is the time complexity?

Sorting

```text
O(N log N)
```

Frequency Array

```text
O(N)
```

---

### Q4. What is the space complexity?

Sorting

```text
O(1)`*` or `O(N)` depending on implementation
```

Frequency Array

```text
O(1)
```

(Uses a fixed-size array of 26 elements.)

---

### Q5. When should you use a HashMap?

When the character set is not limited to lowercase English letters.

---

### Q6. Why use `c - 'a'`?

It maps:

```text
'a' → 0

'b' → 1

...

'z' → 25
```

making indexing into the frequency array simple and efficient.

---

# Time & Space Complexity

|Approach|Time|Space|
|---|---|---|
|Sorting|`O(N log N)`|Depends on sort implementation|
|Frequency Array|`O(N)`|`O(1)`|
|HashMap|`O(N)` average|`O(K)` (`K` = unique characters)|

---

# Interview Summary

- Two strings are **Anagrams** if they have the **same characters with the same frequencies**.
    
- Always **check lengths first**.
    
- For lowercase English letters, the **frequency array** is the optimal solution with **`O(N)`** time and **`O(1)`** space.
    
- Sorting is simpler to write but slower (`O(N log N)`).
    
- Use a **HashMap** when dealing with larger or unknown character sets (uppercase, Unicode, symbols, etc.).
