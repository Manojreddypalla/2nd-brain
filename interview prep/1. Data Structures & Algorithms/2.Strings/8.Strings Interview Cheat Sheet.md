# 9. Reverse String ⭐⭐⭐⭐⭐

Best

```cpp
reverse(s.begin(),s.end());
```

OR

Two Pointer

```cpp
int l=0,r=s.size()-1;

while(l<r)
{
    swap(s[l],s[r]);
    l++;
    r--;
}
```

Complexity

```
Time O(N)

Space O(1)
```

---

# 10. Palindrome ⭐⭐⭐⭐⭐

Best

Two Pointer

```cpp
while(left<right)
{
    if(s[left]!=s[right])
        return false;

    left++;
    right--;
}

return true;
```

Complexity

```
O(N)
```

---

# 11. Anagram ⭐⭐⭐⭐⭐

Optimal

Frequency Array

```cpp
int freq[26]={0};

for(char c:s1)
    freq[c-'a']++;

for(char c:s2)
    freq[c-'a']--;

for(int x:freq)
{
    if(x!=0)
        return false;
}

return true;
```

Complexity

```
Time O(N)

Space O(1)
```

# 18. Sliding Window on Strings ⭐⭐⭐⭐⭐

Most Asked Pattern

Problems

- Longest Substring Without Repeating Characters
    
- Minimum Window Substring
    
- Permutation in String
    
- Find All Anagrams
    
- Longest Repeating Character Replacement
    

Template

```cpp
int left=0;

for(int right=0;right<s.size();right++)
{
    // Expand

    while(condition)
    {
        // Shrink

        left++;
    }
}
```

Complexity

```
O(N)
```

# 🎯 Final Interview Takeaways

If you're preparing for coding interviews, these are the patterns you should recognize instantly:

- ✅ **Two Pointers** → Reverse, Palindrome, Reverse Vowels
    
- ✅ **Frequency Array / HashMap** → Anagram, Character Count, Duplicate Detection
    
- ✅ **Sliding Window** → Longest/Shortest Substring problems
    
- ✅ **Pattern Matching** → Naive → KMP → Rabin-Karp
    
- ✅ **Trie** → Prefix Search, Autocomplete, Dictionary
    
- ✅ **STL Mastery** → `find`, `substr`, `reverse`, `sort`, `transform`, `count`, `getline`, `stringstream`
    

Mastering these patterns will cover the vast majority of string questions asked in DSA interviews, coding assessments, and platforms like LeetCode, HackerRank, and Codeforces.
