For interviews, you should know **`std::vector` (dynamic array)** much more thoroughly than C-style arrays. Almost every company expects `vector` unless the question specifically asks for arrays.

# Arrays (vector) STL Cheat Sheet

```cpp
#include <vector>
#include <algorithm>
#include <numeric>
using namespace std;
```

---

# 1. Creating Arrays

```cpp
vector<int> arr;

vector<int> arr(5);

vector<int> arr(5,10);

vector<int> arr={1,2,3,4,5};

vector<int> arr(other);

vector<int> arr(other.begin(),other.end());
```

---

# 2. Size & Capacity

|Function|Description|Complexity|
|---|---|---|
|`size()`|Number of elements|O(1)|
|`empty()`|Check empty|O(1)|
|`capacity()`|Allocated capacity|O(1)|
|`resize(n)`|Resize vector|O(n)|
|`reserve(n)`|Reserve capacity|O(n)|
|`clear()`|Remove all elements|O(n)|
|`shrink_to_fit()`|Reduce capacity|O(n)|

Example

```cpp
v.size();

v.empty();

v.reserve(100);

v.resize(10);
```

# 4. Traversal

### Index

```cpp
for(int i=0;i<v.size();i++)
    cout<<v[i];
```

---

### Range Loop

```cpp
for(int x:v)
    cout<<x;
```

---

### Iterator

```cpp
for(auto it=v.begin();it!=v.end();it++)
    cout<<*it;
```

---

### Reverse Iterator

```cpp
for(auto it=v.rbegin();it!=v.rend();it++)
    cout<<*it;
```
