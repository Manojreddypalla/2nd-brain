## Definition

**Array Traversal** is the process of **visiting every element of an array exactly once** to perform some operation such as printing, searching, counting, updating, or calculating.

> **Think:** Traversal means **moving through the array from the first element to the last element**.

---

# Why Traversal?

Traversal is the foundation of almost every array problem.

Used in:

- Printing elements
    
- Finding maximum/minimum
    
- Searching
    
- Calculating sum/average
    
- Updating values
    
- Counting frequencies
    
- Applying transformations
    

---

# Basic Traversal

```cpp
#include <iostream>
using namespace std;

int main()
{
    int arr[] = {10, 20, 30, 40, 50};
    int n = 5;

    for(int i = 0; i < n; i++)
    {
        cout << arr[i] << " ";
    }
}
```

Output

```text
10 20 30 40 50
```

---

# Internal Working

Array

```text
Index : 0   1   2   3   4
Value : 10  20  30  40  50
```

Traversal

```text
i = 0 → arr[0] → 10

i = 1 → arr[1] → 20

i = 2 → arr[2] → 30

i = 3 → arr[3] → 40

i = 4 → arr[4] → 50
```

The loop accesses each element once.

---

# Memory Visualization

```text
Address

1000 → 10

1004 → 20

1008 → 30

1012 → 40

1016 → 50
```

Since arrays are stored in **contiguous memory**, each next element is at the next memory location (for `int`, typically +4 bytes).

Access formula:

```text
Address = Base + (Index × Size of Data Type)
```

# Reverse Traversal

```cpp
for(int i = n - 1; i >= 0; i--)
{
    cout << arr[i] << " ";
}
```

Output

```text
50 40 30 20 10
```

# Common Operations Using Traversal

### Find Sum

```cpp
int sum = 0;

for(int i = 0; i < n; i++)
{
    sum += arr[i];
}
```

---

### Find Maximum

```cpp
int mx = arr[0];

for(int i = 1; i < n; i++)
{
    if(arr[i] > mx)
        mx = arr[i];
}
```

---

### Count Even Numbers

```cpp
int count = 0;

for(int i = 0; i < n; i++)
{
    if(arr[i] % 2 == 0)
        count++;
}
```

---

### Search an Element (Linear Search)

```cpp
int target = 30;

for(int i = 0; i < n; i++)
{
    if(arr[i] == target)
    {
        cout << "Found";
        break;
    }
}
```

# Common Mistakes

## Using Wrong Loop Condition

Wrong

```cpp
for(int i = 0; i <= n; i++)
```

This accesses `arr[n]`, which is **out of bounds**.

Correct

```cpp
for(int i = 0; i < n; i++)
```

---

## Forgetting to Update the Loop Variable

Wrong

```cpp
while(i < n)
{
    cout << arr[i];
}
```

Infinite loop because `i` never changes.

Correct

```cpp
while(i < n)
{
    cout << arr[i];
    i++;
}
```

---

## Accessing Invalid Index

```cpp
arr[-1];
arr[n];
```

Both are invalid and lead to **undefined behavior**.

# Common Interview Questions

### Q1. What is array traversal?

Visiting each element of an array exactly once to perform an operation.

---

### Q2. Why is array traversal `O(N)`?

Because every element is visited exactly once.

---

### Q3. Can traversal be done in reverse?

Yes.

```cpp
for(int i = n - 1; i >= 0; i--)
```

---

### Q4. Difference between traversal and searching?

- **Traversal:** Visit all elements.
    
- **Searching:** Find a specific element (may stop early).
    

---

### Q5. Why are arrays fast to traverse?

Because array elements are stored in **contiguous memory**, giving good cache locality and constant-time index access.

---

### Q6. Can we modify elements during traversal?

Yes.

Example:

```cpp
arr[i] *= 2;
```

# Time & Space Complexity

|Operation|Complexity|
|---|---|
|Traverse entire array|**O(N)**|
|Reverse traversal|**O(N)**|
|Extra Space|**O(1)**|

---

# Interview Summary

- **Traversal** means visiting each array element exactly once.
    
- Arrays support efficient traversal because they use **contiguous memory**.
    
- Forward and reverse traversal both take **O(N)** time.
    
- Traversal is the basis for operations like sum, max, search, update, and counting.
    
- Avoid out-of-bounds access by using `i < n`.
    
- Traversal uses **O(1)** auxiliary space.
