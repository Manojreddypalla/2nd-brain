# Arrays — Prefix Sum

## Definition

A **Prefix Sum** array stores the **sum of all elements from index `0` to index `i`**.

> **Think:** Instead of calculating the sum repeatedly, we precompute cumulative sums once and answer range sum queries in constant time.

---

# Why Prefix Sum?

Used in:

- Range Sum Queries
    
- Subarray Problems
    
- Frequency Counting
    
- Difference Arrays
    
- Dynamic Programming
    
- Competitive Programming
    
- Interview Problems
    

---

# Basic Idea

Original Array

```text
Index : 0  1  2  3  4

Value : 2  4  6  8  10
```

Prefix Sum Array

```text
Index : 0   1   2   3   4

Value : 2   6  12  20  30
```

Explanation

```text
prefix[0] = 2

prefix[1] = 2 + 4 = 6

prefix[2] = 2 + 4 + 6 = 12

prefix[3] = 20

prefix[4] = 30
```

---

# Building Prefix Sum

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main()
{
    vector<int> arr = {2, 4, 6, 8, 10};
    int n = arr.size();

    vector<int> prefix(n);

    prefix[0] = arr[0];

    for(int i = 1; i < n; i++)
    {
        prefix[i] = prefix[i - 1] + arr[i];
    }
}
```

# Range Sum Query

Find the sum from index **L** to **R**.

Formula

```text
If L == 0

Sum = prefix[R]
```

Otherwise

```text
Sum = prefix[R] - prefix[L - 1]
```

---

### Example

Array

```text
2 4 6 8 10
```

Find sum from index **1** to **3**

```text
4 + 6 + 8 = 18
```

Using Prefix

```text
prefix[3] = 20

prefix[0] = 2

20 - 2 = 18
```

---

# Code for Range Sum

```cpp
int rangeSum(vector<int>& prefix, int L, int R)
{
    if(L == 0)
        return prefix[R];

    return prefix[R] - prefix[L - 1];
}
```

---

# Without Prefix Sum

Suppose there are **Q** queries.

```cpp
for(int i = L; i <= R; i++)
{
    sum += arr[i];
}
```

Each query

```text
O(N)
```

Total

```text
O(N × Q)
```

---

# With Prefix Sum

Preprocessing

```text
O(N)
```

Each Query

```text
O(1)
```

Total

```text
O(N + Q)
```

Huge improvement when many queries exist.

# Common Mistakes

## Forgetting L = 0

Wrong

```cpp
prefix[R] - prefix[L - 1]
```

If `L = 0`, then `L - 1 = -1`, causing invalid access.

Correct

```cpp
if(L == 0)
    return prefix[R];
```

---

## Wrong Prefix Formula

Wrong

```cpp
prefix[i] = arr[i];
```

Correct

```cpp
prefix[i] = prefix[i - 1] + arr[i];
```

---

## Modifying Original Array Accidentally

If using in-place prefix sums, remember the original values are lost.

# Common Interview Questions

### Q1. What is Prefix Sum?

A preprocessing technique where each element stores the cumulative sum from the beginning of the array.

---

### Q2. Why use Prefix Sum?

To answer range sum queries in **O(1)** time after **O(N)** preprocessing.

---

### Q3. How do you find the sum from L to R?

```text
If L == 0

prefix[R]

Else

prefix[R] - prefix[L - 1]
```

---

### Q4. Difference between normal traversal and Prefix Sum?

|Traversal|Prefix Sum|
|---|---|
|Computes each query separately|Precomputes cumulative sums|
|Range query: `O(N)`|Range query: `O(1)`|

---

### Q5. Where is Prefix Sum used?

- Range Sum Queries
    
- Subarray Sum Problems
    
- HashMap + Prefix Sum
    
- Matrix Queries
    
- Competitive Programming
    

---

### Q6. Can Prefix Sum be built in-place?

Yes.

```cpp
arr[i] += arr[i - 1];
```

This reduces auxiliary space to `O(1)`.

# Interview Summary

- **Prefix Sum** stores cumulative sums for efficient range queries.
    
- Build the prefix array once in **`O(N)`** time.
    
- Answer any range sum query in **`O(1)`** using:
    
    - `prefix[R]` if `L == 0`
        
    - `prefix[R] - prefix[L - 1]` otherwise.
        
- Prefix Sum is the foundation for many interview problems involving **subarrays**, **hash maps**, and **2D matrices**.
    
- Always handle the `L == 0` edge case correctly.
