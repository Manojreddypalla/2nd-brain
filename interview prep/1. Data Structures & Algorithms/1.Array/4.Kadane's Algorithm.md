# Arrays — Kadane's Algorithm

## Definition

**Kadane's Algorithm** is an efficient algorithm used to find the **Maximum Sum Contiguous Subarray** in an array.

> **Think:** At every element, decide:
> 
> - **Continue** the current subarray, or
>     
> - **Start a new subarray** from the current element.
>     

---

# Why Kadane's Algorithm?

Used in:

- Maximum Subarray Sum
    
- Stock Market Analysis
    
- Dynamic Programming
    
- Signal Processing
    
- Interview Problems
    
- Optimization Problems
    

---

# Problem Statement

Given

```text
-2 1 -3 4 -1 2 1 -5 4
```

Find the **contiguous subarray** with the maximum sum.

Answer

```text
4 -1 2 1

Sum = 6
```

---

# Brute Force Approach

Generate every possible subarray.

```cpp
int ans = INT_MIN;

for(int i = 0; i < n; i++)
{
    int sum = 0;

    for(int j = i; j < n; j++)
    {
        sum += arr[j];
        ans = max(ans, sum);
    }
}
```

### Time Complexity

```text
O(N²)
```

### Space Complexity

```text
O(1)
```

---

# Kadane's Algorithm (Optimal)

### Idea

Maintain two variables:

- `currentSum` → Sum of current subarray
    
- `maxSum` → Maximum sum seen so far
    

If `currentSum` becomes worse than starting fresh, restart from the current element.

---

# Algorithm

```text
currentSum += arr[i]

↓

Update maxSum

↓

If currentSum < 0

Reset currentSum = 0
```

---

# Code

```cpp
#include <iostream>
#include <climits>
using namespace std;

int kadane(int arr[], int n)
{
    int currentSum = 0;
    int maxSum = INT_MIN;

    for(int i = 0; i < n; i++)
    {
        currentSum += arr[i];

        maxSum = max(maxSum, currentSum);

        if(currentSum < 0)
            currentSum = 0;
    }

    return maxSum;
}
```

# Why Reset When Sum Becomes Negative?

Suppose

```text
Current Sum = -5

Next Element = 10
```

Continuing

```text
-5 + 10 = 5
```

Starting fresh

```text
10
```

Clearly, carrying a negative sum only hurts the result.

---

# Handling All Negative Numbers

Example

```text
-8 -3 -6 -2 -5
```

Answer

```text
-2
```

The standard Kadane implementation above works because `maxSum` is initialized to `INT_MIN` **before** resetting `currentSum`.

An alternative interview-friendly version:

```cpp
int currentSum = arr[0];
int maxSum = arr[0];

for(int i = 1; i < n; i++)
{
    currentSum = max(arr[i], currentSum + arr[i]);
    maxSum = max(maxSum, currentSum);
}
```

This version naturally handles all-negative arrays.

# Common Mistakes

## Initializing `maxSum` to 0

Wrong

```cpp
int maxSum = 0;
```

Fails for

```text
-5 -2 -8
```

Correct

```cpp
int maxSum = INT_MIN;
```

or initialize both values with `arr[0]`.

---

## Resetting Before Updating `maxSum`

Wrong

```cpp
if(currentSum < 0)
    currentSum = 0;

maxSum = max(maxSum, currentSum);
```

Always update `maxSum` **before** resetting.

---

## Forgetting Contiguous Requirement

Kadane works only for **contiguous** subarrays.

# Common Interview Questions

### Q1. What is Kadane's Algorithm?

An algorithm to find the maximum sum contiguous subarray in linear time.

---

### Q2. Why reset `currentSum` to 0?

A negative running sum reduces the sum of any future subarray, so it's better to start fresh.

---

### Q3. What is the time complexity?

```text
O(N)
```

---

### Q4. What is the space complexity?

```text
O(1)
```

---

### Q5. Can Kadane handle all-negative arrays?

Yes, if implemented correctly by initializing with `INT_MIN` (or using the first element).

---

### Q6. Can Kadane return the actual subarray?

Yes. Track:

- Start index
    
- End index
    
- Temporary start index
    

along with the running sums.

# Interview Summary

- **Kadane's Algorithm** finds the **maximum sum contiguous subarray**.
    
- It scans the array once, maintaining:
    
    - `currentSum` → current subarray sum.
        
    - `maxSum` → best sum found so far.
        
- If the running sum becomes negative, start a new subarray.
    
- The optimal solution runs in **`O(N)` time** with **`O(1)` extra space**.
    
- Remember to handle **all-negative arrays**, a very common interview edge case.
