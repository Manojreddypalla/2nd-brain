## Definition

A **Regular Expression (Regex)** is a **pattern** used to search, validate, extract, or replace text.

> **Think:** Regex is like a **search template** instead of searching for exact text.

Example:

```text
Pattern:  [0-9]+

Matches:

123

45

9999
```

---

# Why Use Regex?

- Validate emails
    
- Validate phone numbers
    
- Password validation
    
- Extract numbers
    
- Search logs
    
- Replace text
    
- Data cleaning
    

---

# Creating a Pattern

```cpp
regex pattern("[0-9]+");
```

This pattern means:

```text
One or more digits
```

---

# regex_match()

Checks whether the **entire string** matches the pattern.

```cpp
string s = "12345";

regex pattern("[0-9]+");

cout << regex_match(s, pattern);
```

Output

```text
1
```

---

Example

```cpp
string s = "abc123";
```

Output

```text
0
```

Because the **whole string** is not only digits.

---

# regex_search()

Searches for the pattern **anywhere** in the string.

```cpp
string s = "abc123xyz";

regex pattern("[0-9]+");

cout << regex_search(s, pattern);
```

Output

```text
1
```

Because `"123"` exists inside the string.

---

# Difference

|regex_match()|regex_search()|
|---|---|
|Entire string|Partial search|
|Strict validation|Finding text|

---

# regex_replace()

Replace matched text.

```cpp
string s = "I have 10 apples";

regex pattern("[0-9]+");

cout << regex_replace(s, pattern, "20");
```

Output

```text
I have 20 apples
```

---

# Match Result (smatch)

Stores matched text.

```cpp
string s = "Age 25";

smatch match;

regex pattern("[0-9]+");

if(regex_search(s, match, pattern))
{
    cout << match.str();
}
```

Output

```text
25
```

# Password Example

At least one uppercase

At least one lowercase

At least one digit

Minimum 8 characters

```text
^(?=.*[A-Z])(?=.*[a-z])(?=.*[0-9]).{8,}$
```

> Note: This pattern uses lookaheads. Support depends on the C++ standard library implementation, so verify compatibility with your compiler.

# Extract All Numbers

```cpp
string s = "A12 B45 C89";

regex pattern("[0-9]+");

for(sregex_iterator it(s.begin(), s.end(), pattern);
    it != sregex_iterator();
    ++it)
{
    cout << it->str() << "\n";
}
```

Output

```text
12

45

89
```

# Common Mistakes

## Forgetting Escape Characters

Wrong

```cpp
"."
```

Matches **any** character.

Correct (literal dot)

```cpp
"\\."
```

Matches only `.`

---

## Using regex_match Instead of regex_search

Wrong

```cpp
regex_match("abc123", pattern)
```

Returns

```text
false
```

Use

```cpp
regex_search()
```

# Common Interview Questions

### Q1. What is Regex?

A pattern language used to search, validate, extract, and replace text.

---

### Q2. Difference between `regex_match()` and `regex_search()`?

|regex_match|regex_search|
|---|---|
|Entire string must match|Finds a match anywhere in the string|

---

### Q3. Difference between `*` and `+`?

- `*` → Zero or more occurrences.
    
- `+` → One or more occurrences.
    

---

### Q4. What does `.` mean?

Matches **any single character** (except newline in most regex engines by default).

---

### Q5. What is `^` and `$`?

- `^` → Start of the string.
    
- `$` → End of the string.
    

---

### Q6. How do you replace text using Regex?

Use

```cpp
regex_replace()
```

---

### Q7. How do you extract matched text?

Use

```cpp
smatch
```

or iterate over all matches using

```cpp
sregex_iterator
```

# Time & Space Complexity

Let:

- **N** = Length of input string
    
- **P** = Length of regex pattern
    

|Operation|Time|
|---|---|
|`regex_match()`|Typically `O(N)`*|
|`regex_search()`|Typically `O(N)`*|
|`regex_replace()`|Typically `O(N)`*|

> *For well-behaved patterns. Some complex regex features (especially nested backtracking) can take much longer in the worst case.

# Interview Summary

- **Regex** is used for **searching, validating, extracting, and replacing** text using patterns.
    
- Include `<regex>` and use the `regex` class.
    
- `regex_match()` validates the **entire string**, while `regex_search()` finds a **substring** match.
    
- `regex_replace()` replaces matched text, and `smatch` stores match results.
    
- Learn common metacharacters: `.`, `*`, `+`, `?`, `^`, `$`, `[]`, and `()`.
    
- Character classes (`[0-9]`, `[a-z]`, etc.) and quantifiers (`{n}`, `{m,n}`) are essential for interview questions.
    
- Remember to escape special characters like `.` as `"\\."` in C++ string literals.
    
- Regex is commonly used for validating emails, phone numbers, passwords, parsing logs, and text processing.
