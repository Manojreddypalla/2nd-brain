## Definition

**File Handling** is the process of **storing data permanently** in files and retrieving it later.

> **Think:** Variables store data temporarily (RAM). Files store data permanently (Disk).

---

# Why File Handling?

- Save program data
    
- Read configuration files
    
- Store logs
    
- Read datasets
    
- Process CSV/Text files
    
- Database backups
    

---

# File Stream Classes

C++ provides three main classes.

|Class|Purpose|
|---|---|
|`ifstream`|Read from a file|
|`ofstream`|Write to a file|
|`fstream`|Read and Write|

Header

```cpp
#include <fstream>
```

---

# File Flow

```text
Program
     │
     ▼
File Stream
     │
     ▼
Disk File
```

---

# Writing to a File

```cpp
#include <fstream>

int main()
{
    ofstream file("data.txt");

    file << "Hello World";

    file.close();
}
```

Creates

```text
data.txt

Hello World
```

---

# Reading from a File

```cpp
#include <fstream>

int main()
{
    ifstream file("data.txt");

    string s;

    file >> s;

    cout << s;
}
```

Output

```text
Hello
```

Notice:

`>>` stops at whitespace.

---

# Reading Entire Line

```cpp
string line;

getline(file, line);
```

Reads

```text
Hello World
```

instead of just

```text
Hello
```

---

# Reading Entire File

```cpp
string line;

while(getline(file, line))
{
    cout << line << "\n";
}
```

This is the most common interview pattern.

---

# File Modes

|Mode|Meaning|
|---|---|
|`ios::in`|Read|
|`ios::out`|Write|
|`ios::app`|Append|
|`ios::ate`|Start at end|
|`ios::trunc`|Clear existing content|
|`ios::binary`|Binary mode|

---

# Append Mode

Without append

```cpp
ofstream file("data.txt");
```

Old data is erased.

---

Append

```cpp
ofstream file("data.txt", ios::app);

file << "New Line\n";
```

File becomes

```text
Old Data

New Line
```

---

# Read and Write Together

```cpp
fstream file("data.txt",
             ios::in | ios::out);
```

Can both read and write.

# Checking if File Opened

Very common interview question.

```cpp
ifstream file("data.txt");

if(file.is_open())
{
    cout << "Opened";
}
else
{
    cout << "Failed";
}
```

Never assume the file opened successfully.

---

# End of File (EOF)

Read until file ends.

```cpp
string line;

while(getline(file, line))
{
    cout << line;
}
```

Better than

```cpp
while(!file.eof())
```

Avoid using `while(!file.eof())` because EOF is only set **after** a read attempt fails.

---

# Closing a File

```cpp
file.close();
```

Closes the file and flushes pending data.

Files also close automatically when the stream object goes out of scope (RAII).

---

# Binary Files

Text

```text
Hello
```

Stored as characters.

---

Binary

```cpp
ofstream file("data.bin",
              ios::binary);
```

Stores raw bytes.

Used for:

- Images
    
- Audio
    
- Videos
    
- Executables
    
- Serialized objects
    

---

# Writing Binary Data

```cpp
int x = 100;

ofstream file("a.bin", ios::binary);

file.write((char*)&x, sizeof(x));
```

---

# Reading Binary Data

```cpp
int x;

ifstream file("a.bin", ios::binary);

file.read((char*)&x, sizeof(x));
```

# File Pointer

Each file maintains a current position.

Reading

```text
A B C D E
    ^
Current Position
```

After reading one character

```text
A B C D E
      ^
```

# Moving File Pointer

```cpp
file.seekg(0);
```

Move read pointer.

---

```cpp
file.seekp(0);
```

Move write pointer.

---

Current position

```cpp
file.tellg();
```

```cpp
file.tellp();
```

Useful for random file access.

# Common Mistakes

## Forgetting to Open

```cpp
ifstream file;

file >> x;
```

Always open first.

---

## Forgetting to Check

```cpp
ifstream file("abc.txt");
```

May fail if file doesn't exist.

Always verify with `is_open()` or check the stream state.

---

## Using EOF Incorrectly

Wrong

```cpp
while(!file.eof())
```

Correct

```cpp
while(getline(file, line))
```

# Common Interview Questions

### Q1. Difference between `ifstream`, `ofstream`, and `fstream`?

|Class|Purpose|
|---|---|
|`ifstream`|Read|
|`ofstream`|Write|
|`fstream`|Read & Write|

---

### Q2. What is the difference between Text and Binary files?

|Text|Binary|
|---|---|
|Human-readable|Raw bytes|
|Slower|Faster for raw data|
|Easier to edit|Not human-readable|

---

### Q3. What is `ios::app`?

Opens a file in **append mode**, so new data is written at the end without overwriting existing content.

---

### Q4. Why is `while(getline(...))` preferred over `while(!eof())`?

Because `getline()` directly indicates whether the read succeeded, avoiding processing invalid or duplicate data at the end of the file.

---

### Q5. What does `close()` do?

- Flushes buffered output
    
- Releases the file handle
    
- Makes the file available to other processes
    

---

### Q6. What is `seekg()` and `seekp()`?

- `seekg()` moves the **read** pointer.
    
- `seekp()` moves the **write** pointer.
    

---

### Q7. Why check `is_open()`?

To ensure the file was opened successfully before attempting to read or write.

---

# Time & Space Complexity

Assuming file pointer movement is sequential.

|Operation|Time|Space|
|---|---|---|
|Read one character|`O(1)`|`O(1)`|
|Write one character|`O(1)`|`O(1)`|
|Read entire file (N bytes)|`O(N)`|`O(1)`*|
|Write entire file (N bytes)|`O(N)`|`O(1)`*|

> *Additional space depends on how much data your program stores in memory.

---

# Interview Summary

- File handling provides **persistent storage** beyond program execution.
    
- Use `ifstream` for reading, `ofstream` for writing, and `fstream` for both.
    
- Always verify that a file opened successfully before using it.
    
- `getline()` is the preferred way to read text files line by line.
    
- Use `ios::app` to append instead of overwrite.
    
- Text files store readable characters; binary files store raw bytes.
    
- `seekg()`, `seekp()`, `tellg()`, and `tellp()` allow random access within files.
    
- Prefer `while(getline(file, line))` over `while(!file.eof())`.
    
- File streams follow **RAII**—they automatically close when they go out of scope.
