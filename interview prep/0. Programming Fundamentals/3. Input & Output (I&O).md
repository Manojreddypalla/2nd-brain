## Definition

**Input** means taking data from the user or a file.

**Output** means displaying data to the screen or writing it to a file.

C++ uses **streams** for I/O.

- `cin` → Input Stream
    
- `cout` → Output Stream
    
- `cerr` → Error Stream
    
- `clog` → Logging Stream
    

---

# Basic Output

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello World";
}
```

Output

# Basic Input

```cpp
int age;

cin >> age;

cout << age;
```

Input

```
21
```

Output

```
21
```

# How `cin` Works Internally

Suppose the user types:

```
25
```

Flow:

```
Keyboard
      │
      ▼
Input Buffer
      │
      ▼
cin
      │
      ▼
Variable
```

The value first enters the **input buffer**, then `cin` extracts it into the variable.

# Chaining Operators

Input

```cpp

```

Output


# Input for Strings

## Method 1 : `cin`

```cpp
string name;

cin >> name;
```

Input

```
John
```

Works only until the first space.

---

Input

```
John Doe
```

Stored

```
John
```

---

## Method 2 : `getline()`

```cpp
string name;

getline(cin, name);
```

Input

```
John Doe
```

Stored

```
John Doe
```

Reads the entire line, including spaces.

# `cin` vs `getline()`

|cin|getline()|
|---|---|
|Stops at space|Reads full line|
|Faster|Reads spaces too|
|Good for numbers/single words|Good for sentences|

---

# Common Interview Pitfall

```cpp
int age;

cin >> age;

string name;

getline(cin, name);
```

Problem:

`getline()` immediately reads the leftover newline (`\n`) from `cin`.

---

Solution

```cpp
cin.ignore();

getline(cin, name);
```

or

```cpp
getline(cin >> ws, name);
```

# `endl` vs `\n`

```cpp
cout << "Hello" << endl;
```

`endl`

- Prints a new line
    
- Flushes the output buffer
    

---

```cpp
cout << "Hello\n";
```

`\n`

- Only prints a new line
    
- Faster
    

For competitive programming and interviews, prefer **`\n`** unless flushing is required.

# Fast Input / Output

Very common in coding interviews and competitive programming.

```cpp
ios::sync_with_stdio(false);
cin.tie(nullptr);
```

Place at the beginning of `main()`.

```cpp
int main() {

    ios::sync_with_stdio(false);
    cin.tie(nullptr);

}
```

Benefits:

- Faster `cin`
    
- Faster `cout`
    
- Avoids unnecessary synchronization with C I/O

# File I/O (Basics)

Writing

```cpp
ofstream file("data.txt");

file << "Hello";
```

Reading

```cpp
ifstream file("data.txt");

string s;

file >> s;
```

Always check if the file opened successfully before reading or writing.

# Common Interview Questions

### Q1. Difference between `cin` and `getline()`?

- `cin` reads until whitespace.
    
- `getline()` reads the entire line.
    

---

### Q2. Why does `getline()` sometimes read an empty string?

Because `cin` leaves the newline character (`\n`) in the input buffer.

Use:

```cpp
cin.ignore();
```

or

```cpp
getline(cin >> ws, str);
```

---

### Q3. Difference between `endl` and `\n`?

- `endl` prints a newline **and flushes the output buffer**.
    
- `\n` only prints a newline and is faster.
    

---

### Q4. Why use `ios::sync_with_stdio(false)`?

To speed up input and output by disabling synchronization between C and C++ standard streams.

---

### Q5. Difference between `cout` and `cerr`?

- `cout` → Standard output (buffered).
    
- `cerr` → Error output (unbuffered).
    

---

# Time & Space Complexity

For reading or writing **one value**:

- **Time:** `O(1)`
    
- **Space:** `O(1)`
    

For reading **N values**:

- **Time:** `O(N)`
    
- **Space:** `O(1)` (excluding the storage used for the input data)

# Interview Summary

- `cin` is used for input, `cout` for output.
    
- Streams allow chaining with `>>` and `<<`.
    
- `cin` stops at whitespace; `getline()` reads an entire line.
    
- Remember the `cin` + `getline()` newline issue and fix it with `cin.ignore()` or `getline(cin >> ws, ...)`.
    
- Prefer `\n` over `endl` for better performance.
    
- Use `ios::sync_with_stdio(false);` and `cin.tie(nullptr);` for fast I/O.
    
- `cerr` is for error messages and is unbuffered.
    
- Know the basics of file input/output (`ifstream` and `ofstream`).
