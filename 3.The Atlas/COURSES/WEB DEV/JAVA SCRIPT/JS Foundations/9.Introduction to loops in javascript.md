# 🔁 JavaScript Loops

> [!info]
> A **loop** is a programming construct that allows a block of code to execute **repeatedly** until a condition becomes false.

---

# 🧠 Why Do We Need Loops?

Without loops:

```js
console.log("Hello");
console.log("Hello");
console.log("Hello");
...
```

Imagine writing this **1000 times**.

Instead:

```js
for (...) {
    console.log("Hello");
}
```

Loops automate repetitive work.

# 🎯 Mental Model

Think of a loop as:

```
Worker

Task?
↓

Do work

↓

Finished?

↓

No → Repeat

↓

Yes → Exit
```

A loop is simply a worker that keeps doing the same task until told to stop.

---

# 🔄 Loop Flow

```
Start
  │
  ▼
Check Condition
      │
 ┌────┴─────┐
 │          │
True      False
 │          │
 ▼          ▼
Execute    Exit Loop
 │
 ▼
Update State
 │
 └──────────────┐
               ▲
```

Notice:

The condition is checked repeatedly.

---

# 🧩 Every Loop Has 4 Parts

| Part | Purpose |
|-------|----------|
| Initialization | Starting value |
| Condition | Continue or Stop |
| Body | Code to execute |
| Update | Changes value each iteration |

Example

```js
let i = 1;      // Initialization

while(i <= 5){  // Condition

    console.log(i); // Body

    i++;            // Update
}
```

---

# ❗Termination Condition

A loop **must** eventually stop.

Without a stopping condition:

```js
while(true){

}
```

This becomes an **Infinite Loop**.

Problems:

- CPU usage becomes 100%
- Program hangs
- Browser may freeze

# Example: Sum from 1 to 5

Goal

```

```


# ❌ Infinite Loop Example

```js
let i = 1;

while(i <= 5){

    console.log(i);

}
```

Problem

```
i never changes
```

Condition always remains true.

Always update the loop variable.

```js
i++;
```

---

# ++ Operator

Instead of

```js
i = i + 1;
```

Use

```js
i++;
```

Both are identical.

---

# += Operator

Instead of

```js
sum = sum + i;
```

Use

```js
sum += i;
```

Cleaner and shorter.

# Variable Scope

Correct

```js
let sum = 0;

while(...){

}

console.log(sum);
```

Wrong

```js
while(...){

    let sum = 0;

}

console.log(sum);
```

Output

```
ReferenceError
```

Reason:

Variables declared inside `{}` exist only inside that block.

# Types of Loops in JavaScript

| Loop | Description |
|------|-------------|
| while | Checks condition first |
| do...while | Executes once before checking |
| for | Most commonly used |
| for...in | Iterates object keys |
| for...of | Iterates iterable values |
| forEach() | Array iteration method |

---

# while vs do...while

## while

```
Check

↓

Execute
```

Condition is checked first.

If false initially:

```
Runs 0 times
```

---

## do...while

```
Execute

↓

Check
```

Runs **at least once**.

---

Example

```js
let i = 10;

while(i < 5){

    console.log(i);

}
```

Output

```
Nothing
```

---

```js
let i = 10;

do{

    console.log(i);

}while(i < 5);
```

Output

```
10
```

# Best Practices

✅ Always initialize variables.

```js
let i = 0;
```

---

✅ Always update loop variable.

```js
i++;
```

---

✅ Keep termination condition clear.

```js
i <= 10
```

---

✅ Avoid infinite loops.

---

✅ Dry run using pen and paper.

Visualizing each iteration helps understand loop execution.

# Interview Questions

### Why are loops used?

To automate repetitive tasks.

---

### What causes an infinite loop?

The loop condition never becomes false.

---

### Difference between while and do...while?

| while | do...while |
|--------|------------|
| Checks first | Executes first |
| May execute 0 times | Executes at least once |

---

### Why use i++?

It updates the iterator so the loop can eventually terminate.

# Quick Revision

- Loop = Repeat work
- Needs a stopping condition
- Always update iterator
- `while` checks first
- `do...while` executes first
- `sum += i` adds changing values
- `sum += 1` adds constant values
- Infinite loop = No termination
- Most common loop = `for`
