# 1. What is an Array?

An **array** stores multiple values in a single variable.

Instead of:

```js
let tea1 = "Green Tea";
let tea2 = "Black Tea";
let tea3 = "Oolong Tea";
```

Use

```js
let teaFlavors = [
    "Green Tea",
    "Black Tea",
    "Oolong Tea"
];
```

---

# 2. Creating Arrays

## Method 1 (Recommended)

```js
let arr = [1, 2, 3];
```

---

## Method 2

```js
let arr = new Array(1, 2, 3);
```

This also creates an array but is used less frequently.

---

# 3. Accessing Elements

Arrays use **zero-based indexing**.

```
Index

0 → First element
1 → Second element
2 → Third element
```

Example

```js
const teaFlavors = [
    "Green Tea",
    "Black Tea",
    "Oolong Tea"
];

const firstTea = teaFlavors[0];
```

Output

```
Green Tea
```

Human counting starts from **1**.

Programming counting starts from **0**.

# 4. Array Methods

---

## Push()

Adds an element to the end.

```js
let cities = ["Mumbai", "Sydney"];

cities.push("Berlin");
```

Result

```js
["Mumbai", "Sydney", "Berlin"]
```

---

### Why use push()?

Instead of

```js
cities[2] = "Berlin";
```

or

```js
cities[cities.length] = "Berlin";
```

Simply use

```js
cities.push("Berlin");
```

Cleaner and safer.

---

## Pop()

Removes the last element.

```js
let orders = [
    "Chai",
    "Iced Tea",
    "Matcha",
    "Earl Grey"
];

orders.pop();
```

Result

```js
[
 "Chai",
 "Iced Tea",
 "Matcha"
]
```

---

### pop() returns the removed value

```js
const lastOrder = orders.pop();
```

```
lastOrder = "Earl Grey"
```

# 6. includes()

Checks whether an element exists.

```js
const cityBucketList = [
    "Kyoto",
    "London",
    "Cape Town",
    "Vancouver"
];

cityBucketList.includes("London");
```

Output

```
true
```

---

If

```js
cityBucketList.includes("london")
```

Output

```
false
```

It is **case-sensitive**.

# 7. Soft Copy (Reference Copy)

```js
const popularTeas = [
    "Green Tea",
    "Oolong Tea",
    "Chai"
];

const softCopy = popularTeas;
```

Looks like a copy.

Actually both variables point to **the same array**.

```
popularTeas
      │
      ▼
   [Array]
      ▲
      │
softCopy
```

If

```js
popularTeas.pop();
```

Then

```
softCopy
```

also changes.

Reason:

Both variables reference the same memory.

---

# 8. Hard Copy

Creates a brand-new array.

Recommended

```js
const hardCopy = [...popularTeas];
```

Alternative

```js
const hardCopy = popularTeas.slice();
```

Now

```js
popularTeas.pop();
```

does **not** affect

```js
hardCopy
```

Memory

```
popularTeas  ---> Array A

hardCopy -----> Array B
```

Different memory locations.

---

# 9. Spread Operator (...)

```js
const copy = [...array];
```

Creates a new array by expanding every element.

Example

```js
const nums = [1,2,3];

const copy = [...nums];
```

Result

```
[1,2,3]
```

Instructor mentions that the same `...` syntax is also used for **rest operators**, which will be covered later.

# 10. Merging Arrays

Wrong

```js
const world = europeanCities + asianCities;
```

Produces an incorrect result.

---

Also not desired

```js
[
 europeanCities,
 asianCities
]
```

Creates an array **of arrays**.

---

Correct

```js
const worldCities =
    europeanCities.concat(asianCities);
```

Result

```js
[
 "Paris",
 "Rome",
 "Tokyo",
 "Bangkok"
]
```

# 12. Shift vs Unshift

## shift()

Removes the first element.

```js
let arr = [1,2,3];

arr.shift();
```

Result

```
[2,3]
```

---

## unshift()

Adds elements at the beginning.

```js
let arr = [1,2,3];

arr.unshift(0);
```

Result

```
[0,1,2,3]
```

The instructor notes these operations are relatively expensive because existing elements must be shifted in memory.

# 14. Important Takeaways

- Arrays store multiple values together.
    
- Array indexing starts at **0**.
    
- Use `push()` to add at the end.
    
- Use `pop()` to remove from the end.
    
- Use `length` to count elements.
    
- Use `includes()` to check if an element exists.
    
- Assigning one array to another creates a **soft copy** (shared reference).
    
- Use the spread operator (`...`) or `slice()` to create a **hard copy**.
    
- Use `concat()` to merge arrays.
    
- `shift()` removes the first element; `unshift()` adds elements at the beginning.
    
- You don't need to memorize every array method—know that they exist and consult documentation when needed, which the instructor emphasizes as an important developer skill.
