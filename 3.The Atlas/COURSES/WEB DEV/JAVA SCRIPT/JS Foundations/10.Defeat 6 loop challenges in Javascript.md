# JavaScript Loops — Short Complete Notes

## 1. Why Loops?

A **loop repeats a block of code** until some condition becomes false.

Mental model:

```text
Initialize
   ↓
Check condition
   ↓ true
Execute code
   ↓
Update variable
   ↓
Check again...
   ↓ false
STOP
```

Most loops therefore need:

```text
1. Initialization
2. Condition
3. Update (increment/decrement)
```

---

# 2. `while` Loop

Syntax:

```js
let i = 1;

while (condition) {
    // code
    i++;
}
```

The **condition is checked first**.

```text
condition?
   ├── true  → execute → repeat
   └── false → exit
```

## Example: Sum 1 → 5

```js
let sum = 0;
let i = 1;

while (i <= 5) {
    sum += i;
    i++;
}

console.log(sum); // 15
```

Dry run:

|i|sum|
|--:|--:|
|1|1|
|2|3|
|3|6|
|4|10|
|5|15|

`<= 5` matters because using `< 5` would stop before processing `5`.

### `+=`

```js
sum += i;
```

means:

```js
sum = sum + i;
```

# 3. Countdown with `while`

Goal:

```text
5 → 4 → 3 → 2 → 1
```

```js
let countdown = [];
let j = 5;

while (j >= 1) {
    countdown.push(j);
    j--;
}

console.log(countdown);
// [5, 4, 3, 2, 1]
```

Here we **decrement** because we're travelling backward.

```js
j--;
```

means:

```js
j = j - 1;
```

The lecture uses `push()` to store each current value in the array.

# 4. `do...while` Loop

Main difference:

> `do...while` executes the body **at least once**.

Syntax:

```js
do {
    // code
} while (condition);
```

Mental model:

```text
WHILE

condition
   ↓
 execute


DO-WHILE

execute
   ↓
condition
```

This makes `do...while` useful when something must happen once **before you can even test whether to continue**.

---

# 5. User Input with `do...while`

Example from lecture:

Keep asking for tea names until the user enters `"stop"`.

```js
let teaCollection = [];
let tea;

do {
    tea = prompt(`Enter your favorite tea. Type "stop" to finish`);

    if (tea !== "stop") {
        teaCollection.push(tea);
    }

} while (tea !== "stop");
```

Important logic:

```js
tea !== "stop"
```

means:

> continue while tea is **NOT** `"stop"`.

If:

```text
tea = "black tea"
```

condition:

```text
"black tea" !== "stop"
→ true
```

Continue.

If:

```text
tea = "stop"
```

then:

```text
"stop" !== "stop"
→ false
```

Exit.

The `if` also prevents `"stop"` itself from being inserted into the array.

`prompt()` is normally available in the **browser**, but not directly in Node.js.

So this:

```js
prompt("Enter something");
```

works in browser JavaScript, but standard Node.js will produce:

```text
prompt is not defined
```

# 7. Sum Using `do...while`

Add:

```text
1 + 2 + 3
```

```js
let total = 0;
let k = 1;

do {
    total += k;
    k++;
} while (k <= 3);

console.log(total); // 6
```

Be careful with:

```js
k++;
```

Without updating `k`, the condition may stay true forever → **infinite loop**.

# 8. `for` Loop

A `for` loop combines the three important loop pieces into one line.

```js
for (initialization; condition; update) {
    // code
}
```

Example:

```js
for (let i = 0; i < 5; i++) {
    console.log(i);
}
```

Think:

```text
for (
    let i = 0;   // START
    i < 5;       // CONTINUE?
    i++          // MOVE
)
```

Internally:

```text
let i = 0
   ↓
i < 5 ?
   ↓
execute
   ↓
i++
   ↓
i < 5 ?
   ↓
...
```

The lecture emphasizes that `for` isn't fundamentally doing something magical—it packages the initialization, condition, and update that you were already writing separately with `while`.

# 9. Looping Through Arrays

Example:

```js
let numbers = [2, 4, 6];
```

Indexes:

```text
Value:   2   4   6
Index:   0   1   2

length = 3
```

Standard pattern:

```js
for (let i = 0; i < numbers.length; i++) {
    console.log(numbers[i]);
}
```

`i` represents the **index**.

```text
i = 0 → numbers[0] → 2
i = 1 → numbers[1] → 4
i = 2 → numbers[2] → 6
```

---

# 10. Why `< array.length`?

Very important pattern:

```js
i < numbers.length
```

NOT:

```js
i <= numbers.length
```

For:

```js
let numbers = [2, 4, 6];
```

we have:

```text
length = 3

valid indexes:
0
1
2
```

Index `3` is outside the array.

Therefore:

```js
i < numbers.length
```

keeps traversal inside valid indexes. This exact index-vs-length distinction is highlighted in the lecture.

# 11. Multiply Every Array Element

Input:

```js
let numbers = [2, 4, 6];
```

Wanted:

```text
[4, 8, 12]
```

Solution:

```js
let multipliedNumbers = [];

for (let i = 0; i < numbers.length; i++) {
    let newNumber = numbers[i] * 2;
    multipliedNumbers.push(newNumber);
}
```

Or shorter:

```js
let multipliedNumbers = [];

for (let i = 0; i < numbers.length; i++) {
    multipliedNumbers.push(numbers[i] * 2);
}
```

Mental model:

```text
Read → Transform → Store

2 → ×2 → 4 → push
4 → ×2 → 8 → push
6 → ×2 → 12 → push
```

Result:

```js
[4, 8, 12]
```

Both versions perform the same logical operation; the lecture shows both approaches.

# 12. Copy Array Elements Using Loop

```js
let cities = [
    "Paris",
    "New York",
    "Tokyo",
    "London"
];

let cityList = [];

for (let i = 0; i < cities.length; i++) {
    let city = cities[i];
    cityList.push(city);
}
```

Result:

```js
[
    "Paris",
    "New York",
    "Tokyo",
    "London"
]
```

Pattern:

```text
Array
 ↓
index
 ↓
array[index]
 ↓
value
 ↓
push(value)
 ↓
new array
```

# 13. `push()`, `shift()`, `unshift()`

The lecture mainly uses:

```js
array.push(value);
```

which adds to the **end**.

Remember:

```js
push(x)      → add at END
unshift(x)   → add at START
shift()      → remove from START
```

Example:

```js
let arr = [2, 3];

arr.push(4);
// [2, 3, 4]

arr.unshift(1);
// [1, 2, 3, 4]

arr.shift();
// [2, 3, 4]
```

The lecture leaves experimenting with `shift()` and `unshift()` as an exercise.

# 14. Dry Run — Important Skill

Before running code, mentally execute it.

Example:

```js
for (let i = 0; i < 3; i++) {
    console.log(i);
}
```

Think:

```text
i = 0
0 < 3 ✓
print 0
i++

i = 1
1 < 3 ✓
print 1
i++

i = 2
2 < 3 ✓
print 2
i++

i = 3
3 < 3 ✗
STOP
```

Output:

```text
0
1
2
```

The instructor specifically recommends learning to predict execution instead of constantly running the program—this is **dry running**.

# 🧠 Final Cheat Sheet

```js
// WHILE
let i = 0;

while (i < 5) {
    console.log(i);
    i++;
}


// DO-WHILE
let j = 0;

do {
    console.log(j);
    j++;
} while (j < 5);


// FOR
for (let i = 0; i < 5; i++) {
    console.log(i);
}


// ARRAY TRAVERSAL
for (let i = 0; i < arr.length; i++) {
    console.log(arr[i]);
}


// TRANSFORM + STORE
let result = [];

for (let i = 0; i < arr.length; i++) {
    result.push(arr[i] * 2);
}
```

### Pattern to remember

```text
WHILE
→ use when repetition depends mainly on a condition.

DO-WHILE
→ use when code MUST execute at least once.

FOR
→ use when initialization + condition + update
  naturally describe the traversal.

ARRAY TRAVERSAL
→ index starts at 0
→ continue while i < array.length
→ current value = array[i]
```

The **big idea from this lecture isn't memorizing three syntaxes**. All three loops are the same underlying machine:

**start state → check/execute → change state → repeat → stop.**

Once that clicks, later array traversal—and eventually linked-list traversal, tree traversal, BFS/DFS, etc.—becomes much easier to reason about.
