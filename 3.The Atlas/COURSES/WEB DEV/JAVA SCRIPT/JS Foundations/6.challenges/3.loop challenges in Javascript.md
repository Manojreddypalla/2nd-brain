## Q1. Sum numbers from 1 to 5 using `while`

**Question:**  
Write a `while` loop that calculates the sum of all numbers from `1` to `5` and stores the result in `sum`.

```js
let sum = 0;
let i = 1;

while (i <= 5) {
    sum += i;
    i++;
}
```

### How it works

We need two variables:

```js
let sum = 0; // stores the result
let i = 1;   // controls the loop
```

The condition:

```js
i <= 5
```

means **include 5**.

Inside the loop:

```js
sum += i;
```

is shorthand for:

```js
sum = sum + i;
```

Then:

```js
i++;
```

moves to the next number.

### Dry run

```text
i = 1 → sum = 1
i = 2 → sum = 3
i = 3 → sum = 6
i = 4 → sum = 10
i = 5 → sum = 15
```

Final:

```js
sum = 15;
```

**Pattern:**

```text
initialize → condition → work → update
```

# Q2. Countdown from 5 to 1 into an array

**Question:**  
Write a `while` loop that counts down from `5` to `1` and stores the numbers in an array named `countdown`.

```js
let countdown = [];
let j = 5;

while (j > 0) {
    countdown.push(j);
    j--;
}
```

### Why an empty array?

Because the question says **store the numbers in an array**:

```js
let countdown = [];
```

Then each iteration adds the current number:

```js
countdown.push(j);
```

`push()` adds an element to the end of the array.

### Why `j--`?

We're counting **down**:

```text
5 → 4 → 3 → 2 → 1
```

So we decrement:

```js
j--;
```

### Result

```js
[5, 4, 3, 2, 1]
```

### Pattern

For a countdown:

```js
let i = start;

while (i > 0) {
    array.push(i);
    i--;
}
```

# Q3. Ask for tea until user enters `"stop"`

**Question:**  
Write a `do...while` loop that prompts the user for their favourite tea until they enter `"stop"`. Store every tea type in `teaCollection`.

```js
let teaCollection = [];
let tea;

do {
    tea = prompt(`Enter your favourite tea (type "stop" to finish)`);

    if (tea !== "stop") {
        teaCollection.push(tea);
    }

} while (tea !== "stop");
```

### Why `do...while`?

Because the user must be asked **at least once**.

```text
do
 ↓
ask user
 ↓
check condition
 ↓
repeat?
```

Unlike:

```js
while (condition) {
}
```

where the condition is checked **before** the first execution.

### Important logic

```js
if (tea !== "stop")
```

means:

> Only store the tea if it is NOT `"stop"`.

So:

```text
"Black tea" → store
"Green tea" → store
"Lemon tea" → store
"stop"      → don't store → exit
```

### Example result

```js
["Black tea", "Green tea", "Lemon tea"]
```

`"stop"` is **not** included.

### Important idea

The `"stop"` value is being used as the **exit/sentinel value**.

```js
while (tea !== "stop")
```

means:

> Keep going as long as the user hasn't said stop.

# Q4. Add numbers from 1 to 3 using `do...while`

**Question:**  
Write a `do...while` loop that adds numbers from `1` to `3` and stores the result in `total`.

```js
let total = 0;
let k = 1;

do {
    total += k;
    k++;
} while (k <= 3);
```

### Logic

```js
total += k;
```

adds the current number.

```js
k++;
```

moves to the next number.

### Dry run

```text
k = 1 → total = 1
k = 2 → total = 3
k = 3 → total = 6
```

Final:

```js
total = 6;
```

### Remember

`do...while`:

```js
do {
    // execute first
} while (condition);
```

So the condition is checked **after** the loop body.

# Q5. Multiply every array element by 2

**Question:**  
Write a `for` loop that multiplies each element in `[2, 4, 6]` by `2` and stores the results in `multipliedNumbers`.

```js
let multipliedNumbers = [];
let numbers = [2, 4, 6];

for (let l = 0; l < numbers.length; l++) {
    multipliedNumbers.push(numbers[l] * 2);
}
```

### First understand the `for` loop

```js
for (let l = 0; l < numbers.length; l++) {
}
```

It has 3 parts:

```text
initialization ; condition ; update
```

Specifically:

```js
let l = 0       // start at index 0
l < numbers.length  // keep going while valid
l++             // move to next index
```

### Why `l < numbers.length`?

For:

```js
[2, 4, 6]
```

the indexes are:

```text
value:   2   4   6
index:   0   1   2
```

And:

```js
numbers.length
```

is:

```text
3
```

Therefore:

```js
l < 3
```

gives:

```text
0, 1, 2
```

Exactly the valid indexes.

**Don't use:**

```js
l <= numbers.length
```

because that eventually tries:

```js
numbers[3]
```

which is outside the valid indexes.

### What does `numbers[l]` mean?

It means:

> Give me the element at the current index.

```text
l = 0 → numbers[0] → 2
l = 1 → numbers[1] → 4
l = 2 → numbers[2] → 6
```

Then:

```js
numbers[l] * 2
```

gives:

```text
2 × 2 = 4
4 × 2 = 8
6 × 2 = 12
```

Finally:

```js
multipliedNumbers.push(...)
```

stores each result.

### Result

```js
[4, 8, 12]
```

### Core pattern

```js
for (let i = 0; i < array.length; i++) {
    newArray.push(array[i] * something);
}
```

This is the basic **traverse → transform → store** pattern.

# Q6. Copy cities into another array

**Question:**  
Write a `for` loop that lists all cities in:

```js
["Paris", "New York", "Tokyo", "London"]
```

and stores each city in a new array named `cityList`.

```js
let cities = ["Paris", "New York", "Tokyo", "London"];
let cityList = [];

for (let c = 0; c < cities.length; c++) {
    const myCity = cities[c];
    cityList.push(myCity);
}
```

### What happens?

```text
c = 0 → cities[0] → "Paris"
c = 1 → cities[1] → "New York"
c = 2 → cities[2] → "Tokyo"
c = 3 → cities[3] → "London"
```

Each value is pushed into:

```js
cityList
```

Result:

```js
["Paris", "New York", "Tokyo", "London"]
```

### Can we simplify it?

Yes:

```js
for (let c = 0; c < cities.length; c++) {
    cityList.push(cities[c]);
}
```

The temporary variable:

```js
const myCity = cities[c];
```

isn't necessary here.

But it can make the code easier to read when the operation becomes more complicated.

# 🔑 The Main Pattern Behind Q5 & Q6

Both problems are actually the **same fundamental operation**:

```text
Go through every element
        ↓
Access element using index
        ↓
Do something with it
        ↓
Optionally store the result
```

### Just copy

```js
for (let i = 0; i < array.length; i++) {
    newArray.push(array[i]);
}
```

### Transform

```js
for (let i = 0; i < array.length; i++) {
    newArray.push(array[i] * 2);
}
```

So when you see:

> "for every element in an array..."

your brain should immediately think:

```js
for (let i = 0; i < array.length; i++) {
    // array[i]
}
```

# 🧠 Loop Patterns From This Lecture

### `while`

Use when the loop is naturally controlled by a condition.

```js
while (condition) {
    // work
    // update
}
```

### `do...while`

Use when the operation must happen **at least once**.

```js
do {
    // work
} while (condition);
```

### `for`

Use when you're iterating through a known sequence/range, especially arrays.

```js
for (let i = 0; i < array.length; i++) {
    // work
}
```

### Array traversal

```js
array[i]
```

### Add to another array

```js
newArray.push(value)
```

### Move forward

```js
i++
```

### Move backward

```js
i--
```

### Array boundary

```js
i < array.length
```

**Not**

```js
i <= array.length
```
