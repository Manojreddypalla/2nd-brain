# JavaScript — Loop Challenges

## Challenge 1 — Select Teas

Given:

```js
["green tea", "black tea", "chai", "oolong tea"]
```

Write a **`for` loop** that:

- Loops through the array.
    
- Stops when `"chai"` is found.
    
- Stores all teas **before `"chai"`** in a new array named:
    

```js
selectedTeas
```
