# JavaScript Loop Challenges + Solutions

## 1. Select Teas

### Question

```js
const teas = ["green tea", "black tea", "chai", "oolong tea"];
```

Write a `for` loop that:

- Stops when `"chai"` is found.
    
- Stores all teas before `"chai"` in `selectedTeas`.
    

### Solution

```js
const teas = ["green tea", "black tea", "chai", "oolong tea"];
const selectedTeas = [];

for (let i = 0; i < teas.length; i++) {
    if (teas[i] === "chai") {
        break;
    }

    selectedTeas.push(teas[i]);
}

console.log(selectedTeas);
```

### Output

```js
["green tea", "black tea"]
```

**Pattern:** `break` → completely stop the loop.

# 2. Skip Sydney

### Question

```js
const cities = ["Berlin", "Tokyo", "Sydney", "Paris"];
```

Use `forEach` to:

- Skip `"Sydney"`.
    
- Store the remaining cities in `travelledCities`.
    

### Solution

```js
const cities = ["Berlin", "Tokyo", "Sydney", "Paris"];
const travelledCities = [];

cities.forEach(function (city) {
    if (city === "Sydney") {
        return;
    }

    travelledCities.push(city);
});

console.log(travelledCities);
```

### Output

```js
["Berlin", "Tokyo", "Paris"]
```

**Important:** Here `return` does **not** stop the entire `forEach`.  
It exits the current callback/function and `forEach` moves to the next element.

# 3. Double Numbers — Skip 7

### Question

```js
const numbers = [2, 5, 7, 9];
```

Use a `for` loop to:

- Skip `7`.
    
- Multiply every other number by `2`.
    
- Store the results in `doubleNumbers`.
    

### Solution

```js
const numbers = [2, 5, 7, 9];
const doubleNumbers = [];

for (let i = 0; i < numbers.length; i++) {
    if (numbers[i] === 7) {
        continue;
    }

    doubleNumbers.push(numbers[i] * 2);
}

console.log(doubleNumbers);
```

### Output

```js
[4, 10, 18]
```

**Pattern:** `continue` → skip current iteration, then continue looping.

# 5. Large Cities

### Question

Given an object:

```js

    Paris: 2,
```

Use `for...in` to:

- Skip cities with population below `3 million`.

```js
    Paris: 2,

const largeCities = {};
```

**Pattern:**


```js
const teaCollection = [

    "chai",
    "oolong"
];
```

# 8. Stop at Chai — `forEach`

### Question

```js
const teas = [
    "Earl Grey",
    "green tea",
    "chai",
    "oolong"
];
```

Use `forEach` and store the teas before `"chai"` in `availability`.

### Solution

```js
const teas = [
    "Earl Grey",
    "green tea",
    "chai",
    "oolong"
];

const availability = [];

teas.forEach(function (tea) {
    if (tea === "chai") {
        return;
    }

    availability.push(tea);
});

console.log(availability);
```

### Output

```js
["Earl Grey", "green tea", "oolong"]
```

### Why isn't this the same as `break`?

Because:

```js
break;
```

works on the **loop itself**.

But `forEach` executes a **function for each element**. So:

```js
return;
```

means:

```text
"End this function call."
```

not:

```text
"End the entire forEach."
```

The video specifically introduces this distinction through the challenge.

# 🧠 The 3 Patterns You Should Recognize

This entire video is basically training these three mental models:

```text
break
 ↓
STOP THE WHOLE LOOP
```

```text
continue
 ↓
SKIP CURRENT ITERATION
 ↓
GO TO NEXT ITERATION
```

```text
return inside forEach callback
 ↓
END CURRENT FUNCTION CALL
 ↓
forEach continues with next element
```

And the loop-selection pattern:

|Situation|Use|
|---|---|
|Need index/control|`for`|
|Need values from array|`for...of`|
|Need object keys|`for...in`|
|Run a function for every array element|`forEach`|

That's the real skill this video is trying to build: **don't memorize loop syntax; look at what control over the iteration you actually need.**
