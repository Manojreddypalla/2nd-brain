# 📘 JavaScript Mini Notes – Printing, Data Types & Variables

---

# 1. Printing Output

The most common way to print anything:

```js
console.log("Hello World");
```

Output:

```
Hello World
```

---

## Other Printing Methods

### Standard Output (Node.js)

```js
process.stdout.write("Hello");
process.stdout.write(" World");
```

Output

```
Hello World
```

> ❌ Doesn't automatically move to the next line.

---

### Console Methods

```js
console.log("Normal Log");
console.warn("Warning");
console.info("Information");
console.error("Error");
console.table(data);
console.clear();
```

---

## console.table()

Useful for Arrays and Objects.

```js
console.table({
    city: "Jaipur",
    country: "India"
});
```

Output

```
┌─────────┬──────────┐
│ city    │ Jaipur   │
│ country │ India    │
└─────────┴──────────┘
```

Very useful for debugging.

# 3. JavaScript Data Types

JavaScript has **8 primitive/object categories** commonly discussed.

|Type|Example|
|---|---|
|String|`"Hello"`|
|Number|`25`, `3.14`|
|Boolean|`true`, `false`|
|BigInt|`12345678901234567890n`|
|Undefined|`undefined`|
|Null|`null`|
|Object|`{}`, `[]`|
|Symbol|`Symbol("id")`|

---

## String

Collection of characters.

```js
let name = "Retr0";
```

---

## Number

Stores integers or decimals.

```js
let score = 102;
let pi = 3.14;
```

---

## Boolean

Only two values.

```js
true
false
```

Example

```js
let isLoggedIn = true;
```

Used in conditions.

---

## BigInt

For very large integers.

```js
let big = 123456789012345678901234567890n;
```

Notice the **n**.

---

## Undefined

Means

> Value hasn't been assigned yet.

```js
let age;

console.log(age);
```

Output

```
undefined
```

---

## Null

Means

> Intentionally empty.

```js
let temperature = null;
```

Not equal to zero.

```
null ❌ 0
```

---

## Object

Stores related data.

```js
let user = {
    firstName: "Hitesh",
    lastName: "Choudhary"
};
```

---

## Array (Object)

Stores multiple values.

```js
let tea = [
    "Lemon",
    "Orange",
    "Oolong"
];
```

---

## Symbol

Creates unique values.

```js
let id = Symbol("id");
```

Used internally for unique identifiers.

---

# 4. Variables

Think of a variable as a **labeled box in RAM**.

```
RAM

+---------+
| score   | ---> 102
+---------+
```

You access the value using its name.

---

# 5. Variable Keywords

## let

Modern variable.

```js
let score = 100;
```

Can change later.

```js
score = 200;
```

---

## const

Constant variable.

```js
const username = "retr0";
```

Cannot be reassigned.

```js
username = "new";
```

Error

```
TypeError:
Assignment to constant variable
```

---

## var

Old JavaScript keyword.

```js
var age = 20;
```

Avoid in modern code because of scope issues.

---

## Rule

Use

```
const
```

by default.

Use

```
let
```

only when the value changes.

Avoid

```
var
```

---

# 6. Variable Assignment

```js
let score = 102;
```

Copy value

```js
let getScore = score;
```

Now

```
score = 102
getScore = 102
```

---

# 7. Printing Variables

```js
let score = 102;

console.log(score);
```

Output

```
102
```

Nothing prints unless you explicitly tell JavaScript.

---

# 8. Reassigning Variables

Allowed with **let**

```js
let game = "Spider-Man";

game = "Batman";
```

Output

```
Batman
```

Not allowed with **const**

```js
const game = "Spider-Man";

game = "Batman";
```

Throws

```
TypeError
```

---

# 9. Naming Variables (Best Practices)

✅ Good

```js
let gameName;
let firstName;
let isLoggedIn;
let totalScore;
```

❌ Bad

```js
let a;
let x;
let abc;
```

Choose meaningful names.

# 💡 Key Takeaways

- `console.log()` is the standard way to print.
    
- `console.table()` is great for arrays and objects.
    
- Use `//` or `/* */` for comments.
    
- JavaScript has types like `String`, `Number`, `Boolean`, `Object`, `Null`, `Undefined`, `BigInt`, and `Symbol`.
    
- `let` → value can change.
    
- `const` → value cannot be reassigned.
    
- Avoid `var` in modern JavaScript.
    
- Variables are simply named locations in memory.
    
- Nothing is displayed unless you explicitly print it with `console.log()`.
