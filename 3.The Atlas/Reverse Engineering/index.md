# 🔍 Reverse Engineering Index

> **Purpose:**  
> Reverse Engineering is the practice of studying existing products, software, games, media, and systems to understand **how they work (Technical)** and **why they work (Creative)**.  
> This section is not for copying—it is for learning, inspiration, and improving my own work.

---

# 💻 Technical

| Category | Focus | Example Questions |
|----------|-------|-------------------|
| 🎮 Games | Engine architecture, gameplay systems, rendering, AI, networking | How does GTA stream the world? How is save data stored? |
| 🌐 Websites | Architecture, APIs, frontend, backend, performance | How is this dashboard built? Why is it fast? |
| 💻 Software | Features, workflows, UI architecture | Why is this software intuitive? |
| ⚙️ Engine Architecture | Unreal, Unity, Godot internals | How are Actors updated every frame? |
| 🖥 Operating Systems | Windows, Linux internals | How are processes managed? |
| 🤖 AI & LLMs | Agents, RAG, prompting, workflows | How is this AI assistant designed? |
| 🖼 Graphics Programming | Rendering, shaders, lighting | How does this shader work? |
| 📡 Networking | Multiplayer, protocols, APIs | How is synchronization handled? |
| 🔐 Security | Authentication, encryption, exploits | How is cheating prevented? |
| 🦠 Malware Analysis | Static & dynamic analysis | What techniques does this malware use? |
| 🧠 Algorithms | Search, pathfinding, optimization | Which algorithm fits this problem? |
| 📂 Databases | Schema, indexing, scaling | Why was this database chosen? |
| ⚙️ DevOps | Deployment, Docker, CI/CD | How is this application deployed? |
| 🔧 Programming | Code architecture, patterns | Why was this pattern used? |
| 🖱 UI Engineering | Components, accessibility | How is this UI implemented? |
| 🛠 Tools | IDEs, plugins, pipelines | How does this tool improve workflow? |
| 💾 Hardware | CPU, GPU, storage, embedded | How does this hardware achieve its performance? |
