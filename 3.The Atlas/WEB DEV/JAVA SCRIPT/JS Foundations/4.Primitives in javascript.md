# JavaScript Data Types - Revision Notes

## JavaScript Data Types

There are **2 categories** of data.

```
Data Types
│
├── Primitive
│   ├── Number
│   ├── String
│   ├── Boolean
│   ├── Null
│   ├── Undefined
│   └── Symbol
│
└── Non-Primitive (Reference Types)
    ├── Object
    ├── Array
    └── Function
```

# Primitive Data Types

Primitive values are:

- Simple
    
- Immutable
    
- Stored by value
    
- Lightweight
    

There are **6 primitive types**.

```
Number
String
Boolean
Null
Undefined
Symbol
```

# Non-Primitive Types

These are objects.

Examples:

```
Object
Array
Function
```

Characteristics:

- More functionality
    
- Stored by reference
    
- Can contain multiple values

# Number Object (Not Recommended)

```javascript
let balance = new Number(120);
```

Now,

```javascript
typeof balance
```

Output

```
object
```

### Why?

Because

```
120
```

is a primitive.

But

```
new Number(120)
```

creates a **Number object**.

Avoid using

```javascript
new Number()
```

unless you specifically need wrapper objects.

---

```

```

---

Avoid

```javascript
new Boolean(true)
```

because it creates an object.

# Undefined

A variable exists.

But no value has been assigned.

```javascript
let firstName;

console.log(firstName);
```

Output

```
undefined
```

Think of it as:

> Memory exists, value doesn't.

---

You can also explicitly write

```javascript
let lastName = undefined;
```

although it's usually unnecessary.

---

# Null

Null means

> Intentionally empty.

Example

```javascript
let user = null;
```

It is **not**

- ""
    
- 0
    
- false
    

It literally means

```
No value
```

Think:

> I know there should be something here, but right now it's intentionally empty.

---

## Undefined vs Null

|Undefined|Null|
|---|---|
|Variable declared|Variable has a value|
|Value not assigned|Value intentionally empty|
|Default by JavaScript|Assigned manually|

Example

```javascript
let a;

console.log(a);
```

Output

```
undefined
```

Example

```javascript
let b = null;

console.log(b);
```

Output

```
null
```

# String

Ways to create strings.

### Double Quotes

```javascript
let name = "Hitesh";
```

---

### Single Quotes

```javascript
let name = 'Hitesh';
```

---

### Backticks (Template Literals)

```javascript
let name = "Hitesh";

```

Output

```
Hello Hitesh
```

---

# Old String Concatenation

```javascript
let message = "Hello " + name;
```

Works, but becomes messy.

---

# Template Literals (Recommended)

```javascript
let message = `Hello ${name}!`;
```

Advantages

- Cleaner
    
- Easier to read
    
- Supports expressions
    
- Multi-line strings
    

---

# String Interpolation

Inside template literals

```
${}
```

Anything inside is evaluated.

Example

```javascript
let x = 10;

console.log(`Value = ${x}`);
```

Output

```
Value = 10
```

---

You can even calculate.

```javascript
console.log(`Answer = ${2 * 5}`);
```

Output

```
Answer = 10
```

# Symbol

Symbol creates a **unique identifier**.

```javascript
let s1 = Symbol();
let s2 = Symbol();

console.log(s1 === s2);
```

Output

```
false
```

Every Symbol is unique.

Even

```javascript
Symbol("id")
```

and

```javascript
Symbol("id")
```

are different.

The description (`"id"`) is only for debugging—it does **not** make two symbols equal.

# Things Interviewers Love to Ask

### Q1. Difference between `null` and `undefined`?

- `undefined` → variable declared but no value assigned.
    
- `null` → intentionally assigned empty value.
    

---

### Q2. Why avoid `new Number()`?

Because it creates an **object**, not a primitive number, leading to unexpected behavior and unnecessary complexity.

---

### Q3. Why use template literals?

- Readable
    
- Supports `${}` interpolation
    
- Supports expressions
    
- Easier than string concatenation
    

---

### Q4. What is a Symbol?

A primitive type that creates a **unique identifier**, commonly used as unique property keys in objects.
