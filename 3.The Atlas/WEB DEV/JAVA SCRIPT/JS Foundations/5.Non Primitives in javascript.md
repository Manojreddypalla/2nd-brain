# JavaScript Non-Primitive Data Types

## 1. What are Non-Primitive Data Types?

Primitive values store **one single value**.

Example:

```js
let age = 20;
let name = "John";
```

Non-primitive values store **multiple values together**.

Examples:

- Objects
    
- Arrays
    
- Functions (later)
    

---

# 2. Objects

### Definition

An object stores data as **key-value pairs**.

```js
const user = {
    firstName: "John",
    isLoggedIn: true
};
```

Think of it like a student's record.

```
Student

Name  -> John
Age   -> 20
CGPA  -> 8.9
```

Every field has

```
Key  -> Value
```

---

# 3. Object Syntax

```
{
   key : value,
   key : value
}
```

Notice

- Curly braces `{ }`
    
- Colon `:`
    
- Comma `,`
    

Not

```
=
```

Inside objects we always use

```
:
```

---

# 4. Memory Model

Primitive

```
age

20
```

Object

```
user
 │
 ▼
 ----------------------
| firstName | "John"  |
| loggedIn  | true    |
 ----------------------
```

Variable stores a **reference (address)** to a larger memory block that contains all properties.

This is why objects are called **reference types**.

# 5. typeof Object

```js
const user = {};

console.log(typeof user);
```

Output

```
object
```

---

# 6. Accessing Properties

## Dot Notation

Most common.

```js
user.firstName
```

Output

```
John
```

---

## Bracket Notation

```js
user["firstName"]
```

Also returns

```
John
```

---

### When do we need brackets?

When property names contain spaces.

```js
const user = {
    "first name": "John"
};
```

Wrong

```js
user.first name
```

Correct

```js
user["first name"]
```

---

# 7. Updating Object

Objects are mutable.

```js
user.firstName = "Alex";
```

Memory stays same.

Only value changes.

---

# 8. Adding New Properties

```js
user.lastName = "Smith";
```

Now object becomes

```js
{
    firstName: "Alex",
    lastName: "Smith",
    isLoggedIn: true
}
```

Objects can grow dynamically.

---

# 9. const Object

```js
const user = {
    name: "John"
};
```

This is allowed

```js
user.name = "Alex";
```

This is NOT

```js
user = {};
```

Why?

Because

```
const
↓

Reference cannot change

↓

Object contents CAN change
```

# 10. Arrays

Array = Collection of values.

```js
const heroes = [
    "Ironman",
    "Batman",
    "Spiderman"
];
```

Uses

```
[]
```

instead of

```
{}
```

---

# 11. Arrays Can Store Mixed Types

```js
const arr = [
    "John",
    true,
    25,
    null
];
```

Unlike many languages, JavaScript arrays can mix data types.

---

# 12. Array Indexing

Starts from **0**

```
Index

0
1
2
3
```

Example

```js
heroes[0]
```

Returns

```
Ironman
```

---

# 13. Object vs Array

|Object|Array|
|---|---|
|Key → Value|Index → Value|
|Uses `{}`|Uses `[]`|
|Access with key|Access with index|
|Best for describing things|Best for ordered collections|

Example

Object

```js
{
    name:"John",
    age:20
}
```

Array

```js
[
    "John",
    20
]
```

# 14. Implicit Type Conversion

JavaScript automatically converts types sometimes.

Example

```js
1 + "1"
```

Output

```
"11"
```

Because

```
Number
↓

String

↓

Concatenation
```

---

Example

```js
true + 1
```

Output

```
2
```

Because

```
true

↓

1

↓

1+1

↓

2
```

# 19. Dynamic Typing

JavaScript is **dynamically typed**.

```js
let x = 10;

x = "Hello";

x = true;
```

All valid.

The variable's type is determined at runtime, not fixed at compile time.

---

# 20. Key Takeaways

- ✅ Non-primitive types store collections of data.
    
- ✅ Objects store **key-value pairs**.
    
- ✅ Arrays store **ordered values using indexes**.
    
- ✅ Objects are **reference types**.
    
- ✅ `const` prevents changing the **reference**, not the object's contents.
    
- ✅ Use **dot notation** for normal properties.
    
- ✅ Use **bracket notation** for property names with spaces or dynamic keys.
    
- ✅ Arrays start indexing at **0**.
    
- ✅ JavaScript performs **implicit type conversion**, which can produce surprising results.
    
- ✅ Prefer **explicit conversions** (`Number()`, `String()`, `Boolean()`) when you need predictable behavior.
    

### Quick Cheat Sheet

```js
// Object
const user = {
    name: "John",
    age: 20
};

user.name;          // Dot notation
user["name"];       // Bracket notation
user.age = 21;      // Update
user.city = "NY";   // Add property

// Array
const arr = ["A", "B", "C"];
arr[0];             // "A"

// Type Conversion
Number("25");       // 25
Number(true);       // 1
Number(false);      // 0
Number(null);       // 0
Number(undefined);  // NaN

typeof {};          // "object"
typeof [];          // "object"
typeof NaN;         // "number"
```
