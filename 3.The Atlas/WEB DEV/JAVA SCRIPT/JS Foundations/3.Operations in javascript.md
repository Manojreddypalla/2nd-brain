# 📘 JavaScript Notes – Operators & Operations

## 🧠 What are Operators?

Operators perform calculations or comparisons on values.

```text
Operand  Operator  Operand

   5         +        3
```

Result:

```text
8
```

---

# ➕ Arithmetic Operators

|Operator|Meaning|Example|Result|
|---|---|---|---|
|`+`|Addition|`5 + 3`|`8`|
|`-`|Subtraction|`9 - 4`|`5`|
|`*`|Multiplication|`4 * 6`|`24`|
|`/`|Division|`10 / 2`|`5`|
|`%`|Remainder (Modulo)|`9 % 2`|`1`|
|`**`|Exponent (Power)|`2 ** 3`|`8`|

---

## Example

```javascript
let score = 102;
let bonus = 25;

let totalScore = score + bonus;

console.log(totalScore);
```

Output

```text
127
```

---

# 📌 Modulo (`%`)

Returns the **remainder**, **not percentage**.

```javascript
9 % 2
```

Division

```text
9 ÷ 2 = 4 remainder 1
```

Output

```text
1
```

### Common Uses

- Check even/odd numbers
    

```javascript
num % 2 === 0
```

- Circular indexing
    
- Game loops
    
- Hashing
    

---

# 🚀 Exponent Operator

```javascript
2 ** 4
```

Means

```text
2 × 2 × 2 × 2
```

Output

```text
16
```

---

# ➕ Increment

Increase by **1**

```javascript
let score = 100;

score++;
```

Now

```text
101
```

Equivalent to

```javascript
score = score + 1;
```

---

# ➖ Decrement

Decrease by **1**

```javascript
let lives = 5;

lives--;
```

Now

```text
4
```

Equivalent to

```javascript
lives = lives - 1;
```

---

# ⚖️ Comparison Operators

Comparison always returns a **Boolean**.

```text
true
false
```

---

| Operator | Meaning               |
| -------- | --------------------- |
| `==`     | Equal                 |
| `!=`     | Not Equal             |
| `>`      | Greater Than          |
| `<`      | Less Than             |
| `>=`     | Greater Than or Equal |
| `<=`     | Less Than or Equal    |

---

## Examples

```javascript
3 == 3
```

Output

```text
true
```

---

```javascript
3 != 6
```

Output

```text
true
```

---

```javascript
5 > 2
```

Output

```text
true
```

---

```javascript
5 < 2
```

Output

```text
false
```

# ⚠️ Assignment vs Comparison

Assignment

```javascript

```

Stores a value.

```javascript

```

---

Comparison

```javascript
==
```

Checks equality.

```javascript
10 == 10
```

Output

```text

```

# 🧠 Logical Operators

Used to combine Boolean values.

---

## AND (`&&`)

Both conditions must be **true**.

```javascript
true && true
```

Output

```text
true
```

---

```javascript
true && false
```

Output

```text
false
```

### Example

```javascript
let isLoggedIn = true;
let isPaid = true;

console.log(isLoggedIn && isPaid);
```

Output

```text
true
```

---

## OR (`||`)

Only **one** condition needs to be true.

```javascript
true || false
```

Output

```text
true
```

---

Example

```javascript
let emailUser = true;
let googleUser = false;

console.log(emailUser || googleUser);
```

Output

```text
true
```

---

## NOT (`!`)

Reverses a Boolean.

```javascript
!true
```

Output

```text
false
```

---

```javascript
!false
```

Output

```text
true
```

# 📚 Operator Precedence

JavaScript follows mathematical order.

```text
()
**
* /
+ -
```

---

Instead of writing

```javascript
2 * 3 + 2 - 1
```

Prefer

```javascript
(2 * 3) + (2 - 1)
```

Or even better

```javascript
((2 * 3) + 2) - 1
```

✅ Parentheses make code easier to read and reduce mistakes.

# 🚀 Quick Revision

- `+` → Add
    
- `-` → Subtract
    
- `*` → Multiply
    
- `/` → Divide
    
- `%` → Remainder
    
- `**` → Power
    
- `++` → Increment by 1
    
- `--` → Decrement by 1
    
- `=` → Assign value
    
- `==` → Compare values
    
- `!=` → Not equal
    
- `&&` → Both conditions must be true
    
- `||` → At least one condition must be true
    
- `!` → Reverse Boolean
    
- `+=`, `-=`, `*=`, `/=`, `%=` → Shorthand assignment
    
- Use **parentheses** to make expressions clear and avoid relying on operator precedence.
