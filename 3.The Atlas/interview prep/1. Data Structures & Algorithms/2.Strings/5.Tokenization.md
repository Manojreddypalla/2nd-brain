## Definition

**Tokenization** is the process of **splitting a string into smaller parts (tokens)** based on a delimiter.

> **Think:** Break one sentence into multiple words.

---

# Examples

Input

```text
"I love C++ programming"
```

Output

```text

C++

programming
```

---

Input

```text
"apple,banana,mango"
```

Delimiter

```text
,
```

Output

```text
apple

banana

mango
```

# Approach 1: stringstream ⭐⭐⭐⭐⭐ (Most Preferred)

## Idea

`stringstream` reads words separated by whitespace.

Need

```cpp
#include <sstream>
```

---

## Code

```cpp
#include <iostream>
#include <sstream>
using namespace std;

int main()
{
    string s = "I love C++ programming";

    stringstream ss(s);

    string word;

    while(ss >> word)
    {
        cout << word << endl;
    }
}
```

Output

```text
I
love
C++
programming
```

# Approach 2: getline() with Custom Delimiter ⭐⭐⭐⭐⭐

Useful when delimiter is **not space**.

Example

```text
apple,banana,mango
```

Delimiter

```text
,
```

---

## Code

```cpp
#include <iostream>
#include <sstream>
using namespace std;

int main()
{
    string s = "apple,banana,mango";

    stringstream ss(s);

    string token;

    while(getline(ss, token, ','))
    {
        cout << token << endl;
    }
}
```

Output

```text
apple
banana
mango
```

# Approach 3: Manual Traversal ⭐⭐⭐⭐☆

Useful when you don't want to use STL.

---

## Code

```cpp
#include <iostream>
#include <vector>
using namespace std;

vector<string> tokenize(string s)
{
    vector<string> tokens;
    string word = "";

    for(char c : s)
    {
        if(c == ' ')
        {
            if(!word.empty())
            {
                tokens.push_back(word);
                word = "";
            }
        }
        else
        {
            word += c;
        }
    }

    if(!word.empty())
        tokens.push_back(word);

    return tokens;
}
```

# Approach 4: strtok() (C Style)

Need

```cpp
#include <cstring>
```

---

## Code

```cpp
char str[] = "apple,banana,mango";

char *token = strtok(str, ",");

while(token != NULL)
{
    cout << token << endl;
    token = strtok(NULL, ",");
}
```

⚠️ **Note:** `strtok()` modifies the original string and is generally **not recommended** in modern C++ interviews.

# Common Mistakes

## Using `cin >>`

Wrong

```cpp
cin >> s;
```

Input

```text
I love C++
```

Output

```text
I
```

Use

```cpp
getline(cin, s);
```

to read the whole line.

---

## Forgetting Last Token

Wrong

```cpp
for(...)
{
    ...
}
```

Always push the final token after the loop (manual approach).

---

## Using `strtok()` on `std::string`

Wrong

```cpp
string s="abc";

strtok(s,",");
```

`strtok()` only works with **C-style character arrays (`char[]`)**.

# Common Interview Questions

### Q1. Best way to split by spaces?

```cpp
stringstream
```

---

### Q2. Best way to split by commas?

```cpp
getline(ss, token, ',');
```

---

### Q3. Can `stringstream` parse integers?

Yes.

```cpp
stringstream ss("10 20 30");

int x;

while(ss >> x)
{
    cout << x << endl;
}
```

Output

```text
10
20
30
```

---

### Q4. Time Complexity?

```text
O(N)
```

Every character is processed once.

---

### Q5. Space Complexity?

```text
O(N)
```

To store the extracted tokens.

---

### Q6. Why avoid `strtok()`?

- Modifies the original string.
    
- Not thread-safe.
    
- Legacy C function.
    
- `stringstream` is preferred in modern C++.
    

---

# Time & Space Complexity

|Approach|Time|Space|
|---|---|---|
|`stringstream`|`O(N)`|`O(N)`|
|`getline()` + delimiter|`O(N)`|`O(N)`|
|Manual Traversal|`O(N)`|`O(N)`|
|`strtok()`|`O(N)`|`O(1)`*|

> *`strtok()` modifies the input string instead of allocating a new one.

---

# Interview Summary

- **Tokenization** means splitting a string into smaller parts using a delimiter.
    
- For **space-separated words**, use **`stringstream`**.
    
- For **custom delimiters** (`,` `;` `:` etc.), use **`getline()` with a delimiter**.
    
- Manual traversal gives the most control and is useful in custom parsing problems.
    
- Avoid **`strtok()`** in modern C++ unless the interviewer specifically asks about C-style strings.
