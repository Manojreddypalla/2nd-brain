## Definition

**Frequency Count** means counting **how many times each character appears** in a string.

> **Think:** Instead of remembering the order of characters, keep track of **how many times each one occurs**.

---

# Examples

Input

```text
banana
```

Output

```text
a → 3

b → 1

n → 2
```

---

Input

```text
aabccddd
```

Output

```text

b → 1

c → 2

d → 3
```

# Approach 1: Frequency Array ⭐⭐⭐⭐⭐ (Best for Lowercase Letters)

## Idea

Create an array of size **26**.

Each index stores the frequency of one character.

```text
Index

0 1 2 ... 25

↓

a b c ... z
```

---

## Algorithm

For every character

```text
freq[c-'a']++
```

---

## Code

```cpp
#include <iostream>
using namespace std;

void frequencyCount(string s)
{
    int freq[26] = {0};

    for(char c : s)
    {
        freq[c - 'a']++;
    }

    for(int i = 0; i < 26; i++)
    {
        if(freq[i] > 0)
            cout << char(i + 'a') << " : " << freq[i] << endl;
    }
}
```

# Approach 2: HashMap ⭐⭐⭐⭐⭐ (Most General)

Works for

- Uppercase
    
- Lowercase
    
- Digits
    
- Symbols
    
- Unicode (with appropriate key types)
    

---

## Code

```cpp
#include <unordered_map>
using namespace std;

void frequencyCount(string s)
{
    unordered_map<char,int> freq;

    for(char c : s)
        freq[c]++;

    for(auto it : freq)
        cout << it.first << " : " << it.second << endl;
}
```

# Approach 3: Ordered Map

If output should be sorted.


# Frequency Count (Uppercase + Lowercase)

If case-sensitive:

```cpp
unordered_map<char,int> freq;
```

If case-insensitive:

```cpp
transform(s.begin(),
          s.end(),
          s.begin(),
          ::tolower);
```

Then count normally.

---

# Frequency of One Character

Instead of counting everything:

```cpp
count(s.begin(), s.end(), 'a');
```

Example

```cpp
string s="banana";

cout<<count(s.begin(),s.end(),'a');
```

Output

```text
3
```

Need

```cpp
#include <algorithm>
```

# ASCII Frequency

For all ASCII characters (0–255):

```cpp
int freq[256]={0};

for(char c:s)
    freq[(unsigned char)c]++;
```

Useful when input isn't restricted to lowercase letters.

---

# Common Mistakes

## Wrong Index

Wrong

```cpp
freq[c]++;
```

Correct

```cpp
freq[c-'a']++;
```

(for lowercase letters)

---

## Assuming Only Lowercase

Input

```text
Hello
```

Frequency array of size 26 won't work correctly unless you normalize the input or use a larger array/HashMap.

---

## Forgetting Initialization

Wrong

```cpp
int freq[26];
```

Correct

```cpp
int freq[26]={0};
```

# Common Interview Questions

### Q1. Best solution for lowercase letters?

**Frequency Array**

```cpp
int freq[26]={0};
```

---

### Q2. Best solution for all characters?

```cpp
unordered_map<char,int>
```

---

### Q3. Time Complexity?

```text
O(N)
```

---

### Q4. Space Complexity?

Frequency Array

```text
O(1)
```

(HashMap)

```text
O(K)
```

where **K = unique characters**.

---

### Q5. Why use `c-'a'`?

Maps

```text
'a' → 0

'b' → 1

...

'z' → 25
```

---

### Q6. Can STL count one character directly?

Yes.

```cpp
count(s.begin(), s.end(), 'a');
```

---

# Time & Space Complexity

|Approach|Time|Space|
|---|---|---|
|Frequency Array (26 letters)|`O(N)`|`O(1)`|
|ASCII Array (256 chars)|`O(N)`|`O(1)`|
|`unordered_map`|`O(N)` average|`O(K)`|
|`map`|`O(N log K)`|`O(K)`|
|`count()` (single character)|`O(N)`|`O(1)`|

---

# Interview Summary

- **Frequency Count** counts how many times each character appears in a string.
    
- For **lowercase English letters**, use a **26-element frequency array** for the fastest and simplest solution.
    
- For **general input** (uppercase, digits, symbols), use an **`unordered_map<char, int>`**.
    
- Use `count()` when you only need the frequency of a **single character**.
    
- Frequency counting is a core technique used in **Anagrams**, **Hashing**, **Sliding Window**, and many other string interview problems.
