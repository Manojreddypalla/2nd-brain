# Definition

A **Trie (Pronounced: "Try")** is a **tree-like data structure** used to efficiently store and search strings, especially when many strings share common prefixes.

> **Think:** A Trie is like a dictionary where every character is a node.

---

# Why Trie?

Suppose we store

```text
cat
car
care
can
dog
```

Instead of storing each word separately, Trie shares the common prefix.

```text
           Root
          /    \
         c      d
         |      |
         a      o
      /  |  \    |
     t   r   n   g
         |
         e
```

Notice

```text
cat

car

care

can
```

all share

```text
c → a
```

This saves memory and speeds up searching.

# C++ Structure

```cpp
struct TrieNode
{
    TrieNode* children[26];

    bool isEnd;

    TrieNode()
    {
        isEnd = false;

        for(int i=0;i<26;i++)
            children[i]=NULL;
    }
};
```

---

# Trie Class

```cpp

↓

↓

```

---

## Code

```cpp
void insert(string word)
{
    TrieNode* current = root;

    for(char c : word)
    {
        int index = c - 'a';

        if(current->children[index] == NULL)
            current->children[index] = new TrieNode();

        current = current->children[index];
    }

    current->isEnd = true;
}
```

# Operation 2 — Search ⭐⭐⭐⭐⭐

Idea

Move character by character.

If any node is missing

↓

Word doesn't exist.

If all characters are found

↓

Check

```text
isEnd
```

---

## Code

```cpp
bool search(string word)
{
    TrieNode* current = root;

    for(char c : word)
    {
        int index = c - 'a';

        if(current->children[index] == NULL)
            return false;

        current = current->children[index];
    }

    return current->isEnd;
}
```

# Complete Trie Class

```cpp
class TrieNode
{
public:
    TrieNode* children[26];
    bool isEnd;

    TrieNode()
    {
        isEnd = false;

        for(int i=0;i<26;i++)
            children[i]=NULL;
    }
};

class Trie
{
    TrieNode* root;

public:

    Trie()
    {
        root=new TrieNode();
    }

    void insert(string word)
    {
        TrieNode* current=root;

        for(char c:word)
        {
            int index=c-'a';

            if(current->children[index]==NULL)
                current->children[index]=new TrieNode();

            current=current->children[index];
        }

        current->isEnd=true;
    }

    bool search(string word)
    {
        TrieNode* current=root;

        for(char c:word)
        {
            int index=c-'a';

            if(current->children[index]==NULL)
                return false;

            current=current->children[index];
        }

        return current->isEnd;
    }

    bool startsWith(string prefix)
    {
        TrieNode* current=root;

        for(char c:prefix)
        {
            int index=c-'a';

            if(current->children[index]==NULL)
                return false;

            current=current->children[index];
        }

        return true;
    }
};
```

# Complexity

|Operation|Time|Space|
|---|---|---|
|Insert|O(L)|O(L)|
|Search|O(L)|O(1)|
|StartsWith|O(L)|O(1)|

where

```text
L = Length of word
```

---

# Advantages

- Very fast prefix search
    
- Fast insertion
    
- Fast lookup
    
- Shared prefixes save memory
    
- Excellent for autocomplete
    

---

# Disadvantages

- Higher memory usage due to child pointers.
    
- Standard implementation assumes a fixed alphabet (e.g., 26 lowercase letters).
    
- More complex than a `map` or `unordered_map` for simple lookups.

# Common Interview Questions

### Q1. What is a Trie?

A tree-based data structure used for storing and searching strings efficiently by their prefixes.

---

### Q2. Why use Trie instead of HashMap?

|HashMap|Trie|
|---|---|
|Exact search|Exact + Prefix search|
|No autocomplete|Supports autocomplete|
|No shared prefixes|Shares common prefixes|

---

### Q3. Time Complexity?

```text
Insert      O(L)

Search      O(L)

StartsWith  O(L)
```

---

### Q4. What is `isEnd`?

Marks whether a node represents the **end of a complete word**.

Example:

- `app` inserted → `p.isEnd = true`
    
- `apple` inserted → `e.isEnd = true`
    

---

### Q5. Can Trie store duplicate words?

Yes, but the basic implementation doesn't count duplicates. To support duplicates, store an additional integer like:

```cpp
int wordCount;
```

---

### Q6. Can Trie support uppercase or digits?

Yes. You can:

- Increase the child array size (e.g., 52 or 128).
    
- Or replace the fixed array with:
    

```cpp
unordered_map<char, TrieNode*> children;
```

# Interview Summary

- A **Trie** (Prefix Tree) stores strings one character at a time.
    
- Common prefixes are shared, making prefix operations efficient.
    
- The three core operations are:
    
    - `insert(word)` → Add a word.
        
    - `search(word)` → Check if a complete word exists.
        
    - `startsWith(prefix)` → Check if any word starts with a prefix.
        
- Each operation runs in **O(L)** time, where **L** is the length of the input string.
    
- Tries are the preferred data structure for **autocomplete**, **dictionary lookups**, **spell checkers**, and **prefix-based searching**.
