# Arrays — Merge Arrays

## Definition

**Merge Arrays** means **combining two arrays into one**.

In interviews, it usually refers to **merging two sorted arrays into one sorted array**.

> **Think:** Compare the smallest remaining element from both arrays and place the smaller one into the result.

---

# Why Merge Arrays?

Used in:

- Merge Sort
    
- External Sorting
    
- Database Systems
    
- Data Processing
    
- Two Pointer Problems
    
- Interview Questions
    

---

# Problem Statement

Given

```text
Array 1

1 3 5 7

Array 2

2 4 6 8
```

Merge them into

```text
1 2 3 4 5 6 7 8
```

---

# Brute Force Approach

1. Copy both arrays into a third array.
    
2. Sort the third array.
    

```cpp
#include <algorithm>
#include <vector>
using namespace std;

vector<int> mergeArrays(vector<int>& a, vector<int>& b)
{
    vector<int> ans;

    for(int x : a)
        ans.push_back(x);

    for(int x : b)
        ans.push_back(x);

    sort(ans.begin(), ans.end());

    return ans;
}
```

### Time Complexity

```text
O((N + M) log(N + M))
```

### Space Complexity

```text
O(N + M)
```

---

# Optimal Approach (Two Pointers)

Maintain

```text
i → Array 1

j → Array 2
```

Compare

```text
a[i]

and

b[j]
```

Insert the smaller element and move its pointer.

---

# Algorithm

```text
Compare

1 and 2

↓

1 is smaller

↓

Store 1

↓

Move i

↓

Compare

3 and 2

↓

Store 2

↓

Move j
```

Continue until one array finishes.

---

# Code

```cpp
#include <vector>
using namespace std;

vector<int> mergeArrays(vector<int>& a, vector<int>& b)
{
    int i = 0;
    int j = 0;

    vector<int> ans;

    while(i < a.size() && j < b.size())
    {
        if(a[i] <= b[j])
        {
            ans.push_back(a[i]);
            i++;
        }
        else
        {
            ans.push_back(b[j]);
            j++;
        }
    }

    while(i < a.size())
    {
        ans.push_back(a[i]);
        i++;
    }

    while(j < b.size())
    {
        ans.push_back(b[j]);
        j++;
    }

    return ans;
}
```

# In-Place Merge (Advanced)

Sometimes interviewers ask:

```text
Merge two sorted arrays

Without extra space
```

Common methods:

- Gap Algorithm (Shell Sort idea)
    
- Swapping + Sorting
    
- STL (`std::inplace_merge`) when applicable
    

These are advanced variations.

# Common Mistakes

## Forgetting Remaining Elements

Wrong

```cpp
while(i < n && j < m)
```

Loop ends when one array finishes.

Need

```cpp
while(i < n)
```

and

```cpp
while(j < m)
```

to copy leftover elements.

---

## Using Wrong Comparison

Wrong

```cpp
if(a[i] < b[j])
```

Better

```cpp
if(a[i] <= b[j])
```

This preserves the order of equal elements (stable merge).

---

## Not Handling Empty Arrays

```cpp
A = {}

B = {1,2,3}
```

Should still return

```text
1 2 3
```

# Common Interview Questions

### Q1. What is the optimal approach?

**Two Pointers**

---

### Q2. Why use Two Pointers?

Because both arrays are already sorted, allowing us to process each element only once.

---

### Q3. What is the time complexity?

```text
O(N + M)
```

Every element is visited exactly once.

---

### Q4. What is the space complexity?

```text
O(N + M)
```

For the merged output array.

---

### Q5. Can merge be done in-place?

Yes.

Using algorithms like:

- Gap Algorithm
    
- `std::inplace_merge` (for contiguous sorted ranges)
    
- Other in-place merge techniques
    

---

### Q6. Where is merge used?

- Merge Sort
    
- External Sorting
    
- Database joins
    
- Data stream processing
    
- Many interval and two-pointer problems
    

---

# Interview Summary

- **Merge Arrays** usually refers to merging **two sorted arrays**.
    
- The brute-force approach copies and sorts the combined array.
    
- The optimal solution uses the **Two Pointer** technique:
    
    - Compare current elements.
        
    - Insert the smaller one.
        
    - Move its pointer.
        
- Always remember to copy the remaining elements after one array is exhausted.
    
- The optimal solution runs in **`O(N + M)`** time and is a fundamental building block of **Merge Sort**.
