# Arrays — Sliding Window

## Definition

The **Sliding Window** technique is an optimization used to solve problems involving **contiguous subarrays or substrings** by maintaining a window and moving it across the array instead of recalculating everything.

> **Think:** Instead of recomputing every subarray, **slide the current window** by removing one element and adding the next.

---

# Why Sliding Window?

Used in:

- Maximum/Minimum Sum Subarray
    
- Longest Substring
    
- Fixed Size Window Problems
    
- Variable Size Window Problems
    
- String Problems
    
- Interview Questions
    

---

# Types of Sliding Window

## 1. Fixed Size Window

Window size is fixed.

Example

```text
Window Size = 3
```

---

## 2. Variable Size Window

Window expands and shrinks based on a condition.

Example

```text
Longest Subarray

Sum ≤ K

Unique Characters

At Most K Distinct
```

---

# Problem Statement (Fixed Window)

Given

```text
Array

2 1 5 1 3 2

K = 3
```

Find the **maximum sum of any subarray of size 3**.

Answer

```text
5 1 3

Sum = 9
```

---

# Brute Force Approach

Check every subarray of size `k`.

```cpp
int ans = INT_MIN;

for(int i = 0; i <= n - k; i++)
{
    int sum = 0;

    for(int j = i; j < i + k; j++)
    {
        sum += arr[j];
    }

    ans = max(ans, sum);
}
```

### Time Complexity

```text
O(N × K)
```

---

# Optimal Approach (Sliding Window)

### Idea

Compute the first window.

Then

```text
Remove Left Element

+

Add Right Element
```

instead of recalculating the entire sum.

---

# Algorithm

```text
Current Window

↓

Subtract outgoing element

↓

Add incoming element

↓

Update Answer
```

---

# Code (Fixed Size Window)

```cpp
#include <climits>
using namespace std;

int maxSumSubarray(int arr[], int n, int k)
{
    int windowSum = 0;

    for(int i = 0; i < k; i++)
        windowSum += arr[i];

    int maxSum = windowSum;

    for(int i = k; i < n; i++)
    {
        windowSum += arr[i];
        windowSum -= arr[i - k];

        maxSum = max(maxSum, windowSum);
    }

    return maxSum;
}
```

# Variable Size Sliding Window

Example

```text
Longest Subarray

Sum ≤ K
```

Maintain two pointers.

```text
left

right
```

Expand

```text
right++
```

Shrink

```text
left++
```

until the condition becomes valid again.

---

# Generic Variable Window Template

```cpp
int left = 0;

for(int right = 0; right < n; right++)
{
    // Expand window

    while(/* window invalid */)
    {
        // Shrink window
        left++;
    }

    // Update answer
}
```

# Common Mistakes

## Recomputing Every Window

Wrong

```cpp
Calculate sum again
```

Correct

```text
Old Sum

-

Outgoing

+

Incoming
```

---

## Wrong Window Size

Window becomes valid only after it contains exactly `k` elements (for fixed-size problems).

---

## Forgetting to Remove the Left Element

Wrong

```cpp
windowSum += arr[i];
```

Correct

```cpp
windowSum += arr[i];
windowSum -= arr[i - k];
```

# Common Interview Questions

### Q1. What is Sliding Window?

An optimization technique for contiguous subarray/substring problems that updates results by moving a window instead of recomputing everything.

---

### Q2. When should you use Sliding Window?

When the problem involves **contiguous** elements or substrings.

---

### Q3. Difference between Fixed and Variable Window?

|Fixed Window|Variable Window|
|---|---|
|Window size remains constant|Window size changes based on a condition|

---

### Q4. What is the time complexity?

```text
O(N)
```

Each element enters and leaves the window at most once.

---

### Q5. What is the space complexity?

```text
O(1)
```

Only a few variables are used.

---

### Q6. How do you recognize a Sliding Window problem?

Look for keywords like:

- Contiguous Subarray
    
- Contiguous Substring
    
- Window of Size K
    
- Longest
    
- Shortest
    
- Maximum
    
- Minimum
    

---

# Interview Summary

- **Sliding Window** is an optimization for **contiguous** subarray or substring problems.
    
- There are **two types**:
    
    - **Fixed Size Window** → window size is constant.
        
    - **Variable Size Window** → window expands and shrinks based on a condition.
        
- Instead of recalculating each window, update it by:
    
    - **Subtracting** the outgoing element.
        
    - **Adding** the incoming element.
        
- The technique reduces many brute-force solutions from **`O(N × K)`** to **`O(N)`**.
    
- Sliding Window is one of the **most important interview patterns** for arrays and strings.
