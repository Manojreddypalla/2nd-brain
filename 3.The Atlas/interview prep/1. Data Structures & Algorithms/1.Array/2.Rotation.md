# Arrays — Rotation

## Definition

**Array Rotation** means shifting the elements of an array **left** or **right** by `k` positions.

> **Think:** Elements move in a circular manner. Elements going out from one end reappear at the other end.

---

# Why Rotation?

Used in:

- Circular Buffers
    
- Scheduling Algorithms
    
- Cryptography
    
- Game Development
    
- Interview Problems
    
- Rotated Sorted Arrays
    

---

# Left Rotation

Rotate left by **1**

Original

```text
1 2 3 4 5
```

After Rotation

```text
2 3 4 5 1
```

Each element moves one position to the left.

---

# Right Rotation

Rotate right by **1**

Original

```text
1 2 3 4 5
```

After Rotation

```text
5 1 2 3 4
```

Each element moves one position to the right.

# Brute Force Approach (Extra Array)

### Left Rotation

```cpp
#include <iostream>
using namespace std;

void leftRotate(int arr[], int n, int k)
{
    int temp[n];

    k %= n;

    for(int i = 0; i < n; i++)
        temp[i] = arr[(i + k) % n];

    for(int i = 0; i < n; i++)
        arr[i] = temp[i];
}
```

### Time Complexity

```text
O(N)
```

### Space Complexity

```text
O(N)
```

---

# Optimal Approach — Reversal Algorithm

Most asked in interviews.

### Left Rotation

Steps:

```text
Reverse first k elements

↓

Reverse remaining elements

↓

Reverse entire array
```

Example

```text
1 2 3 4 5 6 7

k = 2

↓

2 1 3 4 5 6 7

↓

2 1 7 6 5 4 3

↓

3 4 5 6 7 1 2
```

---

### Code

```cpp
#include <algorithm>
using namespace std;

void leftRotate(int arr[], int n, int k)
{
    k %= n;

    reverse(arr, arr + k);
    reverse(arr + k, arr + n);
    reverse(arr, arr + n);
}
```

---

# Right Rotation using Reversal

Steps

```text
Reverse entire array

↓

Reverse first k

↓

Reverse remaining
```

Example

```text
1 2 3 4 5 6 7

↓

7 6 5 4 3 2 1

↓

6 7 5 4 3 2 1

↓

6 7 1 2 3 4 5
```

---

### Code

```cpp
#include <algorithm>
using namespace std;

void rightRotate(int arr[], int n, int k)
{
    k %= n;

    reverse(arr, arr + n);
    reverse(arr, arr + k);
    reverse(arr + k, arr + n);
}
```

---

# Juggling Algorithm (Advanced)

Uses the **GCD (Greatest Common Divisor)** to rotate elements in cycles.

- Time: **O(N)**
    
- Space: **O(1)**
    

Mostly asked in advanced interviews.

---

# Handling Large K

If

```text
N = 5

K = 12
```

Then

```text
K = K % N

12 % 5 = 2
```

Rotate only **2** times.

Always do

```cpp
k %= n;
```

---

# Common Mistakes

## Forgetting Modulo

Wrong

```cpp
k = 12;
```

Correct

```cpp
k %= n;
```

---

## Using Wrong Reverse Order

Left Rotation

```text
First K

↓

Remaining

↓

Entire Array
```

Right Rotation

```text
Entire Array

↓

First K

↓

Remaining
```

Don't confuse the two.

---

## Not Handling Empty Arrays

```cpp
if(n == 0)
    return;
```

Avoid division by zero when computing `k % n`.

# Common Interview Questions

### Q1. What is array rotation?

Shifting array elements left or right while wrapping around the ends.

---

### Q2. Why do we use `k %= n`?

Rotating by `n` or any multiple of `n` returns the original array, so only the remainder matters.

---

### Q3. Which is the best approach?

The **Reversal Algorithm**.

- Time: **O(N)**
    
- Space: **O(1)**
    

---

### Q4. Can rotation be done without extra memory?

Yes. The Reversal Algorithm and Juggling Algorithm both use **O(1)** auxiliary space.

---

### Q5. Difference between Left and Right Rotation?

|Left Rotation|Right Rotation|
|---|---|
|Elements move left|Elements move right|
|Front goes to end|End comes to front|

---

### Q6. Which algorithm is most commonly asked?

The **Reversal Algorithm** is by far the most common in coding interviews.

# Time & Space Complexity

|Approach|Time|Space|
|---|---|---|
|Rotate one step repeatedly|`O(N × K)`|`O(1)`|
|Extra Array|`O(N)`|`O(N)`|
|Reversal Algorithm|`O(N)`|`O(1)`|
|Juggling Algorithm|`O(N)`|`O(1)`|

---

# Interview Summary

- **Array Rotation** shifts elements left or right in a circular manner.
    
- Always reduce rotations with `k %= n`.
    
- The **Reversal Algorithm** is the preferred interview solution because it achieves **`O(N)` time** and **`O(1)` auxiliary space**.
    
- The **Juggling Algorithm** is another optimal approach but is less commonly expected.
    
- Be careful with the order of reversals and handle edge cases like `n == 0`.
