## Definition

**Operators** are symbols that perform operations on one or more operands (variables or values).

Example:

```cpp
int a = 10, b = 5;

int sum = a + b;
```

`+` is the operator, `a` and `b` are operands.

---

# Types of Operators

## 1. Arithmetic Operators

Used for mathematical calculations.

|Operator|Meaning|Example|
|---|---|---|
|+|Addition|a + b|
|-|Subtraction|a - b|
|*|Multiplication|a * b|
|/|Division|a / b|
|%|Modulus (Remainder)|a % b|

Example:

```cpp
int a = 10, b = 3;

cout << a + b;   //13
cout << a - b;   //7
cout << a * b;   //30
cout << a / b;   //3
cout << a % b;   //1
```

---

## Integer Division

```cpp
cout << 10 / 3;
```

Output

```
3
```

Because both operands are integers.

For decimal result:

```cpp
cout << 10.0 / 3;
```

Output

```
3.33333
```

---

## Modulus (%)

Returns the remainder.

```cpp
10 % 3 = 1

15 % 4 = 3

8 % 2 = 0
```

Interview Uses:

- Even/Odd check
    
- Circular indexing
    
- Hashing
    
- Clock problems
    

---

# 2. Relational (Comparison) Operators

Compare two values.

|Operator|Meaning|
|---|---|
|==|Equal|
|!=|Not Equal|
|>|Greater Than|
|<|Less Than|
|>=|Greater or Equal|
|<=|Less or Equal|

Example

```cpp
int a = 5, b = 10;

cout << (a < b);   //1 (true)
cout << (a == b);  //0 (false)
```

Returns a **bool** (`true` or `false`).

---

# 3. Logical Operators

Used to combine conditions.

|Operator|Meaning|
|---|---|
|&&|AND|
|\||OR|
|!|NOT|

Example

```cpp
int age = 20;

cout << (age > 18 && age < 30);
```

Output

```
true
```

---

### AND (&&)

Returns true only if **both** conditions are true.

```cpp
true && true = true

true && false = false

false && true = false

false && false = false
```

---

### OR (||)

Returns true if **at least one** condition is true.

```cpp
true || false = true

false || true = true

false || false = false
```

---

### NOT (!)

Reverses the result.

```cpp
!true = false

!false = true
```

---

# Short-Circuit Evaluation

C++ stops evaluating once the result is known.

Example

```cpp
if (a != 0 && b / a > 5)
```

If

```cpp
a == 0
```

Second condition is **never evaluated**, preventing division by zero.

This is a very common interview question.

# 4. Assignment Operators

|Operator|Meaning|
|---|---|
|=|Assign|
|+=|Add and Assign|
|-=|Subtract and Assign|
|*=|Multiply and Assign|
|/=|Divide and Assign|
|%=|Modulus and Assign|

Example

```cpp
int x = 5;

x += 3;   //8

x *= 2;   //16
```

Equivalent to

```cpp
x = x + 3;

x = x * 2;
```

# 5. Increment & Decrement

## Pre Increment

```cpp
++x
```

Increase first, then use.

```cpp
int x = 5;

cout << ++x;
```

Output

```
6
```

---

## Post Increment

```cpp
x++
```

Use first, then increase.

```cpp
int x = 5;

cout << x++;
```

Output

```
5
```

After statement

```
x = 6
```

---

## Memory Visualization

```cpp
int x = 5;

cout << x++;
```

Step 1

```
Print 5
```

Step 2

```
x becomes 6
```

---

## Pre vs Post

```cpp
int x = 5;

int a = ++x;
```

Result

```
x = 6

a = 6
```

---

```cpp
int x = 5;

int a = x++;
```

Result

```
x = 6

a = 5
```

# 6. Bitwise Operators

Operate directly on binary bits.

|Operator|Meaning|
|---|---|
|&|AND|
|\||OR|
|^|XOR|
|~|NOT|
|<<|Left Shift|
|>>|Right Shift|

Example

```cpp
5 = 0101

3 = 0011

5 & 3 = 0001 = 1

5 | 3 = 0111 = 7

5 ^ 3 = 0110 = 6
```

Very important in:

- DSA
    
- Competitive Programming
    
- System Programming
    
- Operating Systems
    

---

# 7. Ternary Operator

Shortcut for `if-else`.

Syntax

```cpp
condition ? value1 : value2;
```

Example

```cpp
int age = 20;

string result = (age >= 18) ? "Adult" : "Minor";
```

---

# 8. sizeof Operator

Returns memory occupied.

```cpp
cout << sizeof(int);
```

Usually

```
4
```

---

# 9. Comma Operator

Evaluates left expression first, returns the last expression.

```cpp
int x = (2, 5);

cout << x;
```

Output

```
5
```

Rarely used in interviews but good to know.

# Common Interview Questions

### Q1. Difference between `=` and `==`?

- `=` → Assignment
    
- `==` → Comparison
    

---

### Q2. Difference between `++i` and `i++`?

- `++i` increments first, then returns the value.
    
- `i++` returns the current value, then increments.
    

---

### Q3. Why is `%` useful?

- Even/Odd checking
    
- Cyclic arrays
    
- Hashing
    
- Number theory
    
- Digit extraction
    

---

### Q4. What is short-circuit evaluation?

The logical operators `&&` and `||` stop evaluating as soon as the final result is determined, improving efficiency and preventing errors like division by zero.

---

### Q5. Difference between Logical AND (`&&`) and Bitwise AND (`&`)?

- `&&` works on **boolean expressions** and short-circuits.
    
- `&` works on **individual bits** and always evaluates both operands.
    

Example:

```cpp
5 && 3   // true

5 & 3    // 1 (binary AND)
```

# Time & Space Complexity

All basic operator operations execute in:

- **Time:** `O(1)`
    
- **Space:** `O(1)`

## Interview Summary

- Arithmetic operators perform mathematical calculations.
    
- Relational operators compare values and return `bool`.
    
- Logical operators combine conditions and use short-circuit evaluation.
    
- Assignment operators update variables efficiently.
    
- Know the difference between **pre (`++i`)** and **post (`i++`)** increment.
    
- Understand basic bitwise operators—they're frequently used in DSA and systems interviews.
    
- The ternary operator is a concise `if-else`.
    
- `sizeof` returns the memory occupied by a type or variable.
    
- Remember common precedence rules, and prefer parentheses for clarity.
