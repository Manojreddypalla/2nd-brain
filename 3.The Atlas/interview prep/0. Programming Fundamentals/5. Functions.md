## Definition

A **function** is a reusable block of code that performs a specific task.

Instead of writing the same code multiple times, write it once and call it whenever needed.

---

# Why Use Functions?

- Code Reusability
    
- Better Readability
    
- Easier Debugging
    
- Modular Programming
    
- Reduces Code Duplication
    

---

# Function Syntax

```cpp
return_type function_name(parameters)
{
    // function body
}
```

Example

```cpp
int add(int a, int b)
{
    return a + b;
}
```

---

# Calling a Function

```cpp
int add(int a, int b)
{
    return a + b;
}

int main()
{
    int ans = add(5, 3);

    cout << ans;
}
```

Output

```
8
```

---

# How Function Calls Work (Memory)

```cpp
add(5, 3);
```

Memory Flow

```text
main()
   │
   ▼
Call add()
   │
Create new stack frame
   │
a = 5
b = 3
   │
return 8
   │
Destroy stack frame
   │
Back to main()
```

Every function call creates a **new stack frame** in memory.

# Pass by Value

A **copy** of the variable is passed.

```cpp
void change(int x)
{
    x = 100;
}

int main()
{
    int a = 10;

    change(a);

    cout << a;
}
```

Output

```
10
```

Original variable remains unchanged.

---

## Memory Visualization

```text
main()

a = 10
      │
      ▼
change()

x = 10 (copy)

x = 100
```

Only the copy changes.

---

# Pass by Reference

Uses the original variable.

```cpp
void change(int &x)
{
    x = 100;
}
```

```cpp
int a = 10;

change(a);

cout << a;
```

Output

```
100
```

---

## Memory Visualization

```text
main()

a = 10
 │
 └────────────┐
              ▼
change()

x → same memory as a

x = 100

a = 100
```

No copy is created.

---

# Why Pass by Reference?

- Faster for large objects
    
- Saves memory
    
- Can modify original data
    

Commonly used with:

- vector
    
- string
    
- class objects
    
- maps
    
- sets
    

---

# const Reference

Read-only reference.

```cpp
void print(const string &s)
{
    cout << s;
}
```

Advantages:

- No copying
    
- Faster
    
- Prevents modification
    

Very common in interviews.

# Function Overloading

Same function name

Different parameters.

```cpp
int add(int a, int b);

double add(double a, double b);

int add(int a, int b, int c);
```

Compiler decides which version to call based on the arguments.

---

# Inline Function

Suggests the compiler replace the function call with the function body.

```cpp
inline int square(int x)
{
    return x * x;
}
```

Useful only for **small** functions.

The compiler may ignore the `inline` keyword.

---

# Recursive Function

A function calling itself.

```cpp
int fact(int n)
{
    if(n == 0)
        return 1;

    return n * fact(n - 1);
}
```

---

# Function Call Stack

```cpp
fact(3)
```

```text
fact(3)
   │
fact(2)
   │
fact(1)
   │
fact(0)
```

Returns

```text
1

1 × 1

2 × 1

3 × 2 = 6
```

Each recursive call gets its **own stack frame**.

# Common Interview Questions

### Q1. Difference between parameter and argument?

- **Parameter** → Variable in the function definition.
    
- **Argument** → Actual value passed during the function call.
    

---

### Q2. Pass by Value vs Pass by Reference?

|Pass by Value|Pass by Reference|
|---|---|
|Copy created|No copy|
|Original unchanged|Original can change|
|More memory|Less memory|
|Slower for large objects|Faster|

---

### Q3. Why use `const &`?

- Avoids copying
    
- Improves performance
    
- Prevents accidental modification
    

---

### Q4. What is function overloading?

Multiple functions with the **same name** but **different parameter lists**.

---

### Q5. What happens during a function call?

- A new **stack frame** is created.
    
- Parameters are initialized.
    
- Function executes.
    
- Return value is sent back.
    
- Stack frame is destroyed.
    

---

### Q6. What is the difference between declaration and definition?

- **Declaration** tells the compiler a function exists.
    
- **Definition** provides the actual implementation.
    

---

### Q7. Can `main()` call itself?

Yes, technically it can in C++, but it is **not recommended** and leads to undefined or implementation-dependent behavior. Use normal recursion through other functions instead.

# Time & Space Complexity

Assume the function body takes constant time.

|Operation|Time|Space|
|---|---|---|
|Function Call|`O(1)`|`O(1)`|
|Pass by Value|`O(n)` for large objects (copy cost)|`O(n)`|
|Pass by Reference|`O(1)`|`O(1)`|
|Recursive Depth = N|`O(N)`|`O(N)` (call stack)|

---

# Interview Summary

- A function is a reusable block of code.
    
- Every function call creates a **new stack frame**.
    
- Know the difference between **declaration**, **definition**, and **function call**.
    
- Understand **parameters vs arguments**.
    
- Prefer **pass by reference** for large objects; use **`const &`** when modification isn't needed.
    
- Use **function overloading** for the same operation with different parameter types.
    
- `inline` is a compiler optimization hint for small functions.
    
- Local variables live only within a function; global variables are accessible throughout the program.
    
- Every recursive call has its own stack frame.
