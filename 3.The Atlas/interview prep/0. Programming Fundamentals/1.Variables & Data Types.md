## Definition

A **variable** is a named memory location used to store data.

A **data type** tells the compiler:

- How much memory to allocate
    
- What kind of value can be stored
    
- What operations are allowed
    

---

## Memory Example

```cpp
int age = 21;
```

```
Variable Name     Memory Address      Value
age              0x100               21
```

`age` is just a label pointing to a memory location.

## Declaration vs Initialization

```cpp
int a;      // Declaration
a = 10;     // Assignment

int b = 20; // Initialization
```

---

## Type Conversion

### Implicit

```cpp
int x = 5;
double y = x;
```

Compiler converts automatically.

---

### Explicit (Casting)

```cpp
double x = 5.8;

int y = (int)x;
// y = 5
```

---

## Integer Overflow

```cpp
int x = INT_MAX;
x++;
```

Result:

```
Overflow → Undefined Behavior
```

Use:

```cpp
long long
```

for large numbers.

---

## Signed vs Unsigned

```cpp
signed int a = -10;

unsigned int b = 10;
```

Unsigned stores only positive values.

## Interview Questions

**Q1. Difference between declaration and initialization?**

- Declaration → creates variable.
    
- Initialization → assigns initial value.
    

**Q2. Difference between float and double?**

- `double` has higher precision (8 bytes).
    
- `float` uses less memory (4 bytes).
    

**Q3. Why use `long long`?**

- To avoid integer overflow for large values.
    

**Q4. What is type casting?**

- Converting one data type into another.
    

**Q5. What is integer overflow?**

- When a value exceeds the storage limit of its type, causing incorrect or undefined results.
    

---

## Time & Space Complexity

Reading/Writing a variable:

- **Time:** `O(1)`
    
- **Space:** Depends on the data type (e.g., `int` ≈ 4 bytes, `double` ≈ 8 bytes).
