## Definition

A **loop** repeatedly executes a block of code **until a condition becomes false**.

Loops help avoid writing the same code multiple times.

---

# Types of Loops

There are **3 main loops** in C++:

- `for`
    
- `while`
    
- `do-while`
    

---

# 1. for Loop

Used when the **number of iterations is known**.

### Syntax

```cpp
for(initialization; condition; update)
{
    // code
}
```

Example

```cpp
for(int i = 1; i <= 5; i++)
{
    cout << i << " ";
}
```

Output

```
1 2 3 4 5
```

---

## How it Works

```text
Initialization
      ↓
 Condition?
   ↓     ↓
 Yes     No
 ↓        End
Execute
 ↓
Update
 ↓
Condition Again
```

---

# Memory Visualization

```cpp
for(int i = 1; i <= 3; i++)
```

Execution

```
i = 1 → Print 1

i = 2 → Print 2

i = 3 → Print 3

i = 4 → Condition False

```

---

# 2. while Loop

Used when the **number of iterations is unknown**.

### Syntax

```cpp
while(condition)
{
    // code
}
```

Example

```cpp
int i = 1;

while(i <= 5)
{
    cout << i << " ";
    i++;
}
```

Output

```
1 2 3 4 5
```

---

# 3. do-while Loop

Executes the body **at least once** because the condition is checked **after** execution.

### Syntax

```cpp
do
{
    // code
}
while(condition);
```

Example

```cpp
int i = 1;

do
{
    cout << i << " ";
    i++;
}
while(i <= 5);
```

Output

```
1 2 3 4 5
```

---

# Difference Between while and do-while

```cpp
int x = 10;

while(x < 5)
{
    cout << x;
}
```

Output

```
Nothing
```

---

```cpp
int x = 10;

do
{
    cout << x;
}
while(x < 5);
```

Output

```
10
```

Because `do-while` executes once before checking the condition.

# Infinite Loop

```cpp
while(true)
{
    // runs forever
}
```

or

```cpp
for(;;)
{
}
```

Used in:

- Servers
    
- Game loops
    
- Operating Systems
    

Must include a way to exit (e.g., `break`) when appropriate.

# Loop Control Statements

## break

Immediately exits the loop.

```cpp
for(int i = 1; i <= 10; i++)
{
    if(i == 5)
        break;

    cout << i << " ";
}
```

Output

```
1 2 3 4
```

---

## continue

Skips the current iteration and moves to the next.

```cpp
for(int i = 1; i <= 5; i++)
{
    if(i == 3)
        continue;

    cout << i << " ";
}
```

Output

```
1 2 4 5
```

---

# Nested Loops

A loop inside another loop.

```cpp
for(int i = 1; i <= 3; i++)
{
    for(int j = 1; j <= 3; j++)
    {
        cout << i << "," << j << "\n";
    }
}
```

Output

```
1,1
1,2
1,3
2,1
2,2
2,3
3,1
3,2
3,3
```

# Common Loop Patterns

## Count from 1 to N

```cpp
for(int i = 1; i <= n; i++)
```

---

## Reverse Loop

```cpp
for(int i = n; i >= 1; i--)
```

---

## Traverse an Array

```cpp
for(int i = 0; i < n; i++)
{
    cout << arr[i];
}
```

---

## Traverse a String

```cpp
for(char ch : str)
{
    cout << ch;
}
```

Range-based `for` loop (C++11).

---

## Sum of Numbers

```cpp
int sum = 0;

for(int i = 1; i <= n; i++)
{
    sum += i;
}
```

---

## Factorial

```cpp
int fact = 1;

for(int i = 1; i <= n; i++)
{
    fact *= i;
}
```

# Common Mistakes

## Off-by-One Error

Wrong

```cpp
for(int i = 0; i <= n; i++)
```

Correct (for arrays)

```cpp
for(int i = 0; i < n; i++)
```

Array indices go from `0` to `n-1`.

---

## Forgetting Update

```cpp
while(i <= 10)
{
    cout << i;
}
```

Results in an **infinite loop** because `i` never changes.

# Choosing the Right Loop

|Situation|Best Choice|
|---|---|
|Fixed number of iterations|`for`|
|Unknown number of iterations|`while`|
|Must execute at least once|`do-while`|
|Traverse containers|Range-based `for`|

# Common Interview Questions

### Q1. Difference between `for` and `while`?

- `for` is preferred when the iteration count is known.
    
- `while` is preferred when the stopping condition depends on runtime.
    

---

### Q2. Difference between `break` and `continue`?

- `break` exits the loop completely.
    
- `continue` skips the current iteration and proceeds to the next.
    

---

### Q3. Difference between `while` and `do-while`?

- `while` checks the condition before execution.
    
- `do-while` checks the condition after execution, so it always runs at least once.
    

---

### Q4. What is an infinite loop?

A loop whose condition never becomes false, causing it to run indefinitely.

---

### Q5. What is an off-by-one error?

A mistake where a loop runs **one iteration too many or too few**, often due to incorrect loop boundaries.

# Time & Space Complexity

Assume the loop body takes constant time.

|Loop|Time|Space|
|---|---|---|
|Single loop (N iterations)|`O(N)`|`O(1)`|
|Nested loop (N × N)|`O(N²)`|`O(1)`|
|Triple nested loop|`O(N³)`|`O(1)`|

---

# Interview Summary

- Loops execute code repeatedly until a condition fails.
    
- Use `for` when the number of iterations is known, `while` when it's unknown, and `do-while` when at least one execution is required.
    
- `break` exits a loop; `continue` skips the current iteration.
    
- Nested loops multiply time complexity.
    
- Be careful with **off-by-one errors** and **infinite loops**.
    
- Range-based `for` loops simplify traversal of arrays, strings, and containers.
