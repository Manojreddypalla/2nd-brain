00## 📅 Day 2 — Strings (3 Hours + Revision)

### 🎯 Goal

Master the fundamental string patterns and solve **6–8 problems**.

---

## 🕒 Deep Work (3 Hours)

### 1️⃣ Learn the Concepts (45 min)

- Reverse String
- Palindrome
- Character Frequency
- Valid Anagram
- Longest Common Prefix
- String Builder (`push_back`, `+=`, `append`)
- Character Arrays (`char[]` vs `string`)

---

### 2️⃣ Solve Problems (1 hr 45 min)

Solve in this order:

1. Reverse String
2. Valid Palindrome
3. Valid Anagram
4. First Unique Character in a String
5. Longest Common Prefix
6. Merge Strings Alternately
7. Reverse Words in a String _(optional)_
8. Isomorphic Strings _(optional)_

---

### 3️⃣ Revision (30 min)

Without notes:

- Explain every pattern aloud.
- Rewrite:
    - Reverse String
    - Anagram
    - Longest Common Prefix
- Make one-page notes.

---

# 🧠 DSA Maintenance (1–1.5 Hours)

- Trees – 15 min
- Graphs – 15 min
- Dynamic Programming – 15 min
- Linked List / Stack / Queue – 15 min
- Arrays & Binary Search – 15 min
- Solve **1 mixed revision problem** – 15–30 min

Focus on recalling:

- Core idea
- Time complexity
- Template/code from memory
- When to use the pattern
