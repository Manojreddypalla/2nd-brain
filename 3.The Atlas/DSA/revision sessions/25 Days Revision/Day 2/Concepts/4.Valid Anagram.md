# 📘 Valid Anagram

## Problem

Two strings are **anagrams** if they contain **exactly the same characters with the same frequency**, just in a different order.

### Examples

```
listen  -> silent   ✅

evil    -> vile     ✅

race    -> care     ✅

hello   -> world    ❌

rat     -> car      ❌
```

---

# 🤔 First Thought (Brute Force)

Suppose I give you:

```
listen
silent
```

You might think:

> "Let's compare character by character."

```
listen
silent
```

Immediately:

```
l != s
```

Does that mean it's not an anagram?

❌ No.

Order doesn't matter.

---

# 💡 Key Insight

Don't compare **positions**.

Compare **frequencies**.

Think like this:

```
listen

l → 1
i → 1
s → 1
t → 1
e → 1
n → 1
```

Now count the second string.

```
silent

s → 1
i → 1
l → 1
e → 1
n → 1
t → 1
```

The frequency tables are identical.

Therefore:

```
Anagram ✅
```

# Efficient Idea

Since we only have lowercase English letters:

```
int freq[26] = {0};
```

### Step 1

Increase counts using the first string.

```
listen

l++
i++
s++
t++
e++
n++
```

---

### Step 2

Decrease counts using the second string.

```
silent

s--
i--
l--
e--
n--
t--
```

If everything matches, every count becomes **zero**.

```
a : 0
b : 0
...
l : 0
...
z : 0
```

If even one value isn't zero:

```
Not Anagram
```

---

# Algorithm

1. If lengths differ → `false`
2. Create `freq[26]`
3. Traverse first string → increment
4. Traverse second string → decrement
5. Check every element
6. If all are zero → `true`

---

# Code

```
#include <iostream>
#include <string>
using namespace std;

bool isAnagram(string s, string t) {

    if (s.length() != t.length())
        return false;

    int freq[26] = {0};

    for (char c : s)
        freq[c - 'a']++;

    for (char c : t)
        freq[c - 'a']--;

    for (int i = 0; i < 26; i++) {
        if (freq[i] != 0)
            return false;
    }

    return true;
}

int main() {

    string s = "listen";
    string t = "silent";

    if (isAnagram(s, t))
        cout << "Anagram";
    else
        cout << "Not Anagram";
}
```

# Complexity

- **Time:** `O(n)`
- **Space:** `O(1)` (because the array size is always 26)

# 🧠 Pattern Recognition

Don't memorize "Valid Anagram."

Recognize the underlying pattern:

|If the problem says...|Think...|
|---|---|
|Count characters|Frequency Array / Hash Map|
|Same letters?|Frequency Array|
|Duplicate characters|Frequency Array|
|First unique character|Frequency Array|
|Ransom Note|Frequency Array|

This is your **second major DSA pattern** after **Two Pointers**, and you'll see it repeatedly in string and hashing problems.
