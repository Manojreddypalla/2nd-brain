# Minimum Spanning Tree (MST)

## Intuition

Imagine you are laying **internet cables** to connect several cities.

You want to:

- ✅ Connect **every city**
    
- ✅ Spend the **least amount of money**
    
- ❌ Avoid unnecessary loops (cycles)
    

The cheapest network that connects everyone is called the **Minimum Spanning Tree (MST).**

---

## Definition

A **Minimum Spanning Tree (MST)** is a subset of edges in a **connected, weighted, undirected graph** that:

- Connects **all vertices**
    
- Has **no cycles**
    
- Has the **minimum possible total edge weight**
    

---

## Conditions

An MST must satisfy:

- ✅ All vertices are connected.
    
- ✅ No cycles are present.
    
- ✅ Uses exactly **V − 1 edges** (where **V** is the number of vertices).
    
- ✅ Total edge weight is minimum.
    

---

## Example

```text
A ----1---- B
|           |
4           2
|           |
C ----3---- D
```

Choose the cheapest edges that connect all nodes:

```text
A ----1---- B
             |
             2
             |
C ----3---- D
```

Total Cost = **1 + 2 + 3 = 6**

---

## Important Facts

- MST exists **only for connected graphs**.
    
- If the graph is disconnected, you get a **Minimum Spanning Forest (MSF)**.
    
- There can be **multiple MSTs** if different edge combinations have the same minimum total weight.
