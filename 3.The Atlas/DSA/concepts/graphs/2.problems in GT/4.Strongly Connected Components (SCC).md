# Strongly Connected Components (SCC)

## Intuition

Imagine a group of cities connected by **one-way roads**.

Inside one group, **every city can reach every other city**, even though the roads are one-way.

That group is called a **Strongly Connected Component (SCC).**

Think of it as a **closed team** where everyone can visit everyone else.

---

## Definition

In a **Directed Graph**, an SCC is a **maximum set of vertices** such that

For every pair of vertices `(u, v)`,

- `u → v` is possible
- `v → u` is also possible

In short:

> Every node can reach every other node.

---

## Example

```
A → B↑   ↓← C
```

Can A reach B?  
✅ Yes

Can B reach C?  
✅ Yes

Can C reach A?  
✅ Yes

Actually,

- A → B
- A → C
- B → A
- B → C
- C → A
- C → B

So

```
{A, B, C}
```

is **one SCC.**

---

## Another Example

```
A → B → C
```

Can A reach C?  
✅ Yes

Can C reach A?  
❌ No

So each node is its own SCC.

```
{A}{B}{C}
```

# Looking at your picture

The graph contains several groups.

```
(A,B,C)
```

can all reach each other.

↓

There is an edge going to

```
(D,E)
```

They can reach each other.

↓

There are more nodes on the right that also form another SCC.

Notice something important:

```
SCC -----> SCC -----> SCC
```

Edges may go **between SCCs**, but once you leave an SCC, you **may not be able to come back**.

That's why SCCs are called **maximal groups**.

---

# Why do we need SCCs?

They help solve problems like

- Detecting cycles
- Compressing graphs into DAGs
- Deadlock detection
- Dependency resolution
- Compiler optimizations
- Social network analysis

---

# Mental Model

Think of a college.

Different friend groups exist.

Inside one friend group,

Everyone knows everyone.

Between groups,

Maybe one student knows another group,  
but not everyone.

Each friend group = **SCC**

## Quick Comparison

|Graph Type|Connected Means|
|---|---|
|**Undirected Graph**|Every node is reachable from every other node.|
|**Directed Graph (SCC)**|Every node can reach every other node **following arrow directions**.|

---

## One-Line Memory Trick

> **Connected Component** → Undirected graph → Everyone is connected.
> 
> **Strongly Connected Component** → Directed graph → Everyone can **travel both ways** to everyone else by following directed edges.
