# Bridges (Cut Edges)

## Brief

A **Bridge** (also called a **Cut Edge**) is an edge in an **undirected graph** whose removal **increases the number of connected components**.

In simple words:

> **If removing an edge disconnects the graph, that edge is a Bridge.**

---

## Example

```text
A ----- B ----- C
```

If we remove the edge **B—C**:

```text
A ----- B      C
```

The graph becomes disconnected.

✅ **B—C is a Bridge.**

---

## Non-Bridge Example

```text
A
|\
| \
B--C
```

Removing any one edge still leaves another path between the nodes.

❌ No bridge exists.

---

## Why is it Important?

Bridges represent **critical connections** in a network.

Applications include:

- 🌐 Network reliability
    
- 🚦 Road and transportation networks
    
- 🔌 Power grids
    
- 💻 Computer networks
    
- 🔒 Finding bottlenecks and vulnerabilities
    

---

## Key Property

A bridge **does not belong to any cycle**.

If an edge is part of a cycle, there is another way to reach the destination, so removing it **won't disconnect** the graph.

---

## Time Complexity

- **O(V + E)** using DFS.
    

---

## Algorithm (Name Only)

- **Tarjan's Bridge Finding Algorithm (DFS + Low Link Values)**
    

---

## Memory Trick

> **Bridge = Remove one edge → Graph breaks into more connected components.**
