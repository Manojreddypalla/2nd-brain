## 📘 String Builder (`push_back`, `+=`, `append`)

Imagine you're building a word one character at a time.

Instead of writing:

```cpp
string ans = "";

ans = ans + 'H';
ans = ans + 'E';
ans = ans + 'L';
ans = ans + 'L';
ans = ans + 'O';
```

you use the string's built-in functions.

---

## 1. `push_back()`

Adds **one character** to the end.

```cpp
string s = "";

s.push_back('H');
s.push_back('E');
s.push_back('L');
s.push_back('L');
s.push_back('O');

cout << s;
```

Output:

```text
HELLO
```

---

## 2. `+=`

Can add a character **or** another string.

### Character

```cpp
string s = "";

s += 'A';
s += 'B';
s += 'C';
```

Output

```text
ABC
```

### String

```cpp
string s = "Hello";

s += " World";
```

Output

```text
Hello World
```

---

## 3. `append()`

Adds another **string**.

```cpp
string s = "Hello";

s.append(" World");
```

Output

```text
Hello World
```

You can also append part of another string, but that's something you can learn later.

---

# When are these used?

Suppose you want to remove digits.

Input:

```text
a1b2c3
```

Output:

```text
abc
```

You'll build the answer:

```cpp
string ans = "";

for (char c : s) {
    if (!isdigit(c))
        ans.push_back(c);
}
```

Here, you're **building a new string** character by character.

---

# Which one should you use?

|Function|Use|
|---|---|
|`push_back(c)`|Add **one character**|
|`+=`|Add a character or a whole string|
|`append()`|Add another string|

---

## Interview Tip

For DSA problems:

- **Single character** → `push_back()`
    
- **Whole string** → `+=` or `append()`

```cpp
string s = "";

s.push_back('A');   // Add one character

```
