# Reverse a String (Mini Notes)

## 💡 Intuition

A string is just an array of characters.

```
"HELLO"

Index: 0 1 2 3 4
       H E L L O
```

To reverse it, swap the first and last characters, then move inward.

```
H E L L O
↑       ↑
Swap

O E L L H

  ↑   ↑
Swap

O L L E H
```

---

# Algorithm

```
left = 0
right = n - 1

while(left < right)
{
    swap(str[left], str[right]);
    left++;
    right--;
}
```

Time Complexity: **O(n)**  
Space Complexity: **O(1)** ✅ (in-place)

---

# Method 1 — Two Pointers (Best)

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s = "hello";

    int left = 0;
    int right = s.length() - 1;

    while (left < right) {
        swap(s[left], s[right]);
        left++;
        right--;
    }

    cout << s;
}
```

Output

```
olleh
```

# Method 2 — STL `reverse()`

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    string s = "hello";

    reverse(s.begin(), s.end());

    cout << s;
}
```

Output

```
olleh
```

# Method 3 — Create a New String

```cpp
#include <iostream>
using namespace std;

int main() {
    string s = "hello";
    string rev = "";

    for (int i = s.length() - 1; i >= 0; i--) {
        rev += s[i];
    }

    cout << rev;
}
```

Time: **O(n)**  
Space: **O(n)**

---

# Recursive Method

```cpp
#include <iostream>
using namespace std;

void reverseString(string &s, int left, int right) {
    if (left >= right)
        return;

    swap(s[left], s[right]);

    reverseString(s, left + 1, right - 1);
}

int main() {
    string s = "hello";

    reverseString(s, 0, s.length() - 1);

    cout << s;
}
```

# Interview Pattern

Whenever you see:

- Reverse a string
    
- Reverse an array
    
- Reverse a vector
    
- Reverse part of an array
    

👉 Think **Two Pointers**.

```
Left → ← Right
```

This is one of the most common DSA patterns.

---

# Cheat Sheet

|Method|Time|Space|
|---|---|---|
|Two Pointers|O(n)|O(1) ✅|
|STL `reverse()`|O(n)|O(1)|
|New String|O(n)|O(n)|
|Recursion|O(n)|O(n) (call stack)|

### Key Takeaway

The **two-pointer technique** is the fundamental approach. It appears not only in string reversal but also in problems like palindrome checking, reversing arrays, partitioning arrays, and many sliding-window problems. Master this pattern first.
