# 📘 Next Topic: Character Frequency

This introduces your **second major DSA pattern**:

> **Frequency Counting**

Instead of asking:

> "What character is here?"

You ask:

> **"How many times has each character appeared?"**

---

## Example

String:

```text
banana
```

Instead of reading it as:

```text
b a n a n a
```

Think of it as a table:

```text
Character   Count

a           3
b           1
n           2
```

Now answering questions becomes easy:

- How many `a`s? → 3
    
- Does `b` exist? → Yes
    
- Which character appears once? → `b`
    
- Are two strings anagrams? → Compare frequencies
    

---

## Ways to Store Frequency

### 1. Frequency Array (Fastest for lowercase letters)

```cpp
int freq[26] = {0};
```

Example:

```cpp
string s = "banana";

for (char c : s) {
    freq[c - 'a']++;
}
```

Here:

```text
'a' - 'a' = 0
'b' - 'a' = 1
'c' - 'a' = 2
...
'z' - 'a' = 25
```

---

### 2. Hash Map (Works for any characters)

```cpp
unordered_map<char, int> freq;

for (char c : s) {
    freq[c]++;
}
```

Useful when the string isn't limited to lowercase letters.
