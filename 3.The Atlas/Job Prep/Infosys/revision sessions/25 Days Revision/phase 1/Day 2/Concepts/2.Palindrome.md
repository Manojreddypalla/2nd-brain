# Palindrome (Mini Notes)

## 💡 Intuition

A **palindrome** is a string that reads the same from both directions.

Examples:

```
madam   ✅
racecar ✅
level   ✅

hello   ❌
apple   ❌
```

Instead of reversing the whole string, compare characters from both ends.

```
m a d a m
↑       ↑  Equal

  ↑   ↑    Equal

    ↑      Done
```

If every pair matches, it's a palindrome.

---

# Algorithm

```
left = 0
right = n - 1

while(left < right)
{
    if(str[left] != str[right])
        return false;

    left++;
    right--;
}

return true;
```

**Time Complexity:** O(n)  
**Space Complexity:** O(1) ✅

---

# Method 1 — Two Pointers (Best)

```
#include <iostream>
using namespace std;

bool isPalindrome(string s)
{
    int left = 0;
    int right = s.length() - 1;

    while (left < right)
    {
        if (s[left] != s[right])
            return false;

        left++;
        right--;
    }

    return true;
}

int main()
{
    string s = "madam";

    if (isPalindrome(s))
        cout << "Palindrome";
    else
        cout << "Not Palindrome";
}
```

Output

```
Palindrome
```

# Method 2 — Reverse and Compare

```
#include <iostream>
#include <algorithm>
using namespace std;

bool isPalindrome(string s)
{
    string temp = s;

    reverse(temp.begin(), temp.end());

    return s == temp;
}

int main()
{
    string s = "level";

    cout << (isPalindrome(s) ? "Palindrome" : "Not Palindrome");
}
```

Time: **O(n)**  
Space: **O(n)**

# Recursive Method

```
#include <iostream>
using namespace std;

bool palindrome(string &s, int left, int right)
{
    if (left >= right)
        return true;

    if (s[left] != s[right])
        return false;

    return palindrome(s, left + 1, right - 1);
}

int main()
{
    string s = "racecar";

    cout << (palindrome(s, 0, s.length() - 1) ? "Palindrome" : "Not Palindrome");
}
```

# Interview Pattern

Whenever you see:

- Valid Palindrome
- Check symmetry
- Mirror comparison
- Compare from both ends

👉 Think **Two Pointers**.

```
Left → ← Right
```

No extra memory is needed.

---

# Cheat Sheet

|Method|Time|Space|
|---|---|---|
|Two Pointers|O(n)|O(1) ✅|
|Reverse + Compare|O(n)|O(n)|
|Recursion|O(n)|O(n) (call stack)|

### Key Takeaway

The **two-pointer technique** is the standard solution for palindrome problems. The pattern is simple:

1. Start at both ends.
2. Compare characters.
3. If any pair differs → **Not Palindrome**.
4. If pointers cross without mismatches → **Palindrome**.

This same pattern is used in many LeetCode problems such as **Valid Palindrome**, **Valid Palindrome II**, and **Longest Palindromic Substring** (as part of the expand-around-center approach).
