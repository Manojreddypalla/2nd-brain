### 🔴 Negative Cycle (Brief)

A **negative cycle** is a cycle in a **weighted graph** where the **sum of all edge weights is less than 0**.

Example:

```
A --2--> B
^        |
|        |
-5       1
|        |
+--------+
```

Cycle weight = `2 + 1 + (-5) = -2`

Since `-2 < 0`, it is a **negative cycle**.

### Why is it important?

- Every time you travel around the cycle, your total path cost becomes **smaller**.
    
- You can keep looping forever and make the cost approach **−∞**.
    
- Therefore, the **shortest path is undefined** for any node that can reach this cycle.

### Detect Negative Cycles

- **Floyd–Warshall Algorithm**
    

---

### Related Shortest Path Algorithms (for comparison)

- **Dijkstra's Algorithm** → No negative weights.
    
- **Bellman–Ford Algorithm** → Handles negative weights and detects negative cycles.
    
- **Floyd–Warshall Algorithm** → All-pairs shortest paths and detects negative cycles.
    
- **Johnson's Algorithm** → All-pairs shortest paths on sparse graphs (uses Bellman–Ford internally).
