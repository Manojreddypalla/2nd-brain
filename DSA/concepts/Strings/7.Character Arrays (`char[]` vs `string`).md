# 📘 Character Arrays (`char[]`) vs `std::string`

## Before C++

In the C language, strings didn't exist.

Instead, programmers stored text like this:

```cpp
char name[] = "HELLO";
```

Memory:

```text
Index

0    1    2    3    4    5
+----+----+----+----+----+------+
| H  | E  | L  | L  | O  | '\0' |
+----+----+----+----+----+------+
```

Notice the last character:

```cpp
'\0'
```

called the **Null Character (Null Terminator)**.

---

# Why `'\0'`?

Suppose memory looked like this:

```text
H E L L O ? ? ? ? ?
```

How does the computer know where the word ends?

It doesn't.

So C stores

```cpp
'\0'
```

to indicate:

> **"The string ends here."**

Functions like

```cpp
strlen(name);
printf("%s", name);
```

keep reading until they encounter `'\0'`.

---

# Modern C++

Instead of

```cpp
char name[] = "HELLO";
```

we use

```cpp
string name = "HELLO";
```

The `string` class automatically manages:

- Memory allocation
    
- Length
    
- Resizing
    
- Copying
    
- Appending
    

You don't worry about `'\0'` directly.

---

# Comparison

|`char[]`|`string`|
|---|---|
|C-style string|C++ class|
|Fixed size|Dynamic size|
|Uses `'\0'`|Manages length internally|
|Less safe|Safer|
|Manual operations|Built-in functions|

---

# Example

### Character Array

```cpp
char name[] = "HELLO";

cout << name << endl;
```

Access:

```cpp
cout << name[0];
```

Output

```text
H
```

---

### String

```cpp
string name = "HELLO";

cout << name << endl;
```

Access

```cpp
cout << name[0];
```

Output

```text
H
```

They look similar, but internally they're different.

---

# Functions

### `char[]`

```cpp
strlen(name)
strcpy()
strcat()
strcmp()
```

(C library functions)

---

### `string`

```cpp
name.length()
name.size()
name.substr()
name.find()
name.push_back()
name.append()
```

Much easier to use.

---

# When are Character Arrays Used?

Nowadays, you'll mostly use `std::string`.

You'll still encounter `char[]` in:

- Operating Systems
    
- Embedded Systems
    
- C programs
    
- Legacy code
    
- Some interview questions
    

---

# Interview Rule

If the interviewer says:

> "Given a string..."

Use:

```cpp
string s;
```

If they explicitly say:

> "Given a character array..."

Use:

```cpp
char arr[];
```

---

# 🧠 Summary

|Feature|`char[]`|`string`|
|---|---|---|
|Language|C|C++|
|Null Terminator|Yes (`'\0'`)|Managed internally|
|Resize|❌ No|✅ Yes|
|Easy Functions|❌|✅ Yes|
|Recommended for DSA|❌ Rarely|✅ Almost Always|

## 🎯 What you should remember

For **LeetCode, GFG, interviews, and competitive programming**, you'll use **`std::string` about 99% of the time**.

Just understand that **`std::string` is built on top of lower-level character storage**, and `char[]` is the older C-style representation. Knowing the difference helps you read older code and understand how strings work under the hood, but for your DSA journey, **prefer `std::string` unless a problem explicitly requires `char[]`.**
