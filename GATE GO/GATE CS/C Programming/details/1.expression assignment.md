### C expression assignment — mini note

> **Rule:** Left side of `=` must be a **modifiable lvalue**.

- `x = 5` ✅ → `x` is a variable → modifiable lvalue.
    
- `x + 5 = y` ❌ → `x + 5` is an **expression/value**, not an lvalue.
    
- `(x + y) = z` ❌ → result of arithmetic expression cannot be assigned to.
    
- `x = y + z` ✅ → `x` is the left-side lvalue.
    

**Mental model:**  
`=` means **“put the RHS value into the memory location named by LHS.”**  
So LHS must identify a writable memory location.

**GATE trap:**  
`=` → assignment  
`==` → comparison  
`x = (y == z)` can be valid because the **result of `==` is assigned to `x`**.
