# 19. 2's Complement → Decimal

Now we are doing the **reverse conversion**.

Earlier:

```
Decimal → 2's Complement
```

Now:

```
2's Complement → Decimal
```

Example:

```
1011 → ?
```

The first thing we check is the **MSB (leftmost bit)**.

---

# 20. First Check the MSB

For a signed 2's-complement number:

```
MSB = 0 → Number is non-negative
MSB = 1 → Number is negative
```

So:

```
0101
↑
0

→ non-negative
```

But:

```
1011
↑
1

→ negative
```

> [!important]  
> **Always check the MSB first.**

---

# 21. Case 1 — MSB = `0`

If the MSB is `0`, simply convert the binary number to decimal normally.

### Example

```
0101
```

MSB:

```
0 → non-negative
```

Now use normal binary conversion:

```
0      1      0      1
↓      ↓      ↓      ↓
2³     2²     2¹     2⁰
```

Therefore:

4+1=54+1=54+1=5

So:

```
0101 → +5
```

That's it.

No flipping.

No adding `1`.

---

# 22. Case 2 — MSB = `1`

If the MSB is `1`, the number is **negative**.

To find its decimal value:

```
1. Flip all bits
2. Add 1
3. Convert to decimal normally
4. Put a minus (-) sign
```

Mental model:

```
MSB = 1
   ↓
Negative
   ↓
Flip bits
   ↓
Add 1
   ↓
Convert to decimal
   ↓
Put - sign
```

---

# 23. Example — `1011`

Given:

```
1011
```

### Step 1 — Check MSB

```
1011
↑

MSB = 1
```

Therefore:

```
Negative number
```

### Step 2 — Flip bits

```
1011
 ↓
0100
```

### Step 3 — Add `1`

```
  0100
+ 0001
------
  0101
```

### Step 4 — Convert `0101`

```
0101

= 4 + 1
= 5
```

### Step 5 — Add minus sign

```
1011 → -5
```

So:

1011=−5\boxed{1011=-5}1011=−5​

# 24. The One Rule to Remember

```
Given a 2's-complement number
           ↓
       Check MSB
           ↓
      ┌────┴────┐
      ↓         ↓
      0         1
      ↓         ↓
 Non-negative  Negative
      ↓         ↓
  Convert     Flip bits
  normally       ↓
               + 1
                 ↓
           Convert normally
                 ↓
              Add -
```

### Example

```
0101
↑
0 → normal conversion → 5
```

```
1011
↑
1 → flip + 1 → 5 → -5
```

# 25. Another Method — Negative MSB Weight

There is also a faster mathematical method.

For a signed 2's-complement number, the **MSB has a negative weight**.

For 4 bits:

```
Bit:      b₃    b₂    b₁    b₀

Weight:  -2³    2²    2¹    2⁰
          ↓     ↓     ↓     ↓
         -8     4     2     1
```

> [!important]  
> Only the **MSB weight is negative**.

---

## Example — `1011`

```
Bits:      1    0    1    1

Weights:  -8    4    2    1
```

Take weights where bit = `1`:

```
1 → -8
0 → ignore
1 → +2
1 → +1
```

Therefore:

−8+2+1=−5-8+2+1=-5−8+2+1=−5

So:

```
1011 → -5
```

---

# 26. Which Method Should I Use?

Both give the same answer.

### Method 1 — MSB Negative Weight

```
1011

= -8 + 0 + 2 + 1
= -5
```

Fast once you're comfortable.

### Method 2 — Flip + Add 1

```
1011

MSB = 1
↓
flip → 0100
↓
+1 → 0101
↓
5
↓
-5
```

Easier to remember initially.

> [!tip]  
> For now, use **Method 2** if Method 1 feels confusing.
> 
> Once you're comfortable, the negative-MSB method is faster for GATE questions.

# 27. Unsigned Binary vs Signed 2's Complement

This is VERY important.

Consider:

```
1011
```

If the question says **unsigned binary**:

```
1011

= 8 + 2 + 1
= 11
```

So:

```
1011 → 11
```

But if the question says **4-bit signed 2's complement**:

```
1011
↑
MSB = 1

→ negative
```

Then:

```
1011 → -5
```

Therefore:

```
Same bits: 1011

Unsigned          → 11
Signed 2's comp.  → -5
```

> [!warning] GATE Trap  
> Never look at `1011` and immediately say `11`.
> 
> First check what the question says:
> 
> **Unsigned or signed 2's complement?**

# 28. Bit Width Matters

The number of bits is important.

For example, `-5` can be represented as:

### 4-bit

```
+5 → 0101

flip → 1010
+1   → 1011

-5 → 1011
```

### 8-bit

```
+5 → 00000101

flip → 11111010
+1   → 11111011

-5 → 11111011
```

Therefore:

```
4-bit  -5 → 1011

8-bit  -5 → 11111011
```

Same value, different bit width.

# 29. Decimal → 2's Complement

If the question gives you a **decimal number** and asks for its 2's-complement representation:

## Positive Number

Just convert to binary using the required bit width.

Example:

```
+5 using 4 bits

5 → 0101
```

No flip + 1.

---

## Negative Number

Convert the positive magnitude first, then:

```
Flip bits
   ↓
Add 1
```

Example:

```
-5 using 4 bits

+5
↓
0101
↓ flip
1010
↓ +1
1011

-5 → 1011
```

# 31. Final Mental Model

Don't memorize ten separate rules. Think about **direction**.

### Decimal → Binary Representation

```
Positive?
   ↓
Convert normally

Negative?
   ↓
Convert magnitude
   ↓
Flip
   ↓
+1
```

### Binary Representation → Decimal

```
Check MSB
   ↓
0 ─────────────→ Convert normally

1 ─→ Flip → +1 → Convert → Add minus sign
```

So these four examples should become automatic:

```
Decimal → 2's complement

+5 → 0101
-5 → 1011
```

and:

```
2's complement → Decimal

0101 → +5
1011 → -5
```

> [!summary]  
> **The simplest rule:**
> 
> ```
> Positive decimal → binary normally
> 
> Negative decimal → binary → flip → +1
> 
> Binary with MSB 0 → decimal normally
> 
> Binary with MSB 1 → flip → +1 → decimal → negative
> ```

This is the version I'd actually keep in your notes. The big formula with the summation is mathematically correct, but **you don't need it as your main mental model right now**—understand `MSB → decide positive/negative → convert` first.
