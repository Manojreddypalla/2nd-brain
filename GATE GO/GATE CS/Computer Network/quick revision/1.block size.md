## Finding Block Size — Subnetting

### 1. Convert CIDR `/n` → Subnet Mask

IPv4 has **32 bits**.

Example:

$$ 
/20 = 11111111.11111111.11110000.00000000  
$$ 

$$ 
\boxed{/20 = 255.255.240.0}  
$$ 

---

### 2. Find the **Interesting Octet**

The **interesting octet** is the first octet whose mask value is neither `255` nor `0`.

Example:

```text
255.255.240.0
          ↑
   Interesting octet
```

---

### 3. Calculate Block Size
$$ 
\boxed{\text{Block Size}=256-\text{Mask value}}  
$$ 

For `/20`:

$$ 
256-240=\boxed{16}  
$$ 

So the block size is **16**.

---

### 4. Use Block Size to Find Network Blocks

The network addresses increase by the block size.

For `/20`:

```text
3rd octet

0
16
32
48
64
80
96
112
...
```

Therefore:

```text
128.143.64.0/20
```

covers:

$$ 
\boxed{128.143.64.0;-;128.143.79.255}  
$$ 

because:
$$ 
64+16-1=79  
$$ 

---

### Quick Formula

$$  
\boxed{  
\text{Block Size}=256-\text{mask value in interesting octet}  
}  
$$ 

### GATE Shortcut

|CIDR|Mask|Interesting Octet|Block Size|
|---|---|--:|--:|
|`/24`|`255.255.255.0`|—|1|
|`/23`|`255.255.254.0`|3rd|2|
|`/22`|`255.255.252.0`|3rd|4|
|`/21`|`255.255.248.0`|3rd|8|
|`/20`|`255.255.240.0`|3rd|16|
|`/19`|`255.255.224.0`|3rd|32|
|`/18`|`255.255.192.0`|3rd|64|
|`/17`|`255.255.128.0`|3rd|128|
|`/16`|`255.255.0.0`|—|256*|

*For `/16`, the block boundary is already at the **3rd octet**, so think of it as increments of 1 in the 3rd octet rather than literally applying `256-0` to an octet.
