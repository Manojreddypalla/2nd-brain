  
Which of the following is/are shared by all the threads in a process?

1. Program counter
2. Stack
3. Address space
4. Registers

(I) and (II) only
(III) only
(IV) only
(III) and (IV) only



**Answer: 2) (III) only ✅**

The trick is distinguishing **process-level resources** from **thread-level execution state**.

|Item|Shared among threads?|Why?|
|---|---|---|
|**1. Program Counter (PC)**|❌|Each thread executes independently → each needs its own PC.|
|**2. Stack**|❌|Each thread has its **own stack** for function calls/local variables.|
|**3. Address Space**|✅|Threads of the same process share the **same virtual address space**.|
|**4. Registers**|❌|Each thread has its own CPU register state for independent execution.|

### 🧠 Visualize it

```text
             PROCESS
    ┌────────────────────────┐
    │     SHARED             │
    │  Address Space         │
    │  ├── Code              │
    │  ├── Data              │
    │  └── Heap              │
    │                        │
    │  THREAD 1              │
    │  ├── PC                │
    │  ├── Registers         │
    │  └── Stack             │
    │                        │
    │  THREAD 2              │
    │  ├── PC                │
    │  ├── Registers         │
    │  └── Stack             │
    └────────────────────────┘
```

### 🔥 GATE shortcut

**Shared → Process resources**  
**Private → Execution state**

> **Address Space → shared**  
> **PC + Registers + Stack → per-thread**

⚠️ **Nuance:** A thread's stack is **private/owned by that thread**, but because the address space is shared, another thread can technically access it if it knows the address. **Ownership ≠ accessibility.**

So the answer is **2) (III) only**.
