  
Which one of the following is NOT shared by the threads of the same process ?

1. Stack
2. Address Space
3. File Descriptor Table
4. Message Queue

The answer is **1. Stack** ✅

Let's reason from the core rule rather than memorizing.

### Threads of the same process

Think:

```text
              PROCESS
                 │
      ┌──────────┴──────────┐
      │   SHARED RESOURCES  │
      │                     │
      │ Address Space       │
      │ File Descriptor Tbl │
      │ Message Queue       │
      │                     │
      ├─────────────────────┤
      │                     │
      │ T1        T2        │
      │ │         │         │
      │ Stack     Stack     │  ← separate
      │ PC        PC        │
      │ Registers Registers │
      └─────────────────────┘
```

### Option-by-option

|Option|Same-process threads share?|
|---|---|
|**1. Stack**|❌ **No**|
|2. Address Space|✅ Yes|
|3. File Descriptor Table|✅ Yes|
|4. Message Queue|✅ Yes|

### Why Stack is different?

Each thread needs its **own execution state**:

```text
T1 → Stack 1
T2 → Stack 2
T3 → Stack 3
```

because each thread can be inside a different function and have different local variables/call frames.

Meanwhile, threads belong to the same process, so they share the process's resources/address space.

### 🔥 GATE shortcut

Whenever you see:

> **"What is NOT shared among threads of the same process?"**

Immediately check for:

**PC, Registers, Stack** → **private/separate**

**Code, Data, Heap, Files/File descriptors, Address space** → **shared**

So the answer is:

# **1. Stack** ✅
