  
Threads of a process share

1. global variables but not heap
2. heap but not global variables
3. neither global variables nor heap
4. both heap and global variables



**Answer: 4) both heap and global variables ✅**

### GATE Short Note

Threads belonging to the **same process share the process's address space**.

|Memory area|Shared by threads?|
|---|---|
|**Code/Text**|✅ Shared|
|**Global variables / Data**|✅ Shared|
|**Heap**|✅ Shared|
|**Stack**|❌ Each thread has its own|
|**Registers**|❌ Each thread has its own|
|**Program Counter**|❌ Each thread has its own|

### 🧠 Why?

Imagine one process as a **house** and threads as people living in it:

```text
PROCESS
│
├── Code        ← shared
├── Global vars ← shared
├── Heap        ← shared
│
├── Thread 1
│   └── Stack   ← private
│
└── Thread 2
    └── Stack   ← private
```

So:

> **Global variables + Heap = shared**  
> **Stack + Registers + PC = per-thread**

Therefore **Option 4**.
