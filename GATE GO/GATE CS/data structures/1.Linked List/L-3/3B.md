## 6. Question 1 — Recursive insertion

Given:

```text
4 → 7 → 5 → 3 → 2 → NULL
```

Calling:

```c
insertRear(head, 8)
```

### Key point

The recursive calls reach `NULL`, create `8`, then **unwind and reconnect** the list.

Final:

```text
4 → 7 → 5 → 3 → 2 → 8 → NULL
```

**Pattern:**  
`recursive call → reconnect using l->next → return l`

## 7. Question 2 — `return l->next`

Function:

```c
Node* fun(Node* l, int data)
{
    if (l == NULL)
    {
        Node *n = createNode(data);
        return n;
    }
    else
    {
        l->next = fun(l->next, data);
        return l->next;
    }
}
```

Given:

```text
4 → 7 → 5 → 3 → 2 → NULL
```

Call:

```c
fun(head, 8)
```

### Important difference

Previously:

```c
return l;
```

Now:

```c
return l->next;
```

So while the new node is inserted at the end, the **returned pointer is shifted forward**.

The lecture's result is:

```text
8 → NULL
```

So don't automatically assume that recursive linked-list code returns the original `head`. **Look carefully at the return statement.**

---

# 8. The BIG Recursion Trick 🔥

For linked-list recursion, track **two things separately**:

### 1. What happens while going DOWN?

```text
l → l->next → l->next → ...
```

You're moving toward the base case.

### 2. What happens while coming BACK?

Look at:

```c
l->next = recursive(...);
```

and especially:

```c
return l;
```

or

```c
return l->next;
```

These determine what pointer each stack frame passes upward.

### Mental model

```text
GO DOWN
4 → 7 → 5 → 3 → 2 → NULL
                         ↓
                     create 8
                         ↓
COME BACK
2 → 8
3 → ...
5 → ...
7 → ...
4 → ...
```

**Never solve these questions by only looking at the final code. Trace the return values during unwinding.**

---

# 9. GATE Question Pattern

When you see recursive linked-list code:

### Step 1

Write the original list.

### Step 2

Write every recursive call:

```text
f(4)
 ↓
f(7)
 ↓
f(5)
 ↓
...
```

### Step 3

Stop at base case.

### Step 4

Trace **return values upward**.

### Step 5

Apply pointer assignments during unwinding.

### Step 6

Check what the **original function call returns**.

This is much safer than trying to mentally execute the entire recursion at once.
