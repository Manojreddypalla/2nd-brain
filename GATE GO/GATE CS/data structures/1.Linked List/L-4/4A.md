# 1. Reverse a Linked List

### Original list

```text
head
 ↓
4 → 3 → 5 → 7 → NULL
```

### After reversal

```text
head
 ↓
7 → 5 → 3 → 4 → NULL
```

The **same nodes** are used. We are not creating new nodes.

We only change the `next` pointers.

### Core idea

For every node:

```text
current → next
```

becomes:

```text
current ← next
```

So reversal is fundamentally a **pointer-direction problem**.

---

# 2. The Three-Pointer Technique

To reverse safely, maintain:

```text
prev
current
next
```

Initially:

```text
prev = NULL
current = head
next = current->next
```

Example:

```text
NULL    4       3       5
 ↑      ↑       ↑
prev  current  next
```

The three pointers have different jobs:

|Pointer|Purpose|
|---|---|
|`prev`|Already-reversed portion|
|`current`|Node whose link is being reversed|
|`next`|Saves the unreversed list|

### Why do we need `next`?

Because once we do:

```c
current->next = prev;
```

we destroy the original forward connection.

Without saving:

```c
next = current->next;
```

we would lose access to the remaining list.

**Mental rule:**

> Before changing a pointer, save the information that the pointer currently contains.

# 3. One Iteration of Reversal

Suppose:

```text
prev = NULL
current = 4
next = 3
```

Current list:

```text
NULL ← 4    3 → 5 → 7 → NULL
       ↑    ↑
      prev current
```

### Step 1 — Reverse the pointer

```c
current->next = prev;
```

Now:

```text
NULL ← 4
```

### Step 2 — Move `prev`

```c
prev = current;
```

Now:

```text
prev
 ↓
4 → NULL
```

### Step 3 — Move `current`

```c
current = next;
```

Now:

```text
prev     current
 ↓          ↓
4 → NULL   3 → 5 → 7
```

### Step 4 — Save the next node

```c
next = current->next;
```

Now:

```text
prev     current  next
 ↓          ↓       ↓
4 → NULL   3 →     5 → 7
```

Then repeat.

# 4. Pointer Movement Pattern

The important pattern is:

```c
current->next = prev;

prev = current;
current = next;

if (next != NULL)
    next = next->next;
```

Think of it as:

```text
1. Reverse
2. Shift prev
3. Shift current
4. Shift next
```

or simply:

```text
        REVERSE
           ↓
prev ← current    next → remaining list
           ↓
       shift pointers
```

This is the core pattern you should recognize in GATE questions.

# 5. Iterative Reverse Algorithm

Lecture code:

```c
Node* reverseIterative(Node* head)
{
    if (head == NULL || head->next == NULL)
        return head;

    Node* prev = NULL;
    Node* current = head;
    Node* next = head->next;

    while (current != NULL)
    {
        current->next = prev;

        prev = current;
        current = next;

        if (next != NULL)
            next = next->next;
    }

    return prev;
}
```

### Important

At the end:

```text
current = NULL
```

but:

```text
prev = new head
```

Therefore:

```c
return prev;
```

# 7. GATE Question — Reverse Linked List

The lecture includes a **GATE CSE 2022 Question 5** on reversing a singly linked list.

The question asks:

> Which statement about the time complexity of the best algorithm for reversing a singly linked list is TRUE?

Options include:

```text
A. O(1)
B. O(log n)
C. O(n)
D. Impossible in O(1) space
```

### ✅ Answer: C — O(n)

Why?

A linked list containing `n` nodes must have its links reversed. We need to visit the nodes.

```text
n nodes
 ↓
visit each node once
 ↓
O(n)
```

### Space complexity

The iterative three-pointer approach uses only:

```text
prev
current
next
```

So auxiliary space is:

```text
O(1)
```

Therefore:

```text
Time  = O(n)
Space = O(1)
```

### 🚨 GATE Trap

Do **not** confuse:

```text
O(1) auxiliary space
```

with:

```text
O(1) time
```

Reversal is possible in **constant extra space**, but still requires **linear time**.
