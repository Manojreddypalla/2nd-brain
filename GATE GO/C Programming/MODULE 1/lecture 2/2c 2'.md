# 2's Complement — GATE Notes

## 1. Why 2's Complement?

2's complement is a way to represent **negative numbers in binary**.

The key advantage:

> **Addition can be used for both positive and negative numbers.**

The lecture starts by showing that we want a representation of negative numbers where adding a number and its negative gives `0`.

---

# 2. 1's Complement

Before 2's complement, understand **1's complement**.

### Rule

**Invert every bit:**

```text
0 → 1
1 → 0
```

Example:

```text
  0101
  ↓↓↓↓
  1010
```

Therefore:

```text
1's complement of 0101 = 1010
```

The lecture shows that a binary number + its 1's complement gives **all 1s**.

Example:

```text
  0101
+ 1010
------
  1111
```

---

# 3. 2's Complement ⭐

### Formula

```text
2's complement
= 1's complement + 1
```

Example:

```text
Number = 0101

1's complement:
1010

Add 1:
1010
+0001
-----
1011
```

Therefore:

```text
2's complement of 0101 = 1011
```

---

# 4. Why Does It Give Zero?

Take:

```text
0101
```

Its 2's complement is:

```text
1011
```

Now add:

```text
  0101
+ 1011
------
 10000
```

For a **4-bit system**, we keep only 4 bits:

```text
0000
```

The extra carry is discarded.

So:

```text
0101 + 1011 = 0000   (4-bit)
```

The lecture illustrates this exact idea.

### ⭐ GATE takeaway

```text
N + 2's complement(N) = 0
```

when working with a fixed number of bits and ignoring the carry out.

---

# 5. Why `+1`?

Remember:

```text
1's complement → all 1s when added to original
```

Example:

```text
  0101
+ 1010
------
  1111
```

Now add `1`:

```text
  1111
+ 0001
------
10000
```

Discard the extra carry:

```text
0000
```

Hence:

```text
2's complement = 1's complement + 1
```

The lecture explicitly demonstrates this transition from all `1`s to `0` after adding `1`.

---

# 6. Fast Trick to Find 2's Complement ⭐⭐⭐

Instead of:

```text
Invert all bits
+
Add 1
```

use this shortcut:

### From RIGHT → LEFT:

1. Copy bits **until and including the first `1`**
    
2. Invert all remaining bits to the **left**
    

The lecture gives this exact trick.

### Example

Find 2's complement of:

```text
100100
```

Start from right:

```text
100100
     ↑
 first 1
```

Copy through that `1`:

```text
???100
```

Invert everything to its left:

```text
011100
```

Therefore:

```text
2's complement = 011100
```

---

# 7. Another Example

Find 2's complement of:

```text
010110
```

Start from right:

```text
010110
     ↑
```

First `1` from the right is already near the end.

Copy:

```text
010110
     ↑
```

Invert bits to its left:

```text
101010
```

Therefore:

```text
2's complement = 101010
```

The lecture shows this type of transformation directly.

# 8. Using 2's Complement to Represent Negative Numbers

This is the **big connection with signed numbers**.

To represent `-X`:

```text
X
↓
binary representation
↓
2's complement
↓
representation of -X
```

Example using 4 bits:

```text
+5 = 0101
```

2's complement:

```text
0101
1010   ← 1's complement
+0001
-----
1011
```

Therefore:

```text
+5 = 0101
-5 = 1011
```

Now verify:

```text
  0101
+ 1011
------
10000
```

Discard carry:

```text
0000
```

Perfect.

---

# 9. 4-bit 2's Complement Range ⭐

For an `n`-bit signed 2's complement number:

```text
Range = -2^(n-1) to 2^(n-1)-1
```

For **4 bits**:

```text
-2³ to 2³ - 1
= -8 to +7
```

The lecture's 4-bit representation diagram shows exactly this range.

```text
-8 ... -1 | 0 | +1 ... +7
```

# 10. 4-bit Representation Table

From the lecture's diagram:

|Binary|Decimal|
|---|--:|
|`0000`|0|
|`0001`|+1|
|`0010`|+2|
|`0011`|+3|
|`0100`|+4|
|`0101`|+5|
|`0110`|+6|
|`0111`|+7|
|`1000`|-8|
|`1001`|-7|
|`1010`|-6|
|`1011`|-5|
|`1100`|-4|
|`1101`|-3|
|`1110`|-2|
|`1111`|-1|

### Pattern to notice

```text
0000 →   0
...
0111 →  +7

1000 →  -8
...
1111 →  -1
```

The **MSB is effectively the sign indicator** in 2's complement:

```text
MSB = 0 → non-negative
MSB = 1 → negative
```

# 11. How to Decode a Negative 2's Complement Number

Suppose you get:

```text
1011
```

MSB is `1`, so it's negative.

Find its magnitude using 2's complement:

```text
1011
↓ invert
0100
↓ +1
0101
```

`0101 = 5`

Therefore:

```text
1011 = -5
```

### Mental model

```text
negative binary
      ↓
take 2's complement
      ↓
get magnitude
      ↓
put '-' sign
```

If you see:

```text
negative number
2's complement
signed integer
binary addition
```

immediately think:

```text
          2's complement
                ↓
     ┌────────────────────┐
     │ invert bits + 1    │
     └────────────────────┘
                ↓
       fixed-width binary
                ↓
       discard carry out
```

And don't forget: **bit width matters.** `1011` as 4-bit 2's complement is `-5`; you cannot interpret it correctly without knowing the number of bits.
