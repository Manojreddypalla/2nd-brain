# Copy Bits to Higher Bits — Sign Extension

## Definition

> [!definition] Sign Extension  
> **Sign extension** is the process of increasing the number of bits of a signed 2's-complement number **without changing its value**.

For 2's-complement numbers, when increasing the bit width:

> **Copy the MSB (sign bit) into the new higher-order bits.**

---

# Rule

```text
MSB = 0 → Fill higher bits with 0
MSB = 1 → Fill higher bits with 1
```

So:

```text
Positive number → copy 0s
Negative number → copy 1s
```

---

# Example 1 — Positive Number

4-bit representation of `+5`:

```text
0101
↑
MSB = 0
```

Convert it to 8 bits by copying the MSB:

```text
4-bit:       0101
             ↑
           MSB = 0

8-bit:   00000101
```

Therefore:

```text
0101      = +5
00000101  = +5
```

The value does **not change**.

---

# Example 2 — Negative Number

4-bit representation of `-5`:

```text
1011
↑
MSB = 1
```

Convert it to 8 bits by copying `1` into the higher bits:

```text
4-bit:       1011
             ↑
           MSB = 1

8-bit:   11111011
```

Therefore:

```text
1011      = -5
11111011  = -5
```

Again, the value remains the same.

---

# Why Can't We Just Add Zeros?

Suppose:

```text
1011 = -5
```

If we incorrectly extend it using zeros:

```text
00001011
```

Now the MSB is:

```text
0 → positive
```

and the value becomes:

```text
00001011 = 11
```

So:

```text
1011       → -5

00001011   → +11 ❌
11111011   → -5  ✅
```

That is why signed 2's-complement numbers use **sign extension**.

---

# Mental Model

Think:

```text
Increase bit width
       ↓
Look at old MSB
       ↓
Copy that bit to the left
```

Examples:

```text
0101 → 00000101
 ↑
 copy 0


1011 → 11111011
 ↑
 copy 1
```

---

# Quick Revision

> [!important] Sign Extension Rule
> 
> When increasing the bit width of a **signed 2's-complement number**:
> 
> ```text
> MSB 0 → extend with 0s
> MSB 1 → extend with 1s
> ```
> 
> Example:
> 
> ```text
> +5: 0101 → 00000101
> -5: 1011 → 11111011
> ```
> 
> **Purpose:** Increase the number of bits while preserving the original signed value.
