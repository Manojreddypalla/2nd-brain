# Example 1: VRC (Vertical Redundancy Check)

> [!example] Problem
> Use **Even Parity** for the following data:
>
> ```
> Data = 1011001
> ```

---

## Step 1: Count the Number of 1s

```
Data = 1 0 1 1 0 0 1
```

Number of **1s = 4**

Since we are using **Even Parity**, the total number of 1s must remain **even**.

```
4 → Even
```

Therefore,

```
Parity Bit = 0
```

---

## Step 2: Append the Parity Bit

```
Data        : 1011001
Parity Bit  :       0
------------------------
Transmitted : 10110010
```

---

## Step 3: Receiver Verification

Receiver receives

```
10110010
```

Count the number of 1s.

```
Number of 1s = 4
```

Expected

```
Even
```

Received

```
Even
```

✅ Data Accepted

---

## Example with Error

Suppose one bit changes during transmission.

```
Sent

10110010
```

becomes

```
Received

10010010
```

Now count the number of 1s.

```
3 Ones
```

Expected

```
Even
```

Received

```
Odd
```

❌ Error Detected

---

> [!tip]
> **VRC checks the parity of a single data unit (row).**
