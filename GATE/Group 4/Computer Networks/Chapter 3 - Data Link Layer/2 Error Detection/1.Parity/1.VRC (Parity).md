# 3.2.1 Vertical Redundancy Check (VRC) / Parity Check

> [!info] Definition
> **Vertical Redundancy Check (VRC)**, commonly known as the **Parity Check**, is the simplest error detection technique. It adds **one extra bit**, called the **Parity Bit**, to every data unit so that the total number of 1s follows a predefined rule.

---

# Why is VRC Needed?

During transmission, bits may change because of

- Noise
- Electromagnetic Interference
- Weak Signal
- Hardware Faults

Example

Original Data

```
10110010
```

Received Data

```
10100010
```

One bit changed.

The receiver needs a way to detect this error.

VRC provides a simple solution by adding **one additional bit**.

---

# Basic Idea

Suppose we decide

```
Total number of 1s should always be EVEN.
```

If the data already contains an even number of 1s,

```
Parity Bit = 0
```

Otherwise,

```
Parity Bit = 1
```

Receiver again counts the number of 1s.

If the parity rule is violated,

```
Error Detected
```

---

# Types of Parity

There are two types.

## 1. Even Parity

The total number of **1s (including the parity bit)** must be **even**.

---

## 2. Odd Parity

The total number of **1s (including the parity bit)** must be **odd**.

---

# Even Parity

## Rule

```
Total number of 1s = Even
```

---

### Example 1

Data

```
1011001
```

Count the number of 1s.

```
1 0 1 1 0 0 1

Number of 1s = 4
```

Already even.

Therefore

```
Parity Bit = 0
```

Transmitted Data

```
10110010
```

---

### Example 2

Data

```
1101001
```

Number of 1s

```
5
```

Odd.

Need one more 1.

Therefore

```
Parity Bit = 1
```

Transmission

```
11010011
```

Now

```
Total number of 1s = 6
```

Even.

---

# Odd Parity

## Rule

```
Total number of 1s = Odd
```

---

### Example 1

Data

```
1011001
```

Number of 1s

```
4
```

Need odd.

Parity Bit

```
1
```

Transmission

```
10110011
```

Total

```
5 Ones
```

Odd.

---

### Example 2

Data

```
1110001
```

Number of 1s

```
4
```

Need odd.

Parity Bit

```
1
```

Transmission

```
11100011
```

---

# Sender Algorithm

```
Count number of 1s

↓

Even Parity?

↓

YES

If count is Even

Parity = 0

Else

Parity = 1
```

# Receiver Algorithm

Receiver

```

↓

Count 1s

↓

Yes

```

# Error Detection Capability

VRC can detect

## Single-Bit Error

```
✓ Detected
```

Changing one bit always changes parity.

---

## Double-Bit Error

Example

```
1 → 0

and

0 → 1
```

Number of 1s remains unchanged.

Parity also remains unchanged.

Receiver accepts incorrect data.

```
✗ Not Detected
```

---

## Multiple-Bit Errors

If an **odd number of bits** changes,

```
Detected
```

If an **even number of bits** changes,

```
Not Detected
```

---

# Why?

Parity only checks whether

```
Number of 1s

↓

Even

or

Odd
```

If two bits change,

parity may remain unchanged.

---

# Error Detection Summary

| Error Type | Detection |
|------------|-----------|
| Single-Bit Error | ✅ Always |
| Odd Number of Bit Errors | ✅ Always |
| Even Number of Bit Errors | ❌ May Not Detect |
| Burst Error | ❌ Poor |

---

# Advantages

- Very simple
- Easy implementation
- Low overhead
- Requires only one extra bit
- Fast computation

---

# Disadvantages

- Cannot correct errors
- Cannot detect all multiple-bit errors
- Poor burst error detection
- Not reliable for noisy channels

---

# Applications

Used in

- RAM Memory
- Serial Communication
- Keyboard Communication
- Early Communication Systems

Modern networks generally prefer

- Checksum
- CRC

---

---

# Summary

- VRC adds one extra bit called the Parity Bit.
- Two types:
  - Even Parity
  - Odd Parity
- Detects all single-bit errors.
- Detects all odd-numbered bit errors.
- Cannot detect all even-numbered bit errors.
- Simple but less reliable than CRC.

---

# GATE Points ⭐

> [!important]
> VRC = Vertical Redundancy Check = Parity Check

---

> [!important]
> Detects all **single-bit errors**.

---

> [!important]
> Detects **odd number of bit errors**.

---

> [!warning]
> Does **NOT** detect every even-numbered bit error.

## Remember

> **Parity checks only whether the count of 1s is even or odd—it cannot determine which bit is wrong or correct the error.**
