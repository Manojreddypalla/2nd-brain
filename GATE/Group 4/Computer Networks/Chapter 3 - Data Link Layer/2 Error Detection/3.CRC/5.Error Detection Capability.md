# 3.2.6 Error Detection Capability of CRC

> [!summary]
> **CRC is one of the strongest error detection techniques because it can detect almost all common transmission errors, especially burst errors.**

---

# What is Error Detection Capability?

Error Detection Capability tells us:

> **"What types of errors can CRC detect?"**

Suppose the sender transmits

```
110110
```

During transmission, some bits change.

The receiver performs CRC division.

If the remainder is **not zero**, an error is detected.

---

# Types of Errors

## 1. Single-Bit Error

Only one bit changes.

Example

```
Original

110110

↓

Received

111110
```

Only one bit changed.

### CRC

✅ Detects **all single-bit errors**

---

## 2. Double-Bit Error

Two bits change.

Example

```
Original

110110

↓

Received

111100
```

Two bits changed.

### CRC

✅ Detects **most double-bit errors**

---

## 3. Odd Number of Bit Errors

Example

3 bits changed.

```
Original

110110

↓

Received

100111
```

### CRC

If the Generator contains the factor

```
(x + 1)
```

then

✅ Detects **all odd-bit errors**

> [!note]
> You don't need to perform polynomial calculations for GATE.
> Just remember this rule.

---

## 4. Burst Error ⭐⭐⭐

Most important for GATE.

A **Burst Error** means multiple consecutive bits are corrupted.

Example

```
Original

1101011010

↓

Received

1100100010
```

Several adjacent bits changed.

### CRC

✅ Excellent at detecting burst errors.

This is the biggest advantage of CRC.

---

# Burst Error Detection Rule ⭐⭐⭐

Suppose

```
Generator Length = r + 1
```

Then

### Rule 1

CRC detects

```
All burst errors

Length ≤ r
```

100% guaranteed.

---

### Rule 2

If

```
Burst Length = r + 1
```

CRC detects **almost all** errors.

---

### Rule 3

If

```
Burst Length > r + 1
```

CRC still detects the vast majority of errors.

The probability of missing an error is

```
1 / 2^r
```

which is very small.

---

# Example

Generator

```
10011
```

Length

```
5 bits
```

Therefore

```
r = 4
```

CRC guarantees detection of

```
Burst Errors

Length ≤ 4
```

# Summary Table

| Error Type | CRC Detection |
|------------|---------------|
| Single-bit Error | ✅ Always |
| Double-bit Error | ✅ Most Cases |
| Odd-bit Errors | ✅ If Generator contains (x + 1) |
| Burst Error ≤ r | ✅ Always |
| Burst Error > r | ✅ Very High Probability |

# Why is CRC Better than Checksum?

| Checksum | CRC |
|----------|-----|
| Uses Addition | Uses Polynomial Division |
| Good Detection | Excellent Detection |
| Weak for Burst Errors | Strong for Burst Errors |

# GATE Corner ⭐⭐⭐

- CRC detects **all single-bit errors**.
- CRC detects **most double-bit errors**.
- CRC detects **all burst errors of length ≤ r**, where **r = Generator Length − 1**.
- If the Generator contains **(x + 1)**, CRC detects **all odd-bit errors**.
- CRC is the **strongest error detection technique** among VRC, LRC, Checksum, and CRC.
