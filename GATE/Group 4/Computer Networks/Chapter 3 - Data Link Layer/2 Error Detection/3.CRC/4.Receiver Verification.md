# Receiver Verification

> [!summary]
> The receiver divides the **received codeword** by the same Generator.

If the remainder is

```
0
```

↓

No Error

Otherwise

```
Non-zero
```

↓

Error Detected

---

## Example

Sender transmitted

```
110110
```

Generator

```
101
```

Receiver performs

```
          (Ignore Quotient)
      _______________
101 ) 110110
```

Perform the same Modulo-2 Division.

Suppose the final remainder becomes

```
00
```

Then

```
No Error
```

If the final remainder becomes

```
10
```

or

```
01
```

or

```
11
```

Then

```
Error Detected
```

# Easy Memory Trick

Sender

```
Data

↓

Find CRC

↓

Append CRC

↓

Transmit
```

Receiver

```
Receive Codeword

↓

Divide Again

↓

Remainder = 0 ?

↓

YES → Accept

NO → Reject
```
