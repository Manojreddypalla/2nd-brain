# CRC Sender Algorithm

> [!summary]
> The sender generates the CRC and appends it to the data before transmission.

---

## Algorithm

```
Original Data

↓

Append (Generator Length - 1) Zeros

↓

Modulo-2 Division (XOR)

↓

Remainder = CRC

↓

Append CRC to Original Data

↓

Transmit Codeword
```

---

## Example

Given

```
Data = 1101

Generator = 101
```

Generator Length

```
3
```

Append

```
2 zeros
```

Dividend

```
110100
```

Modulo-2 Division

```
          101
      ___________
101 ) 110100
      101
      ---
       011
        ↓
       111
       101
       ---
        010
         ↓
        100
        101
        ---
         001
          ↓
         010
```

Remainder

```
10
```

CRC

```
10
```

Codeword

```
1101 + 10

↓

110110
```
