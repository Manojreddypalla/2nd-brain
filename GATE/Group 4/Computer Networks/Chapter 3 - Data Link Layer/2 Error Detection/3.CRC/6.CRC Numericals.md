# 3.2.7 CRC Numericals

> [!summary]
> **CRC Numericals = Normal Long Division**
>
> The only difference is:
>
> ```
> Subtraction (-)
>
> ↓
>
> XOR (⊕)
> ```

---

# Steps to Solve Any CRC Numerical

```
Step 1

Write the Data

↓

Step 2

Append (Generator Length - 1) Zeros

↓

Step 3

Perform Long Division using XOR

↓

Step 4

Remainder = CRC

↓

Step 5

Codeword = Data + CRC
```

---

# Numerical 1 (Easy)

### Given

```
Data = 1101

Generator = 101
```

---

## Step 1

Generator Length

```
101
```

Length = **3**

Append

```
3 - 1 = 2 zeros
```

Dividend

```
110100
```

---

## Step 2

Perform Modulo-2 Division

```
          101
      ___________
101 ) 110100
      101
      ---
       011
        ↓ Bring down 1

       111
       101
       ---
        010
         ↓ Bring down 0

        100
        101
        ---
         001
          ↓ Bring down 0

         010
```

No more bits remain.

---

## Step 3

Remainder

```
10
```

Therefore

```
CRC = 10
```

---

## Step 4

Codeword

```
Data

1101

CRC

10

↓

110110
```

---

# Receiver Verification

Received

```
110110
```

Generator

```
101
```

Perform the same division.

```
          (Ignore Quotient)
      ___________
101 ) 110110
```

Final Remainder

```
00
```

Therefore

```
No Error
```

# Exam Tips

✔ Ignore the Quotient.

✔ Never use subtraction.

✔ Always use XOR.

✔ Bring down one bit at a time.

✔ Final remainder = CRC.

✔ Receiver divides the complete codeword again.

✔ If remainder = 0 → Accept.

Otherwise → Reject.
