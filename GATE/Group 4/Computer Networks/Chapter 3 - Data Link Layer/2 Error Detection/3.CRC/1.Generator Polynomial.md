# 3.2.4 Generator Polynomial (CRC)

> [!summary]
> **Think of CRC exactly like school long division.**
>
> - **Dividend** = Data + Appended Zeros
> - **Divisor** = Generator Polynomial
> - **Subtraction** = XOR
> - **Quotient** = Ignore
> - **Remainder** = CRC

---

# What is a Generator Polynomial?

A **Generator Polynomial** is simply the **divisor** used during CRC division.

Just like in decimal division:

```
      5
   ______
5 ) 27
```

- Dividend = 27
- Divisor = 5

Similarly, in CRC:

```
         101
     __________
101 ) 110100
```

- Dividend = 110100
- Divisor = **101 (Generator Polynomial)**

> [!important]
> **Generator Polynomial = Divisor**

---

# Why is it called a Polynomial?

For GATE numericals,

**Don't worry about the word "Polynomial".**

Simply remember:

```
Generator Polynomial = Divisor
```

Later, we'll study the mathematical reason behind the name.

---

# Where does the Generator come from?

The Generator is **predefined by the communication protocol**.

Examples:

- Ethernet → Uses a standard CRC-32 Generator
- USB → Uses another Generator
- HDLC → Uses another Generator

In GATE questions,

> **The Generator is always given.**

Example:

```
Data      = 110101
Generator = 1011
```

# Generator Rules (GATE)

## Rule 1

The first bit is always **1**.

✔ Valid

```
101
10011
11001
```

✘ Invalid

```
0011
0101
```

---

## Rule 2

The last bit is always **1**.

✔ Valid

```
101
10011
11101
```

✘ Invalid

```
1010
11010
```

---

# CRC Length Rule ⭐⭐⭐

If Generator has

```
n bits
```

Then

```
CRC Length = n - 1 bits
```

Examples

| Generator | Length | CRC Length |
|-----------|--------|------------|
| 11 | 2 | 1 |
| 101 | 3 | 2 |
| 1011 | 4 | 3 |
| 10011 | 5 | 4 |

# Memory Trick

Think of CRC as normal long division.

```
Decimal Division

Dividend ÷ Divisor

↓

Quotient
Remainder
```

CRC

```
(Data + Zeros)

÷

Generator Polynomial

↓

Ignore Quotient

Keep Remainder
```

Only one thing changes:

```
Normal Division

Subtraction (-)

↓

CRC Division

XOR (⊕)
```

Everything else remains exactly the same.

---

# GATE Corner ⭐⭐⭐

- Generator Polynomial = Divisor
- Generator is predefined by the protocol.
- If Generator has **n bits**, CRC has **n − 1 bits**.
- Generator always starts with **1**.
- Generator always ends with **1**.
- During division, the Generator never changes.

---

# Quick Revision

```
Generator Polynomial

↓

Acts as Divisor

↓

Append (Generator Length - 1) Zeros

↓

Perform Long Division

↓

Replace (-) with XOR

↓

Ignore Quotient

↓

Remainder = CRC
```
