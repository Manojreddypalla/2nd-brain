# 3.3.4 Hamming Code Numericals

> [!summary]
> Hamming Code numericals are generally of two types:
>
> 1. **Generate the Hamming Code (Sender Side)**
> 2. **Detect & Correct the Error (Receiver Side)**

---

# Type 1: Generate Hamming Code

## Problem

Generate the Hamming Code for

```
Data = 1011
```

using **Even Parity**.

---

## Step 1: Find Number of Parity Bits

Formula

```
2^r ≥ m + r + 1
```

where

```
m = Number of Data Bits

r = Number of Parity Bits
```

Given

```
m = 4
```

Try

```
r = 2

2² = 4

4 ≥ 7

❌
```

Try

```
r = 3

2³ = 8

8 ≥ 8

✅
```

Therefore

```
Parity Bits = 3
```

---

## Step 2: Place Parity Bits

Parity bits occupy powers of 2.

```
1
2
4
```

Table

| Position | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|----------|---|---|---|---|---|---|---|
| Bit | P1 | P2 | D1 | P4 | D2 | D3 | D4 |

---

## Step 3: Insert Data Bits

Data

```
1011
```

Fill only data positions.

| Position | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|----------|---|---|---|---|---|---|---|
| Bit | P1 | P2 | 1 | P4 | 0 | 1 | 1 |

---

## Step 4: Calculate P1

P1 checks

```
1
3
5
7
```

Bits

```
P1
1
0
1
```

Current Ones

```
1 + 0 + 1 = 2
```

Already Even

Therefore

```
P1 = 0
```

---

## Step 5: Calculate P2

P2 checks

```
2
3
6
7
```

Bits

```
P2
1
1
1
```

Current Ones

```
3
```

Odd

Need Even

Therefore

```
P2 = 1
```

---

## Step 6: Calculate P4

P4 checks

```
4
5
6
7
```

Bits

```
P4
0
1
1
```

Current Ones

```
2
```

Already Even

Therefore

```
P4 = 0
```

---

## Final Hamming Code

| Position |1|2|3|4|5|6|7|
|----------|-|-|-|-|-|-|-|
| Bit |0|1|1|0|0|1|1|

```
0110011
```

## Step 4: Form Syndrome

# How to Remember Syndrome

```
P4

↓

Most Significant Bit
```

```
P2

↓

Middle Bit
```

```
P1

↓

Least Significant Bit
```

Example

```
P4 = 1

P2 = 0

P1 = 1
```

```
101₂

↓

5
```

Error at

```
Bit 5
```

### Trick 1

### Trick 2

```

P2

```

---

### Trick 3

```

```

(not reverse)

### Trick 4


# Common Mistakes

❌ Forgetting the formula

```
2^r ≥ m + r + 1
```

---

❌ Placing parity bits at wrong positions.

Correct

```
1
2
4
8
16...
```

---

❌ Skipping parity bit while checking.

Remember

```
Parity Bit always checks itself first.
```

---

❌ Writing syndrome in wrong order.

Correct

```
P8 P4 P2 P1
```

---

❌ Forgetting to flip the erroneous bit.
