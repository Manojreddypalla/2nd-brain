# 3.3.1 Hamming Distance

> [!summary]
> **Hamming Distance (HD)** is the **number of bit positions at which two binary strings of equal length differ.**
>
> It measures how many bits must be changed to convert one binary string into another.

---

# Intuition

Think of two words:

```
CAT
BAT
```

Only one letter is different.

```
Distance = 1
```

Similarly, for binary strings:

```
1011001
1011101
```

Only one bit differs.

```
Hamming Distance = 1
```

---

# Definition

> Hamming Distance is the **count of differing bit positions** between two binary strings of equal length.

---

# How to Calculate Hamming Distance

## Step 1

Write both binary strings one below the other.

```
101101
100111
```

---

## Step 2

Compare each bit position.

```
101101
100111
  ^  ^
```

---

## Step 3

Count the differing positions.

```
Hamming Distance = 2
```

---

# Examples

## Example 1

```
1010
1011
```

Comparison

```
1010
1011
   ^
```

```
HD = 1
```

---

## Example 2

```
111100
101110
```

Comparison

```
111100
101110
 ^
   ^
```

```
HD = 2
```

---

## Example 3

```
10010110
11100111
```

Comparison

```
10010110
11100111
 ^^  ^ ^
```

Different Positions:

- Bit 2
- Bit 3
- Bit 6
- Bit 8

```
HD = 4
```

---

# Important Observations

### 1. Compare Position by Position

Hamming Distance depends on **bit positions**, not on the number of 1s.

Example

```
1111
0000
```

All four positions differ.

```
HD = 4
```

---

### 2. Strings Must Have Equal Length

Valid

```
101101
100111
```

Invalid

```
1011
100101
```

Different lengths cannot be directly compared.

---

# Why is Hamming Distance Important?

Hamming Distance tells us how many errors a code can detect and correct.

A larger Hamming Distance means a more reliable code.

---

# Applications

- Hamming Code
- Error Detection
- Error Correction
- Digital Communication
- Computer Networks
- Memory Error Detection (ECC RAM)
- Satellite and Wireless Communication

---

# GATE Corner ⭐⭐⭐

### Detection Rule

A code with minimum Hamming Distance **d** can detect

```
d − 1
```

errors.

---

### Correction Rule

A code with minimum Hamming Distance **d** can correct

```
⌊(d − 1) / 2⌋
```

errors.

> [!warning]
> These formulas are the **most important part** of Hamming Distance for GATE.
> We'll derive and understand them in the next topic rather than memorizing them.

---

# Common Mistakes

❌ Counting the number of 1s instead of differing positions.

❌ Comparing binary strings of unequal length.

❌ Confusing Hamming Distance with the number of errors that can be corrected.
