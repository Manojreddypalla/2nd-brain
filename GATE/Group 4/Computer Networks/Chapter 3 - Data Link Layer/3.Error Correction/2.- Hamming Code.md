# 3.3.2 Hamming Code

> [!summary]
> **Hamming Code** is an **error correction technique** that can **detect up to two-bit errors** and **correct one-bit error** by adding parity bits to the data.

---

# Why Hamming Code?

CRC can only tell us

```
An error occurred.
```

It **cannot tell which bit is wrong**.

Hamming Code can tell us

```
Which bit is wrong
```

and then

```
Correct it.
```

---

# Basic Idea

Instead of transmitting only data bits,

```
1011
```

we insert additional **Parity Bits**.

```
P1  P2  D1  P4  D2  D3  D4
```

where

```
P = Parity Bit

D = Data Bit
```

---

# Number of Parity Bits

If

```
m = Number of Data Bits

r = Number of Parity Bits
```

then

```
2^r ≥ m + r + 1
```

Choose the smallest value of **r** satisfying the inequality.

### Example

```
m = 4
```

Try

```
r = 2

2² = 4

4 ≥ 7

❌ No
```

Try

```
r = 3

2³ = 8

8 ≥ 8

✅ Yes
```

Therefore

```
Parity Bits = 3
```

---

# Placement of Parity Bits

Parity bits are always placed at positions that are powers of 2.

```
1
2
4
8
16
...
```

Example

| Position | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|----------|---|---|---|---|---|---|---|
| Bit | P1 | P2 | D1 | P4 | D2 | D3 | D4 |

---

# Filling the Data

Given

```
Data = 1011
```

Fill only the data positions.

| Position | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|----------|---|---|---|---|---|---|---|
| Bit | P1 | P2 | 1 | P4 | 0 | 1 | 1 |

Now calculate parity bits.

# ⭐ Most Common Mistake

> [!warning]
> **Always start from the parity bit itself.**
>
> Do **NOT** skip the parity bit.

Correct

```
P2

↓

Take

2
3

↓

Skip

4
5

↓

Take

6
7
```

Incorrect

```
Skip

2
3

↓

Take

4
5
```

Remember

> **Every parity bit checks itself first.**

---

# Receiver Side

Receiver recalculates all parity bits.

The result forms the **Syndrome**.

```
000

↓

No Error
```

Non-zero syndrome

```
↓

Binary value

↓

Position of Error

↓

Flip that Bit

↓

Correct Data
```

Example

```
Syndrome = 110₂

↓

Bit Position = 6

↓

Correct Bit 6
```

---

# Error Detection & Correction Capability

Standard Hamming Code

✅ Corrects **1-bit error**

✅ Detects **2-bit errors**

❌ Cannot correct multiple-bit errors
