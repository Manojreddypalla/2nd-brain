# 3.3.3 Error Detection vs Error Correction

> [!summary]
> **Error Detection** identifies whether an error has occurred during transmission.
>
> **Error Correction** identifies the error **and** recovers the original data without retransmission (for supported error patterns).

---

# Why Do We Need Error Detection and Correction?

During transmission, data may get corrupted due to:

- Noise
- Signal Interference
- Electromagnetic Disturbance
- Hardware Faults

The receiver must determine whether the received data is correct.

There are two approaches:

```
Error Detection

↓

Detect the error only
```

or

```
Error Correction

↓

Detect + Correct the error
```

---

# Error Detection

Error Detection answers one question:

> **"Did an error occur?"**

If an error is detected,

```
Reject Frame

↓

Request Retransmission
```

The receiver **cannot determine which bit is wrong**.

---

## Examples

- VRC
- LRC
- Checksum
- CRC

---

## CRC Example

Sender transmits

```
110110
```

Receiver divides using the same Generator.

```
Remainder = 101
```

Since

```
Remainder ≠ 0
```

Receiver concludes

```
Error Detected
```

But CRC cannot determine:

- Which bit changed?
- What should the correct value be?

Therefore,

```
Retransmission Required
```

---

# Error Correction

Error Correction answers two questions:

> **Did an error occur?**

and

> **Which bit is wrong?**

After locating the incorrect bit,

```
Flip the Bit

↓

Recover Original Data
```

No retransmission is required for a single-bit error.

---

## Example

Original

```
1011011
```

Received

```
1010011
```

Hamming Code determines

```
Bit 4 is incorrect.
```

Receiver flips Bit 4.

Correct data is recovered.

---

# How Does Hamming Code Correct Errors?

Hamming Code adds **Parity Bits** to the transmitted data.

Parity bits are placed at positions

```
1
2
4
8
16
...
```

Each parity bit checks a specific group of bits.

---

# Parity Coverage

```
P1

↓

1 3 5 7 9 ...
```

```
P2

↓

2 3 6 7 10 11 ...
```

```
P4

↓

4 5 6 7 12 13 14 15 ...
```

```
P8

↓

8 9 10 11 12 13 14 15 ...
```

---

# CCTV Camera Analogy ⭐

Think of every parity bit as a **CCTV camera**.

```
P1

Watching

1 3 5 7
```

```
P2

Watching

2 3 6 7
```

```
P4

Watching

4 5 6 7
```

Suppose **Bit 6** becomes corrupted.

Which parity bits detect the error?

```
P1

↓

No
```

```
P2

↓

Yes
```

```
P4

↓

Yes
```

Receiver obtains

```
P4 = Error

P2 = Error

P1 = Correct
```

Syndrome

```
110₂
```

Convert to decimal

```
110₂ = 6
```

Therefore

```
Bit Position = 6
```

Receiver flips Bit 6.

Original data is restored.

---

# Syndrome

The collection of parity check results is called the **Syndrome**.

```
Parity Check Results

↓

Syndrome

↓

Binary Number

↓

Error Position
```

---

# Why Does Hamming Code Work?

Every bit position has a **unique parity combination**.

| Bit Position | Checked by |
|--------------|------------|
| 1 | P1 |
| 2 | P2 |
| 3 | P1, P2 |
| 4 | P4 |
| 5 | P1, P4 |
| 6 | P2, P4 |
| 7 | P1, P2, P4 |

Since every position has a unique combination,

```
Syndrome

↓

Unique Binary Number

↓

Unique Error Position
```

This allows Hamming Code to locate the erroneous bit.

---

# Comparison

| Error Detection | Error Correction |
|-----------------|------------------|
| Detects whether an error occurred | Detects and corrects the error |
| Cannot identify the incorrect bit | Identifies the incorrect bit |
| Requires retransmission | No retransmission for single-bit errors |
| Simpler implementation | More complex implementation |
| Examples: CRC, Checksum, VRC, LRC | Example: Hamming Code |

---

# Advantages of Error Detection

- Simple implementation
- Low overhead
- Suitable when retransmission is possible
- Efficient for computer networks

---

# Advantages of Error Correction

- No retransmission required for single-bit errors
- Faster recovery
- Essential where retransmission is expensive or impossible
- Used in memory systems and space communication

---

# Applications

## Error Detection

- Ethernet (CRC)
- Internet Protocols
- File Integrity Checking
- Data Communication

---

## Error Correction

- ECC RAM

- Deep Space Communication

- Wireless Communication
