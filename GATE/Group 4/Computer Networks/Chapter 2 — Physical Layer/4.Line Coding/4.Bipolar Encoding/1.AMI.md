# AMI (Alternate Mark Inversion)

## Why AMI was introduced?

In **Unipolar** and **Polar NRZ** encoding, long sequences of identical bits create problems:

- Poor synchronization
- DC component
- Baseline wandering
- Difficult long-distance transmission

To overcome these issues, **AMI (Alternate Mark Inversion)** was introduced.

---

# Intuition

Imagine you're switching a light ON.

Instead of turning ON with the **same voltage every time**, you alternate the voltage.

```
1st ON  → +V

2nd ON  → -V

3rd ON  → +V

4th ON  → -V
```

Every **0** means the light stays OFF.

```
0 → 0 V
```

So only **1s generate pulses**, and every pulse changes polarity.

This keeps the average voltage close to **0**, eliminating the DC component.

---

# Definition

**AMI (Alternate Mark Inversion)** is a **bipolar line coding scheme** in which:

- Binary **0** is represented by **0 V**.
- Binary **1** (called a *Mark*) is represented alternately by **+V** and **−V**.

---

# Why is it called AMI?

### Alternate

The voltage alternates.

```
+V

↓

-V

↓

+V

↓

-V
```

---

### Mark

In telecommunication,

```
Mark = Binary 1

Space = Binary 0
```

---

### Inversion

Every new **1** uses the opposite polarity.

```
Previous 1 = +V

Next 1 = -V

Next 1 = +V
```

Hence,

**Alternate Mark Inversion.**

# Characteristics

## 1. Bipolar Encoding

Uses **three voltage levels**

```
+V

0V

-V
```

---

## 2. 0 has No Pulse

```
0

↓

0 Volt
```

---

## 3. 1 Alternates

```
1

↓

+V

↓

-V

↓

+V

↓

-V
```

---

## 4. Average Voltage ≈ 0

Positive and negative pulses cancel each other.

```
(+V)+(-V)=0
```

Hence,

No DC Component.

---

## 5. Better Synchronization

Every **1** creates a transition.

Receiver can recover clock more easily.

---

# Advantages

## No DC Component

Positive and negative voltages balance each other.

Ideal for transformer coupling.

---

## Better Synchronization

Transitions occur whenever **1** appears.

---

## Error Detection

Suppose two consecutive **1s** become

```
+V

+V
```

This is impossible in AMI.

Receiver immediately knows an error occurred.

This is called a

**Bipolar Violation (BPV).**

---

## Lower Baseline Wander

Since average voltage is zero,

Baseline wandering is reduced.

---

## Widely Used

Used in

- T1 Lines
- E1 Lines
- Digital Telephony

---

# Disadvantages

## Long Sequence of Zeros

Example

```
0000000000
```

Signal

```
0V

0V

0V

0V

0V
```

No transitions.

Receiver may lose synchronization.

---

## Needs Scrambling

To solve long zero problems,

AMI is often combined with

- **B8ZS**
- **HDB3**

These replace long runs of zeros with special pulse patterns.

---

# AMI vs Polar NRZ

| Feature | Polar NRZ | AMI |
|----------|-----------|-----|
| Voltage Levels | +V, −V | +V, 0, −V |
| 0 | −V (or +V) | 0 V |
| 1 | Fixed level | Alternating +V/−V |
| DC Component | Present | Nearly Zero |
| Synchronization | Poor | Better |
| Error Detection | No | Yes (BPV) |

---

# GATE Corner ⭐

Remember these points:

- AMI is a **Bipolar Encoding**.
- **0 → 0 V**
- **1 → Alternate between +V and −V**
- No DC Component.
- Long runs of **0s** are a problem.
- Solved using **B8ZS** or **HDB3**.
- Consecutive pulses with the **same polarity** indicate a **Bipolar Violation (BPV)**.

---

# Common GATE Traps

❌ "1 is always +V"

Wrong.

It alternates.

---

❌ "AMI has two voltage levels"

Wrong.

It has **three**.

---

❌ "AMI has no synchronization problem"

Wrong.

Long runs of **0s** still cause synchronization issues.

---

❌ "0 alternates"

Wrong.

Only **1s** alternate.

# Memory Trick 🧠

Think of a person climbing stairs.

```
Step 1

+

↓

Step 2

-

↓

Step 3

+

↓

Step 4

-
```

Every time you step (**1**),

you switch direction.

Standing still (**0**) means no pulse.
