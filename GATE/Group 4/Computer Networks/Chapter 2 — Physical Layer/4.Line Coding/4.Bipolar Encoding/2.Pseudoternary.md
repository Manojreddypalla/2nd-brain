# Pseudoternary Encoding

## Why Pseudoternary?

AMI solves the **DC component** problem by alternating the voltage for **1s**.

But what if we alternate the voltage for **0s** instead?

That is exactly what **Pseudoternary Encoding** does.

It is essentially the **reverse of AMI**.

---

# Intuition

Imagine two people playing a game.

- Whenever a **0** appears, they alternately raise their **left hand (+V)** and **right hand (−V)**.
- Whenever a **1** appears, they keep both hands down (**0 V**).

So,

```
0 → +V

Next 0 → -V

Next 0 → +V

Next 0 → -V
```

While

```
1 → 0 V
```

Only **0s generate pulses**, and their polarity alternates.

---

# Definition

**Pseudoternary** is a **bipolar line coding scheme** in which:

- Binary **1** is represented by **0 V**.
- Binary **0** is represented alternately by **+V** and **−V**.

It is the **complement (reverse)** of AMI.

---

# Voltage Representation

| Bit | Voltage |
|------|---------|
| 1 | 0 V |
| 0 | +V or −V (Alternating) |

---

# Example

### Data

```text
0 1 0 0 1 0
```

### Encoding

```text
0 → +V

1 → 0V

0 → -V

0 → +V

1 → 0V

0 → -V
```

### Signal

```text
+V ───            ───
       │
0V      ───────         ───────
             │                │
-V         ───            ───
```

---

# Characteristics

## 1. Bipolar Encoding

Uses **three voltage levels**:

- +V
- 0 V
- −V

---

## 2. 1 has No Pulse

```
1

↓

0 V
```

---

## 3. 0 Alternates

```
0

↓

+V

↓

-V

↓

+V

↓

-V
```

---

## 4. No DC Component

Positive and negative pulses balance each other.

Average voltage is approximately **0 V**.

---

## 5. Better Synchronization

Transitions occur whenever **0** appears.

---

# Advantages

- No DC component.
- Better synchronization than unipolar schemes.
- Supports error detection using **bipolar violations**.
- Reduces baseline wandering.

---

# Disadvantages

## Long Sequence of 1s

Example:

```text
11111111
```

Signal:

```text
0V 0V 0V 0V 0V 0V 0V 0V
```

No transitions occur.

Receiver may lose synchronization.

---

## Requires Scrambling

Long runs of **1s** may require additional techniques to maintain synchronization.

---

# Pseudoternary vs AMI

| Feature | AMI | Pseudoternary |
|----------|-----|---------------|
| 0 | 0 V | Alternating +V / −V |
| 1 | Alternating +V / −V | 0 V |
| Voltage Levels | +V, 0, −V | +V, 0, −V |
| DC Component | Nearly Zero | Nearly Zero |
| Long Sequence Problem | Long 0s | Long 1s |

---

# GATE Corner ⭐

- **Pseudoternary is the reverse of AMI.**
- Uses **three voltage levels**: +V, 0 V, −V.
- **0 → Alternate +V and −V.**
- **1 → 0 V.**
- No DC component.
- Long runs of **1s** cause synchronization problems.

---

# Common GATE Traps

❌ "Pseudoternary alternates 1s."

**Wrong.** It alternates **0s**.

---

❌ "Pseudoternary uses only two voltage levels."

**Wrong.** It uses **three**.

---

❌ "AMI and Pseudoternary are identical."

**Wrong.** They are **complements** of each other.

---

# Memory Trick 🧠

Think of **Pseudo = Opposite of AMI**.

- **AMI** → **1 alternates**, **0 = 0 V**
- **Pseudoternary** → **0 alternates**, **1 = 0 V**
