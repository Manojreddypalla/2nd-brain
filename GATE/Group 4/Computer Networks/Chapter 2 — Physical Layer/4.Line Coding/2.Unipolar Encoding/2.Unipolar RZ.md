# Unipolar RZ (Return-to-Zero) — GATE Quick Notes

## Definition

**Unipolar RZ** is a line coding scheme where only **one positive voltage level** is used, and the signal **returns to 0 V in the middle of every bit interval**.

- **1 → +V for first half, then 0 V**
- **0 → 0 V for entire bit interval**

---

## Representation

| Bit | Voltage |
|------|---------|
| 1 | +V → 0 V |
| 0 | 0 V |

### Example

Data:

```text
1 0 1 1 0
```

Signal:

```text
+V  ─┐      ─┐ ─┐
     │      │  │
0V ──┴──────┴──┴──────
```

(Each **1** returns to **0 V** in the middle of the bit.)

---

## Characteristics

- Uses **one polarity** (+V and 0 V).
- Returns to **0 V** during every bit interval.
- Provides better synchronization than Unipolar NRZ.
- Requires more bandwidth than NRZ.

---

## Advantages

- Better clock synchronization due to frequent transitions.
- Easier for the receiver to detect bit boundaries.

---

## Disadvantages

- ❌ Higher bandwidth requirement.
- ❌ DC component still exists.
- ❌ More power consumption than NRZ.
- ❌ Less efficient bandwidth utilization.

---

## GATE Facts ⭐

- **Unipolar** → Only one voltage polarity (+V).
- **RZ** → Signal returns to **0 V** in the middle of every bit.
- Better synchronization than **Unipolar NRZ**.
- Requires **more bandwidth** than NRZ.

---

## Memory Trick 🧠

- **Uni** → One polarity
- **RZ** → Return to Zero

So,

- **1 = +V → 0 V**
- **0 = 0 V**

---

## One-Line Revision

**Unipolar RZ uses +V for '1' and returns to 0 V in the middle of the bit, while '0' remains at 0 V throughout.**
