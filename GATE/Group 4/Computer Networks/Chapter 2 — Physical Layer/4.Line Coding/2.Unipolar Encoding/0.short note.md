# Unipolar NRZ vs Unipolar RZ (GATE Quick Notes)

## Intuition

Imagine each bit occupies **1 second**.

### Unipolar NRZ (No Return to Zero)

- If the bit is **1**, the signal stays **HIGH for the entire bit duration**.
- If the bit is **0**, the signal stays at **0 V**.

```text
Bit:      |   1   |   0   |   1   |

Voltage:  +V──────      +V──────
           │            │
0V─────────┘────────────┘─────────
```

**Idea:** Once it goes HIGH, it **doesn't return to zero** until the next bit changes.

---

### Unipolar RZ (Return to Zero)

- If the bit is **1**, the signal goes **HIGH only for the first half**, then returns to **0 V**.
- If the bit is **0**, it stays at **0 V**.

```text
Bit:      |   1   |   0   |   1   |

Voltage:  +V──    +V──
           │      │
0V─────────┴──────┴──────────────
```

**Idea:** Every **1** gives a short pulse and then immediately returns to zero.

---

# Comparison

| Feature | Unipolar NRZ | Unipolar RZ |
|---------|---------------|-------------|
| 1 | +V (entire bit) | +V then 0 V |
| 0 | 0 V | 0 V |
| Return to Zero | ❌ No | ✅ Yes |
| Synchronization | Poor | Better |
| Bandwidth | Lower | Higher |
| DC Component | High | High (reduced compared to NRZ, but still present) |

---

# GATE Memory Trick 🧠

### NRZ

**1 → Stay HIGH**

```text
+V ───────
```

**NRZ = No Return to Zero**

---

### RZ

**1 → HIGH then ZERO**

```text
+V ──
     │
0V ──┴──
```

**RZ = Return to Zero**

---

# One-Line Revision

- **Unipolar NRZ:** **1 = +V throughout the bit**, **0 = 0 V**.
- **Unipolar RZ:** **1 = +V for half the bit then 0 V**, **0 = 0 V**.
