# Unipolar NRZ (Non-Return-to-Zero) — GATE Quick Notes

## Definition

**Unipolar NRZ** is a line coding scheme where only **one positive voltage level** is used to represent binary data.

- **1 → +V**
- **0 → 0 V**

The signal **does not return to zero** between consecutive bits.

---

## Representation

| Bit | Voltage |
|-----|---------|
| 1 | +V |
| 0 | 0 V |

### Example

Data:

```text
1 0 1 1 0
```

Signal:

```text
+V ───      ─────────
      │      │
0V    └──────┘      ───
```

---

## Characteristics

- Uses **one polarity** (+V and 0 V).
- Signal remains constant during one bit interval.
- Does **not** return to zero after each bit.
- Simple to implement.

---

## Advantages

- Simple encoder and decoder.
- Low implementation cost.
- Requires less bandwidth than RZ.

---

## Disadvantages

- ❌ Large DC component.
- ❌ Poor synchronization for long sequences of 1s or 0s.
- ❌ Not suitable for long-distance communication.
- ❌ Baseline wandering may occur.

---

## GATE Facts ⭐

- **Unipolar** → Only one voltage polarity (+V).
- **NRZ** → Signal does **not** return to 0 V during a bit interval.
- Long runs of identical bits cause synchronization problems.
- Has a significant **DC component**.

---

## Memory Trick 🧠

- **Uni** → One polarity
- **NRZ** → No Return to Zero

So,

**1 = +V**, **0 = 0 V**

---

## One-Line Revision

**Unipolar NRZ uses +V for '1' and 0 V for '0', without returning to zero during each bit interval.**
