# 2.4.3.3 Polar RZ (Return-to-Zero)

---

## What is Polar RZ?

Polar RZ (Return-to-Zero) is a line coding scheme that uses **positive (+V)** and **negative (-V)** voltages like other Polar schemes.

The key difference is:

> **The signal always returns to 0 V before the end of every bit period.**

Hence the name **Return-to-Zero (RZ).**

---

## Encoding Rule

| Bit | Signal |
|-----|--------|
| 1 | +V → 0V |
| 0 | -V → 0V |

Each bit occupies one bit interval.

During the **first half**, the signal carries the bit.

During the **second half**, it returns to **0 V**.

---

## Example

Binary Data

```
1 0 1 1 0
```

Signal

```
+V  ┌─┐     ┌─┐ ┌─┐
    │ │     │ │ │ │
0V ─┘ └─────┘ └─┘ └────
       │       │
-V     └─┐         └─┐
         │           │
0V ──────┘───────────┘────
```

Every bit returns to **0 V** before the next bit starts.

---

## Characteristics

### Advantages

- Better clock synchronization
- Easier clock recovery
- Fewer synchronization errors than NRZ

---

### Disadvantages

### Higher Bandwidth

Since every bit contains an additional transition back to zero,

→ More signal changes

→ More bandwidth is required.

---

### More Complex

Generating and detecting RZ signals is more complicated than NRZ.

---

### Power Requirement

More transitions mean higher switching activity.

---

## Applications

Polar RZ is rarely used in modern LANs.

It is mainly studied to understand the evolution of line coding techniques.

---

# Comparison

| Feature | NRZ | Polar RZ |
|---------|-----|-----------|
| Return to Zero | ❌ | ✅ |
| Synchronization | Poor | Better |
| Bandwidth | Lower | Higher |
| Number of Transitions | Fewer | More |
| Complexity | Low | Moderate |
