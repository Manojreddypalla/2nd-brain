# Polar NRZ-L (Non-Return-to-Zero-Level) — GATE Quick Notes

## Intuition

Instead of using **+V and 0 V**, Polar NRZ-L uses **two opposite voltage levels**.

- One voltage level represents **1**
- The other voltage level represents **0**

The signal **stays at that level for the entire bit duration** (it does not return to zero).

---

## Representation (Common Convention)

| Bit | Voltage |
|------|---------|
| 1 | +V |
| 0 | −V |

> **Note:** Some books reverse the mapping (1 = −V, 0 = +V). The important concept is that **two opposite voltage levels are used**.

---

## Example

Data:

```text
1 0 1 1 0
```

Signal:

```text
+V ─────      ─────────
            │
0V ─────────────────────────── (Reference)

−V      ─────          ─────
```

---

## Characteristics

- Uses **two polarities** (+V and −V).
- Signal remains constant during one bit interval.
- No return to zero.
- Smaller DC component than Unipolar NRZ.
- Poor synchronization for long runs of identical bits.

---

## Advantages

- Better than Unipolar NRZ.
- Lower DC component.
- Simple implementation.
- Lower bandwidth than RZ.

---

## Disadvantages

- ❌ Long sequences of 0s or 1s cause synchronization problems.
- ❌ Not self-synchronizing.

---

## GATE Facts ⭐

- **Polar** → Uses **+V and −V**.
- **NRZ** → No return to zero.
- **L** → **Level** represents the bit value.
- Transition occurs **only when the bit value changes**, not because of the coding rule.

---

## Memory Trick 🧠

- **Polar** → Positive & Negative voltages
- **NRZ** → No Return to Zero
- **L** → **Level = Bit**

---

## One-Line Revision

**Polar NRZ-L represents bits using two voltage levels (+V and −V) and keeps the signal at that level for the entire bit interval without returning to zero.**
