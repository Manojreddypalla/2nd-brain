# 2.4.3 Polar Encoding

---

## What is Polar Encoding?

Unlike **Unipolar Encoding**, **Polar Encoding** uses **two voltage levels**:

- Positive Voltage (+V)
- Negative Voltage (-V)

There is **no 0 V level** for representing data (except in Polar RZ).

Using both positive and negative voltages:

- Reduces the DC component
- Improves transmission quality
- Provides better synchronization than Unipolar schemes

---

## Types of Polar Encoding

- NRZ-L
- NRZ-I
- Polar RZ
- Manchester
- Differential Manchester

---

# 2.4.3.1 Polar NRZ-L (Non-Return-to-Zero-Level)

## Idea

In **NRZ-L**, the **voltage level itself** represents the bit.

The receiver simply checks whether the signal is HIGH or LOW.

---

## Encoding Rule

| Bit | Voltage |
|-----|----------|
| 1 | +V |
| 0 | -V |

> **Note:** Some books reverse this mapping (1 → -V, 0 → +V). GATE questions always specify the convention if it matters. What matters is understanding that the **level** represents the bit.

---

## Example

Binary Data

```
1 0 1 1 0
```

Signal

```
+V ───      ─── ───
      │    │
-V ───┴────┘   └────
```

---

## Characteristics

### Advantages

- Simple implementation
- Lower bandwidth than Manchester
- Less DC component than Unipolar

---

### Disadvantages

### Long Sequence Problem

```
1111111111
```

or

```
0000000000
```

No transitions occur.

Receiver may lose clock synchronization.

---

### Error Detection

No built-in error detection.

---

# 2.4.3.2 Polar NRZ-I (Non-Return-to-Zero-Invert)

## Idea

NRZ-I does **not** look at the voltage level.

Instead, it checks **whether the signal changes**.

**I = Invert**

---

## Encoding Rule

| Bit | Action |
|-----|---------|
| 1 | Transition (Invert Voltage) |
| 0 | No Transition |

The starting voltage can be either +V or -V.

---

## Example

Assume starting voltage = -V

Binary

```
1 0 1 1 0
```

Signal

```
Start = -V

Bit 1 → Transition → +V
Bit 0 → Stay +V
Bit 1 → Transition → -V
Bit 1 → Transition → +V
Bit 0 → Stay +V
```

---

## Characteristics

### Advantages

- Better synchronization for long sequences of 1s
- Less affected by polarity inversion

---

### Disadvantages

Long sequence of **0s** still causes synchronization problems.

Example

```
0000000000
```

No transitions.

---

# NRZ-L vs NRZ-I

| Feature | NRZ-L | NRZ-I |
|---------|--------|--------|
| L stands for | Level | Invert |
| Bit represented by | Voltage Level | Transition |
| 1 | +V (or -V) | Transition |
| 0 | -V (or +V) | No Transition |
| Long 1s | Poor Sync | Better |
| Long 0s | Poor Sync | Poor Sync |
