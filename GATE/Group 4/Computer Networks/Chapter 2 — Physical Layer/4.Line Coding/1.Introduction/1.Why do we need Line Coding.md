# 📘 Line Coding

## Why do we need Line Coding?

Computers generate **binary data (0s and 1s)**, but a communication medium (wire, fiber, etc.) carries **electrical or optical signals**, not raw bits.

Therefore, we need a method to **convert binary data into digital signals** before transmission.

This conversion process is called **Line Coding**.

> [!important]
> **Line Coding = Binary Data → Digital Signal**

---

# Data vs Signal

```
Binary Data
10110010
      │
      ▼
Line Coding
      │
      ▼
Digital Signal
```

---

# Definition

**Line Coding** is the process of representing binary bits using predefined voltage levels or signal transitions.

---

# Why is Line Coding Important?

A good line coding scheme should:

- Represent 0 and 1 clearly.
- Allow synchronization between sender and receiver.
- Consume less bandwidth.
- Reduce transmission errors.
- Avoid long sequences of identical voltage levels.

---

# Characteristics of a Good Line Code

A good line code should have:

- Easy Clock Recovery (Synchronization)
- Low Bandwidth Requirement
- Low Error Rate
- No DC Component (preferred)
- Simple Implementation

---

# Types of Line Coding

There are three major categories.

```
                Line Coding
                     │
      ┌──────────────┼──────────────┐
      │              │              │
      ▼              ▼              ▼
    Unipolar      Polar         Bipolar
```

---

# 1. Unipolar Encoding

Uses only **one polarity**.

Example:

```
1 = +V
0 = 0V
```

Example:

```
Data

10110

Signal

+V 0 +V +V 0
```

### Advantages

- Very simple

### Disadvantages

- Poor synchronization
- Large DC component
- Not used in modern networks

---

# 2. Polar Encoding

Uses **positive and negative voltages**.

Example

```
1 = +V
0 = -V
```

Advantages

- Better synchronization
- Less DC component

Popular techniques:

- NRZ-L
- NRZ-I
- RZ
- Manchester
- Differential Manchester

---

# 3. Bipolar Encoding

Uses

- +V
- 0
- -V

Most common:

AMI (Alternate Mark Inversion)

Example

```
Data

101101

Signal

+V 0 -V +V 0 -V
```

Every successive **1** alternates between **+V** and **−V**.

Advantages

- No DC component
- Error detection possible

---

# Comparison

| Feature | Unipolar | Polar | Bipolar |
|----------|----------|-------|----------|
| Voltage Levels | 2 | 2 | 3 |
| DC Component | High | Low | Very Low |
| Synchronization | Poor | Good | Good |
| Used Today | Rare | Yes | Yes |

---

# Applications

- Ethernet
- LAN
- Optical Communication
- Digital Transmission Systems

Different standards use different line coding techniques.

---

# Important Note

> [!warning]
> **Line Coding is NOT Modulation.**

Line Coding:

```
Digital Data
        │
        ▼
Digital Signal
```

Modulation:

```
Digital Data
        │
        ▼
Analog Signal
```

# Formula Sheet

There is **no mathematical formula** for line coding.

Most GATE questions are **concept-based** and **waveform-based**.

---

# Common Mistakes

❌ Line Coding = Modulation

Wrong.

---

❌ Data = Signal

Wrong.

Data is information.

Signal is the physical representation.

---

❌ Bipolar means only +V and −V.

Wrong.

It uses **+V, 0, and −V**.
