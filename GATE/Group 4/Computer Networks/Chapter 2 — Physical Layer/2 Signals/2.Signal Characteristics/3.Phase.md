# Topic: Phase (GATE In-Depth Notes)

Phase is one of the **three fundamental characteristics of a signal**.

The other two are:

- Amplitude (A)
- Frequency (f)

Phase is extremely important for:

- Analog Signals
- Digital Signals
- Modulation (PSK)
- Synchronization
- Carrier Signals
- Fourier Analysis
- Communication Systems

Although GATE asks fewer direct questions on phase, it is an **important conceptual topic** and is frequently used in later chapters.

---

# 1. Intuition

Imagine two people start running around a circular track.

Runner A starts from

```
0°
```

Runner B starts from

```
90°
```

Both run at the **same speed**.

The only difference is

**Runner B started later (or from a different position).**

This starting position difference is called **Phase**.

---

Another example

Imagine two identical sine waves.

Wave 1

```text
     /\      /\
    /  \    /  \
___/____\__/____\____
```

Wave 2

```text
        /\      /\
       /  \    /  \
______/____\__/____\__
```

Both have

✔ Same amplitude

✔ Same frequency

But one starts later.

This difference is called **Phase Difference**.

---

# 2. Definition

**Phase** is the **position of a waveform relative to a reference point at a given instant of time.**

In simple words,

> **Phase tells us where a signal starts in its cycle.**

---

# 3. Mathematical Representation

A sinusoidal signal is written as

$$
x(t)=A\sin(2\pi ft+\phi)
$$

where

- **A** = Amplitude
- **f** = Frequency
- **φ (phi)** = Phase
- **t** = Time

The phase **φ** determines the starting position of the wave.

---

# 4. Understanding Phase

Suppose

### Phase = 0°

```text
     /\      /\
    /  \    /  \
___/____\__/____\____
```

Starts normally.

---

### Phase = 90°

```text
      /\      /\
_____/  \____/  \____
```

Shifted to the left by one-quarter cycle.

---

### Phase = 180°

```text
____      ____      ____
    \    /    \    /
     \__/      \__/
```

Wave is inverted.

---

### Phase = 270°

```text
\____      ____      ___
     \    /    \    /
      \__/      \__/
```

Shifted by three-fourths of a cycle.

---

# 5. Phase Shift

When one signal is shifted with respect to another, it is called **Phase Shift**.

Example

```text
Signal A

     /\      /\
____/  \____/  \____
```

```text
Signal B

       /\      /\
______/  \____/  \____
```

Signal B is **phase shifted**.

# 7. Phase Does NOT Change

Changing phase

✔ Changes the starting position

❌ Does NOT change amplitude

❌ Does NOT change frequency

Example

All these waves have

- Same amplitude
- Same frequency

Only the phase changes.

# GATE Corner ⭐

## Definition

**Phase** is the **starting position of a signal in its cycle relative to a reference point.**

---

## Signal Equation

$$
x(t)=A\sin(2\pi ft+\phi)
$$

where

**φ** represents the phase.

---

## Key Facts

- Phase determines the **horizontal shift** of a waveform.
- Measured in **degrees** or **radians**.
- Changing phase does **not** change amplitude.
- Changing phase does **not** change frequency.
- Two signals can have the same amplitude and frequency but different phases.

---

## Common GATE Traps

❌ Phase changes the height of the signal.

✔ Amplitude changes the height.

---

❌ Phase changes the number of cycles.

✔ Frequency changes the number of cycles.

---

❌ Phase changes signal strength.

✔ Amplitude changes signal strength.

---

❌ Signals with different phases always have different frequencies.

✔ Signals can have the **same frequency** but different phases.

> **Phase is the starting position of a waveform relative to a reference point. It shifts the waveform left or right without changing its amplitude or frequency and is measured in degrees or radians.**
