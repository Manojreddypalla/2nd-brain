# What is Bipolar Encoding?

Unlike Unipolar and Polar encoding, **Bipolar Encoding uses three voltage levels**.

- **+V**
- **0 V**
- **−V**

That's why it's called **Bi-polar**.

The main idea is to **reduce the DC component** while maintaining good synchronization.

---

## Types of Bipolar Encoding

- AMI (Alternate Mark Inversion)
- Pseudoternary

---

# 2.4.4.1 AMI (Alternate Mark Inversion) ⭐⭐⭐⭐

## What is AMI?

In **AMI**, the bit **0** is represented by **0 V**.

The bit **1** is represented by alternating positive and negative voltages.

Hence the name:

- **A** = Alternate
- **M** = Mark (Mark means binary **1**)
- **I** = Inversion

---

## Encoding Rule

|Bit|Signal|
|---|---|
|**0**|0 V|
|**1**|Alternate between +V and −V|

---

## Example

Binary:

```
1 1 0 1 0 1
```

Signal:

```
+V  -V   0   +V   0   -V
```

Notice:

The first `1` is +V.

The next `1` becomes -V.

The next `1` becomes +V again.

It **alternates every time a 1 appears**.

---

## Why Alternate?

If every `1` were always +V,

there would be a DC component.

Alternating +V and -V makes the average voltage close to zero.

---

## Advantages

### No DC Component

Positive and negative pulses cancel each other.

---

### Better Synchronization

Transitions occur whenever 1s are transmitted.

---

### Error Detection

Two consecutive +V or two consecutive -V pulses violate the AMI rule.

Such a violation can indicate a transmission error.

---

## Disadvantages

### Long Sequence of Zeros

Example:

```
0000000000
```

No transitions occur.

Receiver may lose synchronization.

This is why practical systems later introduced scrambling techniques (not part of basic GATE Physical Layer).

---

## Applications

- T1/E1 Digital Telephone Lines
- Older Digital Communication Systems

---

# 2.4.4.2 Pseudoternary

Pseudoternary is simply the **reverse of AMI**.

---

## Encoding Rule

|Bit|Signal|
|---|---|
|**1**|0 V|
|**0**|Alternate between +V and −V|

---

## Example

Binary:

```
1 0 0 1 0
```

Signal:

```
0  +V  -V  0  +V
```

Only **0s alternate**.

---

## Comparison

|Feature|AMI|Pseudoternary|
|---|---|---|
|Alternating Voltage For|1|0|
|Other Bit|0 V|0 V|
|DC Component|Very Low|Very Low|
|Synchronization|Better than Unipolar|Better than Unipolar|

---

# GATE Points

Remember:

- **AMI → Ones Alternate**
- **Pseudoternary → Zeros Alternate**

That's the biggest difference.

# Short Notes

```
Bipolar Encoding

Uses +V, 0V, -V

AMI
1 → +V, -V, +V...
0 → 0V

Pseudoternary
0 → +V, -V, +V...
1 → 0V

✓ Low DC component
✓ Better synchronization
✗ Long sequence of 0s (AMI) or 1s (Pseudoternary) causes problems
```
