# 2.4.3.4 Manchester Encoding

---

## What is Manchester Encoding?

Manchester Encoding is a **Polar Line Coding** technique in which **every bit contains a transition at the middle of the bit interval**.

Unlike NRZ-L or NRZ-I,

**Information is represented by the direction of the mid-bit transition, not by the voltage level.**

This mandatory transition also acts as a **clock signal**, making synchronization easy.

---

## Encoding Rule

There are two conventions in books.

### IEEE 802.3 Convention (used in Ethernet)

| Bit | Mid-bit Transition |
|-----|--------------------|
| 1 | Low → High |
| 0 | High → Low |

> **Important:** Some books use the opposite convention. GATE will specify the convention if needed. The important property is that **every bit has one transition in the middle.**

---

## Example

Binary Data

```
1 0 1 1 0
```

Possible Signal

```
Bit 1 :  _|‾
Bit 0 :  ‾|_
Bit 1 :  _|‾
Bit 1 :  _|‾
Bit 0 :  ‾|_
```

Notice:

Every bit contains **one mandatory transition**.

---

## Why is Manchester Encoding Self-Clocking?

Every bit has a transition at its center.

The receiver uses this transition to synchronize its clock.

Therefore,

Even if many consecutive 0s or 1s occur,

Synchronization is never lost.

Example

```
111111111

Every bit still has one transition.
```

---

## Characteristics

### Advantages

### Excellent Synchronization

Clock recovery is very easy.

---

### No DC Component

Positive and negative voltages balance each other.

Average voltage ≈ 0.

Suitable for transformer-coupled links.

---

### Reliable Transmission

Works well even for long sequences of identical bits.

---

### Widely Used

Classic Ethernet (10 Mbps Ethernet) uses Manchester Encoding.

---

## Disadvantages

### High Bandwidth Requirement

Every bit produces a transition.

Therefore,

Manchester requires approximately **twice the bandwidth** of NRZ.

This is its biggest disadvantage.

---

### More Signal Transitions

More transitions

↓

Higher switching activity

↓

More bandwidth consumption.

---

## Applications

- Ethernet (IEEE 802.3)
- Digital communication systems

# Comparison

| Feature | NRZ | Manchester |
|---------|-----|------------|
| Synchronization | Poor | Excellent |
| DC Component | Present | None |
| Bandwidth | Low | High |
| Clock Recovery | Difficult | Easy |
| Long 0s / 1s | Problem | No Problem |
