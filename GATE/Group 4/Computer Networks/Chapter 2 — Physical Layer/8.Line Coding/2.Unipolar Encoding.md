# 2.4.2 Unipolar Encoding

---

## What is Unipolar Encoding?

In **Unipolar Encoding**, only **one voltage polarity** is used.

The signal is either:

- +V (positive voltage)
- 0 V (no voltage)

There is **no negative voltage**.

Hence the name **Uni-polar** (one polarity).

---

## Types of Unipolar Encoding

- Unipolar NRZ
- Unipolar RZ

---

# 2.4.2.1 Unipolar NRZ (Non-Return-to-Zero)

## Encoding Rule

| Bit | Voltage |
|-----|---------|
| 1 | +V |
| 0 | 0 V |

The signal **does not return to zero** during the bit interval.

---

## Example

Binary Data

```
1 0 1 1 0
```

Signal

```
+V ───      ─── ───
      │    │
0V ───┴────┘   └────
```

---

## Characteristics

### Advantages

- Very simple
- Easy to generate
- Requires less bandwidth than Manchester

---

### Disadvantages

### 1. Synchronization Problem

If many consecutive 1s or 0s occur,

Example

```
111111111111
```

or

```
000000000000
```

There are **no transitions**.

Receiver loses clock synchronization.

---

### 2. DC Component

Average voltage is positive.

Not suitable for transformer-coupled transmission.

---

### 3. Baseline Wandering

Long identical bits shift receiver reference voltage.

---

### 4. Poor Error Detection

No special pattern helps detect errors.

---

## Applications

Almost never used in modern networks.

Mostly used only to explain basic concepts.

---

# 2.4.2.2 Unipolar RZ (Return-to-Zero)

## Encoding Rule

| Bit | Signal |
|-----|--------|
| 1 | +V then 0 |
| 0 | 0 |

For every '1',

the signal returns to zero before the bit finishes.

---

## Example

Binary

```
1 0 1
```

Signal

```
+V ─┐    ─┐
    │    │
0V ─┴────┴────
```

Notice

Every '1'

returns to zero.

---

## Advantages

- Better synchronization than Unipolar NRZ
- Easier clock recovery

---

## Disadvantages

- Higher bandwidth requirement
- Still has DC component
- Still inefficient

---

# Unipolar NRZ vs Unipolar RZ

| Feature | NRZ | RZ |
|---------|-----|----|
| Returns to Zero | ❌ | ✅ |
| Bandwidth | Lower | Higher |
| Synchronization | Poor | Better |
| DC Component | Present | Present |
| Practical Usage | Rare | Rare |

# Shortcut

NRZ

```
1 → Stay High
0 → Stay Low
```

RZ

```
1 → High then Zero
0 → Zero
```
