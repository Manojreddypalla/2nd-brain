# 2.4.5 Block Coding

## What is Block Coding?

**Block Coding** is a technique in which a group of data bits is replaced with a **larger group of bits** before transmission.

Instead of sending the original bits directly,

we first convert them into another bit pattern.

Example:

```text
4 bits
↓

5 bits

1010

↓

10110
```

So,

> **m data bits → n coded bits (where n > m)**

---

## Why do we need Block Coding?

Some line coding schemes (like NRZ) may produce:

```text
000000000000
```

or

```text
111111111111
```

These long runs of identical bits have **very few or no transitions**, making clock synchronization difficult.

Block coding solves this by **adding controlled redundancy** so that the transmitted data contains enough transitions.

---

## Objectives of Block Coding

A good block coding scheme should:

- Improve synchronization.
    
- Reduce long runs of 0s or 1s.
    
- Help in limited error detection.
    
- Work together with line coding schemes.
    

---

# 2.4.5.1 4B/5B Encoding ⭐⭐⭐

## What is 4B/5B?

In **4B/5B encoding**,

every **4-bit data block** is replaced by a **5-bit code**.

```text
4 bits

↓

5 bits
```

The extra bit is **not additional data**.

It is added to improve synchronization.

---

## Example

Suppose:

```text
Data

1010
```

may become

```text
Code

10110
```

(The actual mapping is defined by a lookup table.)

You **do not need to memorize the table for GATE** unless specifically asked.

---

## Why is 4B/5B used?

The coding table is designed so that:

- Long sequences of zeros are avoided.
    
- Enough transitions occur.
    
- Clock recovery becomes easier.
    

---

## Overhead

Every 4 bits become 5 bits.

Efficiency:

```text
4 / 5 = 80%
```

So,

20% extra bits are transmitted.

---

## Applications

- Fast Ethernet
    
- Fiber networks
    
- FDDI
    

---

# 2.4.5.2 8B/10B Encoding ⭐⭐

## What is 8B/10B?

In **8B/10B encoding**,

every **8-bit data block** is converted into a **10-bit code**.

```text
8 bits

↓

10 bits
```

Again,

extra bits improve synchronization and maintain DC balance.

---

## Advantages

- Better synchronization.
    
- Reduces DC component.
    
- Helps maintain signal quality.
    
- Allows limited error detection.
    

---

## Efficiency

```text
8 / 10 = 80%
```

Same efficiency as 4B/5B.

---

## Applications

Used in high-speed communication systems such as:

- Gigabit Ethernet
    
- Fibre Channel
    
- PCI Express (older generations)
    
- SATA (older generations)
    

---

# 4B/5B vs 8B/10B

|Feature|4B/5B|8B/10B|
|---|---|---|
|Data Bits|4|8|
|Encoded Bits|5|10|
|Efficiency|80%|80%|
|Synchronization|Good|Better|
|DC Balance|Limited|Better|
|Usage|Fast Ethernet|Gigabit Ethernet & High-Speed Links|

---

# Why Block Coding is Used Before Line Coding

Think of the transmission process like this:

```text
Original Data
      │
      ▼
Block Coding
(4B/5B, 8B/10B)
      │
      ▼
Line Coding
(NRZ, Manchester, AMI...)
      │
      ▼
Transmission Medium
```

So:

- **Block Coding** improves the bit stream.
    
- **Line Coding** converts the bit stream into electrical or optical signals.
    

They solve different problems and often work together.
