# Chapter 2.6 – Multiplexing

## Overview

Multiplexing is a technique that **combines multiple independent signals into a single communication channel** for transmission.

At the receiver, the signals are separated back into their original form using a **Demultiplexer (DEMUX).**

### Basic Block Diagram

```
Multiple Inputs
     │
     ▼
+----------------+
| Multiplexer    |
|     (MUX)      |
+----------------+
        │
 Single Communication Channel
        │
        ▼
+----------------+
| Demultiplexer  |
|    (DEMUX)     |
+----------------+
        │
        ▼
Original Outputs
```

### Advantages

- Better bandwidth utilization
- Reduces transmission cost
- Allows multiple users to share one medium
- Efficient communication

---

# 2.6.1 Frequency Division Multiplexing (FDM)

## Definition

Frequency Division Multiplexing (FDM) is a multiplexing technique in which the **available bandwidth is divided into multiple frequency bands**, and each user is assigned a different frequency band.

> **Key Idea:** Multiple signals are transmitted **simultaneously**, each using a different frequency.

---

## Working

Suppose a communication channel has a bandwidth of **1 MHz**.

It can be divided into smaller frequency bands.

```
Frequency

| User A | GB | User B | GB | User C |

GB = Guard Band
```

Each user transmits continuously on their own frequency.

---

## Guard Band

A **Guard Band** is a small unused frequency range placed between two channels.

### Purpose

- Prevents overlapping
- Reduces interference
- Avoids cross-talk

---

## Characteristics

- Simultaneous transmission
- Uses different frequencies
- Mostly used for analog communication
- Requires Guard Bands

---

## Advantages

- Continuous transmission
- Low delay
- Multiple users communicate simultaneously

---

## Disadvantages

- Bandwidth wastage due to Guard Bands
- Cross-talk possible
- Requires careful frequency allocation

---

## Applications

- FM Radio
- Television Broadcasting
- Cable TV
- Satellite Communication

---

# 2.6.2 Time Division Multiplexing (TDM)

## Definition

Time Division Multiplexing (TDM) allows multiple users to share the **same communication channel**, but each user transmits during a different **time slot**.

> **Key Idea:** One frequency, different time slots.

---

## Working

```
Time

| A | B | C | A | B | C | A | B | C |
```

Each device waits for its assigned time slot.

---

## Characteristics

- Digital communication
- Uses time slots
- One channel shared among users
- No Guard Bands

---

## Advantages

- Efficient channel utilization
- Suitable for digital communication
- No frequency interference

---

## Disadvantages

- Synchronization required
- Idle slots may waste bandwidth

---

# 2.6.2.1 Synchronous TDM

## Definition

Each user is assigned a **fixed time slot**, regardless of whether the user has data to send.

---

## Example

Three users:

```
Time

| A | B | C | A | B | C |
```

Even if B has no data,

its time slot is still reserved.

```
| A | Empty | C |
```

---

## Characteristics

- Fixed slot allocation
- Predictable timing
- Simple implementation

---

## Advantages

- Easy implementation
- Guaranteed bandwidth
- Simple scheduling

---

## Disadvantages

- Poor bandwidth utilization
- Empty slots are wasted

---

## Applications

- PCM Telephone Systems
- ISDN

---

# 2.6.2.2 Statistical TDM

## Definition

Time slots are allocated **only to users that have data to transmit**.

Also called

**Asynchronous TDM**

---

## Working

If User B has no data,

```
Instead of

| A | B | C |

It becomes

| A | C | A |
```

No bandwidth is wasted.

---

## Characteristics

- Dynamic slot allocation
- Better channel utilization
- Requires buffering

---

## Advantages

- Efficient bandwidth usage
- Higher throughput
- No idle slots

---

## Disadvantages

- More complex
- Buffer memory required
- Variable delay possible

---

## Applications

- Computer Networks
- Data Communication Systems

---

# Synchronous TDM vs Statistical TDM

| Feature | Synchronous TDM | Statistical TDM |
|----------|-----------------|-----------------|
| Time Slot | Fixed | Dynamic |
| Idle Slot | Wasted | Not Wasted |
| Bandwidth Utilization | Lower | Higher |
| Complexity | Low | High |
| Buffer Required | No | Yes |

---

# 2.6.3 Wavelength Division Multiplexing (WDM) *(Basic)*

## Definition

Wavelength Division Multiplexing (WDM) is a multiplexing technique used in **Optical Fiber Communication**, where multiple optical signals are transmitted simultaneously using **different wavelengths (colors) of light**.

> **Key Idea:** Multiple wavelengths share the same optical fiber.

---

## Working

```
Optical Fiber

λ1 ─────────►

λ2 ─────────►

λ3 ─────────►

λ4 ─────────►
```

Each wavelength carries independent data.

---

## Characteristics

- Used only in Optical Fiber
- Very high bandwidth
- Long-distance communication
- Multiple wavelengths simultaneously

---

## Advantages

- Extremely high capacity
- Efficient fiber utilization
- Long-distance transmission
- Low signal loss

---

## Disadvantages

- Expensive equipment
- Complex implementation
- Optical components required

---

## Applications

- Optical Fiber Networks
- Internet Backbone
- Undersea Fiber Cables
- Long-distance Communication

---

# Comparison

| Feature | FDM | TDM | WDM |
|----------|-----|-----|------|
| Resource Shared | Frequency | Time | Wavelength |
| Mainly Used In | Analog | Digital | Optical Fiber |
| Users Share | Different Frequencies | Different Time Slots | Different Light Wavelengths |
| Simultaneous Transmission | Yes | No (Time Shared) | Yes |
| Guard Band Required | Yes | No | No |
