# GATE Short Notes — Transmission Media

## Definition

**Transmission Media** is the communication channel used to **carry signals** from the sender to the receiver.

> **Key Point:** It carries **signals**, not raw bits.

---

## Physical Layer

Transmission Media belongs to the **Physical Layer (Layer 1)**.

**Responsibilities:**

- Bit transmission
    
- Signal transmission
    
- Encoding
    
- Physical connection
    

**Not Responsible For:**

- Routing
    
- Error Control
    
- Flow Control
    
- Addressing
    

---

## Data Flow

```text
Bits
   ↓
Signal Generation
   ↓
Transmission Medium
   ↓
Signal Reception
   ↓
Bits
```

**Remember:**

> **Bits are converted into signals before transmission.**

---

## Types of Transmission Media

```text
Transmission Media
│
├── Guided (Wired)
└── Unguided (Wireless)
```

---

## Signals Used

|Medium|Signal|
|---|---|
|Twisted Pair|Electrical|
|Coaxial Cable|Electrical|
|Optical Fiber|Light|
|Wi-Fi|Radio Waves|
|Bluetooth|Radio Waves|
|Satellite|Microwaves|

---

## Important Characteristics

- **Bandwidth** → Data carrying capacity
    
- **Data Rate** → Transmission speed
    
- **Distance** → Maximum transmission range
    
- **Noise Immunity** → Resistance to interference
    
- **Cost**
    
- **Ease of Installation**

# GATE Corner ⭐

✅ Transmission media belongs to **Physical Layer**.

✅ It **carries signals**, not packets or frames.

✅ Transmission media is classified into **Guided** and **Unguided** only.

✅ Fiber uses **light**.

✅ Copper uses **electrical signals**.

✅ Wireless uses **radio/microwave signals**.

---

# Common Traps

❌ Bits travel through the cable.  
✔ Signals travel through the cable.

❌ Fiber carries electricity.  
✔ Fiber carries **light**.

❌ Wi-Fi is guided media.  
✔ Wi-Fi is **unguided** media.

❌ Physical Layer performs routing.  
✔ Routing is done by the **Network Layer**.

---

# One-Line Revision

> **Transmission Media = The physical or wireless path that carries signals between communicating devices.**
