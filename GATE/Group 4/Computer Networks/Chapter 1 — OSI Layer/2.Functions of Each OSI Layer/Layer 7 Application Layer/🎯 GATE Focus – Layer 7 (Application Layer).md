## ⚠ Common Mistakes

❌ Chrome/Firefox is the Application Layer.

✔ They are **applications** that **use Application Layer protocols**.

---

❌ HTTP sends packets.

✔ HTTP creates **application data/messages**. TCP and IP handle transport and routing.

---

❌ DNS belongs to the Network Layer.

✔ **DNS is an Application Layer protocol** used to convert **domain names into IP addresses**.

---

❌ Application Layer performs routing.

✔ Routing belongs to the **Network Layer**.

## ⭐ Ultimate Layer Identification Trick (GATE)

|If the question mentions...|Think...|
|---|---|
|HTTP, DNS, FTP, SMTP|**Layer 7 – Application**|
|Encryption, Compression|**Layer 6 – Presentation**|
|Session, Checkpoint|**Layer 5 – Session**|
|TCP, UDP, Port Number|**Layer 4 – Transport**|
|IP, Routing, Router|**Layer 3 – Network**|
|MAC, Ethernet, Switch|**Layer 2 – Data Link**|
|Bits, Cable, Signals|**Layer 1 – Physical**|

💡 **Memorize this table.** It is one of the fastest ways to identify the correct OSI layer in GATE objective questions.
