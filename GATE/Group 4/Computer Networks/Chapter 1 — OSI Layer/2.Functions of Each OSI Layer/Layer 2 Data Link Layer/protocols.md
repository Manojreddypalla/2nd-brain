For **Layer 2 (Data Link Layer)**, there are quite a few protocols. Here's a **GATE-oriented list**.

# 📌 Layer 2 – Data Link Layer Protocols

|Protocol|Full Form|Purpose|
|---|---|---|
|**Ethernet (IEEE 802.3)**|Ethernet|Wired LAN communication.|
|**Wi-Fi MAC (IEEE 802.11)**|Wireless LAN|Wireless LAN communication.|
|**PPP**|Point-to-Point Protocol|Direct communication between two nodes.|
|**HDLC**|High-Level Data Link Control|Bit-oriented WAN protocol.|
|**Frame Relay**|Frame Relay|WAN packet-switching protocol.|
|**ATM**|Asynchronous Transfer Mode|High-speed cell-switching technology.|
|**ARP**|Address Resolution Protocol|Resolves **IP → MAC** _(Layer 2/3 boundary)_.|
|**RARP**|Reverse Address Resolution Protocol|Resolves **MAC → IP** _(Obsolete)_.|
|**STP**|Spanning Tree Protocol|Prevents switching loops.|
|**RSTP**|Rapid Spanning Tree Protocol|Faster version of STP.|
|**VTP**|VLAN Trunking Protocol|Manages VLAN information (Cisco).|
|**LACP**|Link Aggregation Control Protocol|Combines multiple physical links.|
|**LLDP**|Link Layer Discovery Protocol|Discovers neighboring network devices.|
|**CDP**|Cisco Discovery Protocol|Cisco device discovery.|
|**IEEE 802.1Q**|VLAN Tagging|Adds VLAN tags to Ethernet frames.|
|**MPLS**|Multiprotocol Label Switching|Label-based forwarding (often considered Layer 2.5).|

## 📝 GATE Tip

Don't just memorize the names. Remember what each one is primarily associated with:

- **Ethernet** → Wired LAN
    
- **Wi-Fi (802.11)** → Wireless LAN
    
- **PPP** → Point-to-Point links
    
- **HDLC** → WAN
    
- **ARP** → IP → MAC resolution
    
- **STP** → Prevents switching loops
    
- **802.1Q** → VLAN tagging
    
- **Frame Relay / ATM** → Legacy WAN technologies
    

These are the protocols that most commonly appear in GATE Computer Networks questions.
