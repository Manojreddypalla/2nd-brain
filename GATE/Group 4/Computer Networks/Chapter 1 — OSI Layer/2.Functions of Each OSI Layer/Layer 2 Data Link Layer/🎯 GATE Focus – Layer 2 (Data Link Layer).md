## ⚠ Common Mistakes

❌ Switch forwards using IP Address.

✔ Switch forwards frames using **MAC Address**.

---

❌ Data Link Layer performs routing.

✔ Routing is the responsibility of the **Network Layer**.

---

❌ MAC Address and IP Address are the same.

✔ **MAC Address** → Physical Address (Layer 2)

✔ **IP Address** → Logical Address (Layer 3)

---

❌ Error Detection = Error Correction.

✔ Layer 2 mainly **detects** errors (using CRC); correction is typically handled by higher-layer protocols like TCP.
