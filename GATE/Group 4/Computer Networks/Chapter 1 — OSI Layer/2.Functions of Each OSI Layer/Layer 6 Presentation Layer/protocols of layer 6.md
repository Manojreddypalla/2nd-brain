# Layer 6 — Presentation Layer Protocols / Standards

|Protocol / Standard|Purpose|
|---|---|
|**SSL (Secure Sockets Layer)**|Encrypts data during communication (obsolete but important historically)|
|**TLS (Transport Layer Security)**|Modern encryption protocol used by HTTPS, SMTP, IMAP, etc.|
|**ASCII**|Standard character encoding (7-bit)|
|**Unicode**|Universal character encoding supporting almost all languages|
|**UTF-8**|Most widely used Unicode encoding|
|**UTF-16**|Unicode encoding using 16-bit units|
|**JPEG / JPG**|Image compression format|
|**PNG**|Lossless image format|
|**GIF**|Image format supporting animation|
|**MPEG**|Video compression standard|
|**MP3**|Audio compression format|
|**AAC**|Advanced audio compression|
|**GZIP**|Data compression algorithm|
|**ZIP**|File compression format|
|**XDR (External Data Representation)**|Standard data representation across different systems|
|**ASN.1 (Abstract Syntax Notation One)**|Standard for representing structured data in communication protocols|
