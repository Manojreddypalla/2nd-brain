### ⚠ Common Mistakes

❌ IP guarantees reliable delivery.

✔ IP provides **best-effort delivery** only.

---

❌ Routers use MAC addresses to route packets.

✔ Routers make forwarding decisions using **IP addresses**.

---

❌ ARP is a routing protocol.

✔ ARP resolves **IP → MAC** and is generally considered to operate at the **Layer 2/Layer 3 boundary**, not as a routing protocol.

---

❌ Routing and Forwarding are the same.

✔ **Routing** = Finding the best path.

✔ **Forwarding** = Sending the packet to the next hop using the routing table.
