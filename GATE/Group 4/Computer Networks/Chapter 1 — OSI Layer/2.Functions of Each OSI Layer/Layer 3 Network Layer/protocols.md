For **Layer 3 (Network Layer)**, these are the important protocols you should know.

# 📌 Layer 3 – Network Layer Protocols

|Protocol|Full Form|Purpose|
|---|---|---|
|**IPv4**|Internet Protocol Version 4|Provides logical addressing and routing.|
|**IPv6**|Internet Protocol Version 6|Next-generation Internet Protocol with a larger address space.|
|**ICMP**|Internet Control Message Protocol|Error reporting and network diagnostics (e.g., `ping`).|
|**IGMP**|Internet Group Management Protocol|Manages multicast group membership.|
|**IPsec**|Internet Protocol Security|Secures IP communication using authentication and encryption.|
|**ARP**|Address Resolution Protocol|Maps IP Address to MAC Address _(often considered Layer 2/Layer 3 boundary; GATE usually treats it with Data Link Layer)_.|
|**RARP**|Reverse Address Resolution Protocol|Maps MAC Address to IP Address _(obsolete)_.|
|**OSPF**|Open Shortest Path First|Link-state routing protocol used within an Autonomous System.|
|**RIP**|Routing Information Protocol|Distance-vector routing protocol.|
|**EIGRP**|Enhanced Interior Gateway Routing Protocol|Cisco's advanced routing protocol.|
|**BGP**|Border Gateway Protocol|Routing between different Autonomous Systems (the Internet backbone).|

### Address Resolution

- ARP
    
- RARP _(obsolete)_
    

> **Exam Tip:** Don't confuse **IP** with **routing protocols**. **IP** carries packets, while **OSPF, RIP, and BGP** help routers learn and choose the best paths.
