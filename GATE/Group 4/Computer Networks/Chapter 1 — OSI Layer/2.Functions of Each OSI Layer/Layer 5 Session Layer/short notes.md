# 📄 OSI Model – Layer 5: Session Layer

## 🎯 Purpose

Manages **communication sessions** between two applications.

Think of it as the **Conversation Manager** of the OSI model.

---

## 💡 Core Idea

Responsible for:

- Establishing sessions
- Maintaining sessions
- Synchronizing sessions (Checkpoints)
- Terminating sessions

---

## ⚙ Functions

- Session Establishment
- Session Maintenance
- Session Termination
- Synchronization (Recovery Checkpoints)
- Dialog Control (Half/Full Duplex)

---

## 🌍 Real-World Examples

- Gmail Login Session
- Netflix Streaming Session
- SSH Session
- SMB File Sharing Session
- Database Connection

---

## 🌐 Important Protocols

- NetBIOS
- RPC
- PPTP _(Legacy)_
- SMB Session Service
- SAP
- RTCP
- H.245

---

## 📦 PDU

**Data**

---

## 📍 Address Used

**None**

- ❌ MAC Address
- ❌ IP Address
- ❌ Port Number

---

## 🚫 Does NOT Handle

- Routing
- Reliability
- Error Detection
- Encryption
- Compression
- Packet Delivery

---

## 🎯 GATE Focus

Questions on:

- Session Establishment
- Session Maintenance
- Synchronization
- Dialog Control

---

## ⚠ Common Mistakes

- ❌ Session Layer = TCP
- ❌ Session Layer = Reliability
- ❌ Session Layer = Packet Management

**Remember:** It manages the **conversation**, not the packets.

---

## 📝 One-Line Revision

> **Layer 5 (Session Layer) establishes, manages, synchronizes, and terminates communication sessions between applications.**
