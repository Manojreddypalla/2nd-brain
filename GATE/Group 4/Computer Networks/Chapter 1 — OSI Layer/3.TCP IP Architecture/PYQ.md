## PYQ 1 (GATE-style)

**Which one of the following protocols is associated with the Transport layer of the TCP/IP protocol stack?**

A. IP

B. TCP

C. Ethernet

D. HTTP

<details> <summary>Answer</summary>

✅ **B. TCP**

- IP → Internet layer
- Ethernet → Network Access layer
- HTTP → Application layer

</details>

---

## PYQ 2 (Very Common)

**The Presentation layer and Session layer of the OSI model are part of which layer in the TCP/IP architecture?**

A. Internet

B. Transport

C. Network Access

D. Application

<details> <summary>Answer</summary>

✅ **D. Application**

</details>

---

## PYQ 3 (Frequently Asked)

**The routing function is performed by which layer of the TCP/IP model?**

A. Application

B. Transport

C. Internet

D. Network Access

<details> <summary>Answer</summary>

✅ **C. Internet**

</details>

---

## PYQ 4

**Which of the following is NOT a Transport layer protocol?**

A. TCP

B. UDP

C. IP

D. None of the above

<details> <summary>Answer</summary>

✅ **C. IP**

</details>

## PYQ 5 (Matching)

Match the following:

|Protocol|Layer|
|---|---|
|HTTP|?|
|TCP|?|
|IP|?|
|Ethernet|?|

Answer:

- HTTP → Application
- TCP → Transport
- IP → Internet
- Ethernet → Network Access

---

## PYQ 6 (Conceptual)

**Which statement is TRUE?**

A. TCP/IP has 7 layers.

B. TCP/IP is only the combination of TCP and IP.

C. TCP/IP is a protocol suite.

D. OSI is the protocol used on the Internet.

<details> <summary>Answer</summary>

✅ **C. TCP/IP is a protocol suite.**

</details>
