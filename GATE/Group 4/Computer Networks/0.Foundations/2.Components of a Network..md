# 2. Components of a Network

## 🎯 Intuition

Just like a road system needs roads, vehicles, traffic lights, and destinations, a network needs different components to send data.

---

## 🧠 Core Components

### End Devices (Hosts)

Devices that send or receive data.

Examples:

- Laptop
- Phone
- Server
- Printer

---

### Transmission Media

The path through which data travels.

Examples:

- Ethernet Cable
- Fiber Optic
- Wi-Fi

---

### Network Devices

Help move data between devices.

- Hub
- Switch
- Router
- Access Point
- Modem

(Don't worry about how each works yet.)

---

### Protocols

Rules that every device follows to communicate.

Examples:

- HTTP
- TCP
- IP

---

## 🌍 Example

```
Laptop
   │
Wi-Fi

   │
Internet
   │
Google Server
```

## 🎯 GATE Point

Basic components:

- Hosts

## 📝 Revision

> Every network consists of devices, a communication medium, networking equipment, and protocols.
