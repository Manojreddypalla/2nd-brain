# Computer Networks – Module 0: Foundations (Short Notes)

## 1. Why Networking?

- Connects multiple computers to communicate and share resources.
    
- Enables:
    
    - Data Sharing
        
    - Resource Sharing
        
    - Communication
        
    - Internet Access
        

**Remember:**

> OS manages **one computer**.  
> Computer Networks connect **many computers**.

---

## 2. Components of a Network

### End Devices (Hosts)

- Laptop
    
- Mobile
    
- Server
    
- Printer
    

### Transmission Media

- Ethernet Cable
    
- Fiber Optic
    
- Wi-Fi
    

### Networking Devices

- Hub
    
- Switch
    
- Router
    
- Modem
    
- Access Point
    

### Protocols

Rules for communication (HTTP, TCP, IP, FTP).

---

## 3. Types of Networks

### LAN (Local Area Network)

- Small area
    
- High speed
    
- Low latency
    
- Example: Home, Office
    

### MAN (Metropolitan Area Network)

- Covers a city
    
- Usually managed by ISPs
    

### WAN (Wide Area Network)

- Covers countries/continents
    
- Example: Internet
    

**Order:**

> **LAN < MAN < WAN**

---

## 4. Network Topologies

### Bus

- Single backbone cable
    
- Cheap
    
- Backbone failure → Entire network fails
    

### Star ⭐

- Central Switch/Hub
    
- Most common
    
- Switch failure → Entire network fails
    

### Ring

- Circular connection
    
- Each node connects to two neighbors
    

### Mesh

- Every node connected to every other node
    
- Highly reliable
    
- Links = **n(n−1)/2**
    

### Tree

- Hierarchical structure
    
- Combination of multiple Star networks
    

---

## 5. Protocol

**Definition**  
A set of rules governing communication between devices.

Defines:

- Syntax (Format)
    
- Semantics (Meaning)
    
- Timing (When)
    

Examples:

- HTTP
    
- TCP
    
- IP
    
- UDP
    

---

## 6. Service

**What is provided** by a lower layer to the upper layer.

Example:  
Transport Layer provides **reliable data delivery**.

---

## 7. Interface

**How the service is accessed.**

Example:  
`send()` using sockets is an interface to the transport service.

**Memory Trick**

- Service = **What**
    
- Interface = **How**
    

---

## 8. Layering

Breaks communication into multiple layers.

Advantages:

- Modularity
    
- Simplicity
    
- Easy Troubleshooting
    
- Standardization
    

Each layer:

- Performs one task
    
- Provides service upward
    
- Uses service downward
    

---

## 9. Encapsulation

Adding protocol headers (and sometimes trailers) while moving **down** the protocol stack.

Flow:

Data  
↓  
Segment  
↓  
Packet  
↓  
Frame  
↓  
Bits

---

## 10. Decapsulation

Removing protocol headers (and trailers) while moving **up** the protocol stack.

Flow:

Bits  
↑  
Frame  
↑  
Packet  
↑  
Segment  
↑  
Data

---

## 11. PDU (Protocol Data Unit)

|Layer|PDU|
|---|---|
|Application|Data|
|Transport|Segment (TCP) / Datagram (UDP)|
|Network|Packet|
|Data Link|Frame|
|Physical|Bits|

**Mnemonic:**

> **Data → Segment → Packet → Frame → Bits**

---

## 12. OSI Model (Overview)

**OSI = Open Systems Interconnection**

- 7-layer **reference model**
    
- Divides networking into layers
    
- Each layer performs one specific function
    

Layers (Top → Bottom):

1. Application
    
2. Presentation
    
3. Session
    
4. Transport
    
5. Network
    
6. Data Link
    
7. Physical
    

**Note:** The Internet primarily uses the **TCP/IP model**, while the **OSI model** is used to understand networking concepts.
