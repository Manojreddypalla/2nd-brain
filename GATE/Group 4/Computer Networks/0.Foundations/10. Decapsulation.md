# 10. Decapsulation

## 🎯 Intuition

When you receive a courier package, you don't use it immediately.

You remove:

- Shipping label
    
- Outer box
    
- Inner box
    

Until you finally reach the actual gift.

Networking does the same thing.

---

## 🧠 Core Concept

**Decapsulation** is the process of **removing protocol-specific headers (and trailers) as data moves up the protocol stack at the receiver.**

Each layer removes **only its own information** and passes the remaining data upward.

---

## How It Works

Suppose the sender transmitted:

```text
[MAC][IP][TCP][Data][CRC]
```

At the receiver:

### Physical Layer

Receives bits.

```text
010101010...
```

↓

### Data Link Layer

- Checks CRC
    
- Removes MAC Header
    
- Removes Trailer
    

Passes:

```text
[IP][TCP][Data]
```

↓

### Network Layer

Removes IP Header.

Passes:

```text
[TCP][Data]
```

↓

### Transport Layer

Removes TCP Header.

Passes:

```text
Data
```

↓

### Application Layer

Finally receives:

```text
Hello
```

---

## Visualization

```text
Bits
  │
  ▼
Data Link
Remove MAC + CRC
  │
  ▼
Network
Remove IP Header
  │
  ▼
Transport
Remove TCP Header
  │
  ▼
Application
Original Data
```

---

## Why Remove Headers?

Each header is useful only to its own layer.

For example:

- **MAC Header** → Used only for communication on the local network.
    
- **IP Header** → Used for routing across networks.
    
- **TCP Header** → Used for reliable delivery.
    

Once a layer finishes its job, it removes its header because the upper layers don't need it.

---

## 🌍 Real-Life Analogy

Receiving a parcel:

```text
Courier Box
      ↓
Shipping Label Removed
      ↓
Gift Box Opened
      ↓
Gift 🎁
```

Each layer unwraps one level.

---

## 🎯 GATE Focus

Remember:

> **As data moves UP the layers → Headers are REMOVED.**

This is **Decapsulation**.

---

## 💻 Developer Connection

When your browser receives a webpage:

1. The network card receives the bits.
    
2. The Data Link layer removes the Ethernet header.
    
3. The Network layer removes the IP header.
    
4. The Transport layer removes the TCP header.
    
5. The browser finally receives the HTTP data and displays the webpage.
    

All of this happens automatically.

---

## 📝 Revision

- Decapsulation = Removing headers (and trailers).
    
- Happens while moving **up** the protocol stack.
    
- Each layer removes **only its own** header.
    
- The Application layer finally receives the original data.
    

---

# 🧠 Quick Comparison

|Encapsulation|Decapsulation|
|---|---|
|Sender side|Receiver side|
|Data moves **down** the stack|Data moves **up** the stack|
|Headers added|Headers removed|
|Data → Bits|Bits → Original Data|

## Pattern Recognition

You've now learned the **flow of data** through the layers:

```text
Sender
Application
      ↓
Transport (+TCP Header)
      ↓
Network (+IP Header)
      ↓
Data Link (+MAC Header + CRC)
      ↓
Physical (Bits)
═══════════════════════
Transmission
═══════════════════════
Physical
      ↑
Data Link (-MAC Header - CRC)
      ↑
Network (-IP Header)
      ↑
Transport (-TCP Header)
      ↑
Application
Receiver
```

This entire diagram is one of the most important mental models in Computer Networks.
