# 9. Encapsulation

## 🎯 Intuition

When you send a parcel, you don't hand over the item as-is.

You **wrap it**.

Then the courier adds:

- Sender address
    
- Receiver address
    
- Tracking number
    
- Barcode
    

Each stage adds its own information.

Networking works exactly the same way.

---

## 🧠 Core Concept

**Encapsulation** is the process of **adding protocol-specific information (headers, and sometimes trailers) to data as it moves down the protocol stack.**

Every layer adds its own information before passing the data to the next layer.

---

## How It Works

Suppose you send:

```text
Hello
```

### Application Layer

Creates the data.

```text
Data
```

↓

### Transport Layer

Adds a **TCP/UDP Header**

```text
[TCP Header][Data]
```

↓

### Network Layer

Adds an **IP Header**

```text
[IP Header][TCP Header][Data]
```

↓

### Data Link Layer

Adds:

- MAC Header
    
- Trailer (CRC)
    

```text
[MAC Header][IP Header][TCP Header][Data][Trailer]
```

↓

### Physical Layer

Converts everything into bits.

```text
010101010101...
```

---

## Visualization

```text
Application
      Data
        │
        ▼
Transport
[TCP][Data]
        │
        ▼
Network
[IP][TCP][Data]
        │
        ▼
Data Link
[MAC][IP][TCP][Data][CRC]
        │
        ▼
Physical
Bits
```

Each lower layer **encapsulates** the previous layer's data.

---

## Why Do We Add Headers?

Every layer needs information to perform its job.

Examples:

### TCP Header

- Source Port
    
- Destination Port
    
- Sequence Number
    
- ACK Number
    

---

### IP Header

- Source IP
    
- Destination IP
    
- TTL
    

---

### MAC Header

- Source MAC
    
- Destination MAC
    

Each layer only reads **its own header**.

---

## 🌍 Real-Life Analogy

Sending a gift:

```text
Gift
   ↓
Gift Box
   ↓
Shipping Box
   ↓
Courier Label
   ↓
Truck
```

Every stage adds extra information without changing the gift itself.

---

## 🎯 GATE Focus

Remember:

> **As data moves DOWN the layers → Headers are ADDED.**

This is **Encapsulation**.

---

## 💻 Developer Connection

When you write:

```text
GET /index.html
```

You only create the application data.

The operating system automatically adds:

- TCP Header
    
- IP Header
    
- Ethernet Header
    

You never do this manually.

---

## 📝 Revision

- Encapsulation = Adding headers (and sometimes trailers).
    
- Happens while moving **down** the protocol stack.
    
- Each layer adds information required for its own task.
    
- Physical layer finally transmits **bits**.
    

---

# 🧠 Think About It

If the sender **adds** all these headers while sending...

**How does the receiver get back the original `"Hello"` message?**

It must remove the headers **one by one**.

That process is called **Decapsulation**, and it's the exact reverse of encapsulation. We'll cover that next.
