# 📜 Rules

### Rule 1

Every **Subject** contains only **Modules**.

---

### Rule 2

Every **Module** contains only **Topics**.

---

### Rule 3

Every **Topic** must contain:

```text
Theory.md
PYQs/
```

---

### Rule 4

If a topic becomes too large,

convert it into

```text
Topic/
    Subtopic/
```

---

### Rule 5

Every subtopic again follows

```text
Theory.md
PYQs/
```

---

### Rule 6

Never mix multiple concepts in one note.

One note = One concept.

---

### Rule 7

Never move to the next topic until the current topic's PYQs are completed.

---

### Rule 8

Update Theory after solving PYQs if you discover new tricks or important insights.

---

### Final Structure

```text
GATE
└── Subject
    └── Module
        └── Topic
            ├── Theory.md
            └── PYQs
                ├── GateOverflow.md
                ├── Practice Set 1.md
                └── Practice Set 2.md
```

I wouldn't add anything more. The beauty of this structure is that **every subject—OS, CN, DBMS, COA, TOC, DSA—uses the exact same hierarchy**, so once you learn the structure, you never have to think about organization again. Your mental energy stays focused on studying rather than managing folders.
