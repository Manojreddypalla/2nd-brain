Here are the most important `fork()` return value examples for GATE and interviews.

---

# 1. Parent gets Child PID (`pid > 0`)

```c
#include <stdio.h>
#include <unistd.h>

int main()
{
    pid_t pid = fork();

    if(pid > 0)
    {
        printf("Parent Process\n");
        printf("fork() returned : %d\n", pid);
        printf("My PID          : %d\n", getpid());
    }

    return 0;
}
```

### Possible Output

```
Parent Process
fork() returned : 1235
My PID          : 1234
```

Notice

```
Parent PID = 1234

fork() returned = 1235
```

The returned value is **the child's PID**, **not** the parent's.

---

# 2. Child gets `0`

```c
#include <stdio.h>
#include <unistd.h>

int main()
{
    pid_t pid = fork();

    if(pid == 0)
    {
        printf("Child Process\n");
        printf("fork() returned : %d\n", pid);
        printf("My PID          : %d\n", getpid());
    }

    return 0;
}
```

### Possible Output

```
Child Process
fork() returned : 0
My PID          : 1235
```

Notice

```
fork() returned = 0

Actual PID = 1235
```

The child PID is **NOT** zero.

---

# 3. Failure (`pid == -1`)

```c
#include <stdio.h>
#include <unistd.h>

int main()
{
    pid_t pid = fork();

    if(pid == -1)
    {
        printf("Fork Failed!\n");
    }

    return 0;
}
```

Normally you won't see this unless the system cannot create another process.

---

# 4. Complete Example

```c
#include <stdio.h>
#include <unistd.h>

int main()
{
    pid_t pid = fork();

    if(pid == -1)
    {
        printf("Fork Failed\n");
    }
    else if(pid == 0)
    {
        printf("\n===== CHILD =====\n");
        printf("fork() returned : %d\n", pid);
        printf("My PID          : %d\n", getpid());
        printf("Parent PID      : %d\n", getppid());
    }
    else
    {
        printf("\n===== PARENT =====\n");
        printf("fork() returned : %d\n", pid);
        printf("My PID          : %d\n", getpid());
    }

    return 0;
}
```

### Sample Output

```
===== PARENT =====
fork() returned : 2145
My PID          : 2144

===== CHILD =====
fork() returned : 0
My PID          : 2145
Parent PID      : 2144
```

---

# 5. Most Important Example (Interview Favorite)

```c
#include <stdio.h>
#include <unistd.h>

int main()
{
    pid_t pid = fork();

    if(pid == 0)
        printf("I am Child\n");
    else
        printf("I am Parent\n");

    return 0;
}
```

Possible Output

```
I am Parent
I am Child
```

or

```
I am Child
I am Parent
```

**Execution order is not guaranteed.**

---

# 6. Verify the Return Value Isn't the PID

```c
#include <stdio.h>
#include <unistd.h>

int main()
{
    pid_t pid = fork();

    printf("---------------------------------\n");
    printf("fork() returned : %d\n", pid);
    printf("My PID          : %d\n", getpid());
    printf("Parent PID      : %d\n", getppid());

    return 0;
}
```

### Example Output

```
---------------------------------
fork() returned : 3102
My PID          : 3101
Parent PID      : 3000

---------------------------------
fork() returned : 0
My PID          : 3102
Parent PID      : 3101
```

This example clearly proves:

- In the **parent**, `fork()` returns the **child's actual PID** (`3102`).
    
- In the **child**, `fork()` returns `0`, but its **real PID** is still `3102`.

# ⭐ GATE Master Program (Recommended)

This is the one program I recommend remembering because it demonstrates almost everything about `fork()` return values.

```c
#include <stdio.h>
#include <unistd.h>

int main()
{
    pid_t pid = fork();

    if(pid == -1)
    {
        printf("Fork Failed!\n");
    }
    else if(pid == 0)
    {
        printf("\n===== CHILD PROCESS =====\n");
        printf("fork() returned : %d\n", pid);
        printf("Child PID       : %d\n", getpid());
        printf("Parent PID      : %d\n", getppid());
    }
    else
    {
        printf("\n===== PARENT PROCESS =====\n");
        printf("fork() returned : %d\n", pid);
        printf("Parent PID      : %d\n", getpid());
    }

    return 0;
}
```

This single program demonstrates:

- ✅ `fork()` called once, returns twice
    
- ✅ Parent gets the child's PID
    
- ✅ Child gets `0`
    
- ✅ Difference between `fork()` return value and `getpid()`
    
- ✅ Parent's PID vs Child's PID
    
- ✅ `getppid()` (parent's PID as seen by the child)
    

If you thoroughly understand and can explain this program, you're well-prepared for nearly every GATE or interview question about `fork()` return values.
