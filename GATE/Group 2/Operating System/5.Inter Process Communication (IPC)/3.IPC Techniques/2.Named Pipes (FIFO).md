# Named Pipes (FIFO)

## Definition

A **Named Pipe (FIFO - First In First Out)** is an IPC mechanism that allows **both related and unrelated processes** to communicate through a **special file** in the file system.

Unlike an anonymous pipe, a named pipe has a **filename**, so any process with the required permissions can use it.

---

# Why Named Pipes?

Anonymous Pipes have one major limitation:

❌ Only parent and child (related) processes can communicate.

What if two completely independent processes need to communicate?

Example:

```text
Music Player            Calculator

(No Parent-Child Relationship)
```

Anonymous Pipe cannot be used.

The solution is **Named Pipe (FIFO).**

---

# Working

The operating system creates a special file called a FIFO.

```text
Process A

Write()

     │

     ▼

+-----------------------+
| Named Pipe (FIFO)     |
+-----------------------+

     │

Read()

     ▼

Process B
```

Unlike an anonymous pipe, both processes simply open the same FIFO file.

---

# Why is it Called FIFO?

FIFO means **First In First Out**.

The first byte written is the first byte read.

Example

Write:

```text
A
B
C
```

Read:

```text
A
B
C
```

---

# Characteristics

- Named in the file system.
- Can communicate between unrelated processes.
- FIFO data order.
- Uses a kernel buffer.
- Temporary data, but the FIFO file remains until deleted.

---

# Anonymous Pipe vs Named Pipe

| Feature | Anonymous Pipe | Named Pipe (FIFO) |
|----------|----------------|-------------------|
| Name | No | Yes |
| Exists in File System | No | Yes |
| Related Processes | Yes | Yes |
| Unrelated Processes | No | Yes |
| Communication | One-way | One-way |
| FIFO Order | Yes | Yes |

---

# Communication

Example

```text
Process A

Write

      │

      ▼

Named Pipe

      ▲

      │

Read

Process B
```

Any process can access the FIFO if it knows its pathname and has permission.

---

# Blocking Behavior

## Read

If the FIFO is empty,

```text
Reader

↓

Wait
```

The reader blocks until data is written.

---

## Write

If the FIFO buffer is full,

```text
Writer

↓

Wait
```

The writer blocks until space becomes available.

---

# Advantages

## 1. Unrelated Processes

Processes do not need a parent-child relationship.

---

## 2. Simple

Easy to create and use.

---

## 3. FIFO Ordering

Messages are received in the same order they are sent.

---

## 4. No Shared Memory Needed

Communication is managed by the operating system.

---

# Disadvantages

## 1. One-Way Communication

One FIFO provides only one direction of communication.

Two FIFOs are needed for bidirectional communication.

---

## 2. Slower Than Shared Memory

Data passes through the kernel buffer.

---

## 3. Limited Buffer

If the buffer becomes full,

writers block.

---

# Linux System Call

## mkfifo()

Creates a Named Pipe.

```c
mkfifo("myfifo", 0666);
```

Example

```text
Process A

↓

myfifo

↓

Process B
```

Processes open the FIFO like a normal file.

---

# Linux Commands

Create FIFO

```bash
mkfifo mypipe
```

View FIFO

```bash
ls -l
```

Output

```text
prw-r--r--
```

The first letter

```text
p
```

indicates a Named Pipe.

---

# Real-Life Analogy

Imagine a **mailbox** outside a house.

```text
Person A

↓

Mailbox

↓

Person B
```

- Anyone who knows the mailbox location can send or receive mail.
- The people don't need to know each other personally.
- The mailbox is the Named Pipe.

---

# Pipe vs Named Pipe

| Pipe | Named Pipe |
|------|------------|
| No filename | Has filename |
| Parent-Child only | Any process |
| Temporary | FIFO file exists until deleted |
| Created using `pipe()` | Created using `mkfifo()` |

---

# GATE Points ⭐

- Named Pipe is also called **FIFO**.
- Created using **`mkfifo()`**.
- Exists as a special file in the file system.
- Used by **related and unrelated processes**.
- FIFO data order.
- Uses a kernel buffer.
- One-way communication.
- Two FIFOs are required for bidirectional communication.

# Common GATE MCQs

### Q1

Which IPC mechanism allows communication between unrelated processes?

- FCFS
- Anonymous Pipe
- Named Pipe
- Semaphore

✅ **Answer:** Named Pipe

---

### Q2

Which system call creates a Named Pipe?

- pipe()
- fork()
- socket()
- mkfifo()

✅ **Answer:** mkfifo()

---

### Q3

Which statement is TRUE?

- Anonymous Pipes exist in the file system.
- Named Pipes require a parent-child relationship.
- Named Pipes exist as special files.
- Named Pipes are bidirectional.

✅ **Answer:** Named Pipes exist as special files.
