# Sockets

## Definition

A **Socket** is an IPC mechanism that allows **two processes to communicate by sending and receiving data over a network or on the same machine**.

It acts as an **endpoint of communication** between two processes.

Unlike Pipes or Shared Memory, sockets can communicate **across different computers**.

---

# Why Sockets?

Most IPC mechanisms have limitations.

- Pipes → Related processes.
- Named Pipes → Same machine.
- Shared Memory → Same machine.
- Message Queues → Same machine.

But what if:

```text
Computer A

↓

Needs to communicate with

↓

Computer B
```

Shared Memory cannot do this.

The solution is **Sockets**.

---

# Real-Life Analogy

Think of a **telephone call**.

```text
Person A

☎

Person B
```

Both people can:

- Send information.
- Receive information.

Even if they are in different cities.

A Socket works in the same way.

---

# What is a Socket?

A socket is simply an **endpoint** used for communication.

```text
Process A

Socket

~~~~~~~~ Network ~~~~~~~~

Socket

Process B
```

Both processes communicate through their sockets.

# Communication Model

Sockets generally follow the **Client-Server Model**.

```text
Client

↓

Request

↓

Server

↓

Response

↓

Client
```

Examples:

- Web Browser ↔ Web Server
- Chat Application
- Email
- Online Games

---

# Types of Sockets

## 1. Stream Socket (TCP)

Uses TCP.

Characteristics:

- Reliable.
- Connection-Oriented.
- Ordered delivery.
- Error checking.

Examples:

- HTTP
- HTTPS
- SSH
- FTP

---

## 2. Datagram Socket (UDP)

Uses UDP.

Characteristics:

- Faster.
- Connectionless.
- No delivery guarantee.
- No ordering guarantee.

Examples:

- Video Streaming
- Online Games
- Voice Calls

---

# Characteristics

- Bidirectional communication.
- Same machine or different machines.
- Network capable.
- Client-Server architecture.
- Supports TCP and UDP.

# Socket vs Pipe

| Pipe | Socket |
|------|--------|
| Local Machine | Local or Remote |
| Parent-Child Preferred | Any Processes |
| Unidirectional | Bidirectional |
| Simple | More Flexible |

---

# Socket vs Shared Memory

| Shared Memory | Socket |
|--------------|--------|
| Fastest IPC | Slower |
| Same Machine | Local & Remote |
| No Data Copy | Network Transfer |
| Programmer Synchronizes | Network Protocol Handles Communication |

---

# Socket vs Message Queue

| Message Queue | Socket |
|--------------|--------|
| Local IPC | Local & Remote IPC |
| Queue Based | Network Endpoint |
| Kernel Queue | Network Stack |

---

# GATE Points ⭐

- Socket = Communication endpoint.
- Supports communication on the **same machine** and **across different machines**.
- Uses the **Client-Server model**.
- **TCP Socket** → Reliable, Connection-Oriented.
- **UDP Socket** → Faster, Connectionless.
- Server: `socket()` → `bind()` → `listen()` → `accept()`.
- Client: `socket()` → `connect()`.
- Data transfer: `send()` and `recv()`.
- Close connection: `close()`.
