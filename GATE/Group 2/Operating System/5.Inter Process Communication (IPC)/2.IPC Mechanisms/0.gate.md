# GATE Corner ⭐

## Shared Memory

- **Fastest IPC mechanism.**
- Processes communicate by accessing the **same memory region**.
- **No data copying** between processes.
- Requires **Synchronization** (Semaphore, Mutex, etc.).
- Can suffer from **Race Conditions**.
- Works only between processes on the **same machine**.
- Linux System Calls:
  - `shmget()`
  - `shmat()`
  - `shmdt()`
  - `shmctl()`

---

## Message Passing

- Processes communicate using **send()** and **receive()**.
- **No shared memory** is required.
- Operating System transfers the messages.
- Safer but **slower than Shared Memory** due to data copying.
- Suitable for **local and distributed systems**.

---

## Direct Communication

- Sender and receiver **know each other's identity**.
- One-to-one communication.
- **Tightly coupled**.

---

## Indirect Communication

- Communication occurs through a **Mailbox (Port)**.
- Sender and receiver **do not know each other's identity**.
- **Loosely coupled**.
- Supports one-to-many and many-to-many communication.

---

## Blocking Communication (Synchronous)

- Process **waits** until the operation completes.
- **Blocking Send:** Waits until the message is accepted.
- **Blocking Receive:** Waits until a message arrives.

---

## Non-Blocking Communication (Asynchronous)

- Process **does not wait**.
- Continues execution immediately.
- If no message is available, receive returns immediately.

---

## Buffering

### Zero Capacity Buffer

- Buffer size = **0**
- No message storage.
- Sender and receiver must synchronize directly.
- Sender **always waits**.

### Bounded Capacity Buffer

- Fixed-size buffer.
- Sender waits **only when the buffer is full**.
- Receiver waits **when the buffer is empty**.
- Most common implementation.

### Unbounded Capacity Buffer

- Logically unlimited buffer.
- Sender **never waits because the buffer is full**.
- Receiver waits only if there are no messages.

---

# One-Line Memory Tricks ⭐

- **Shared Memory** → Fastest, Shared Data, Synchronization Required.
- **Message Passing** → OS Copies Messages.
- **Direct** → Process ↔ Process.
- **Indirect** → Process ↔ Mailbox ↔ Process.
- **Blocking** → Wait.
- **Non-Blocking** → Continue.
- **Zero Buffer** → Always Wait.
- **Bounded Buffer** → Wait If Full.
- **Unbounded Buffer** → Sender Never Waits (due to full buffer).
