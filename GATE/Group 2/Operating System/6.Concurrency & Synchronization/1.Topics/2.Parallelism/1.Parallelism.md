# Parallelism

---

# Definition

**Parallelism** is the ability of a system to **execute multiple tasks or multiple parts of a task simultaneously**.

> Unlike concurrency, parallelism means that multiple instructions are actually running **at the same instant**.

---

# Why Do We Need Parallelism?

Imagine rendering a 3D movie.

If only one CPU core is available:

```text
Frame 1

↓

Frame 2

↓

Frame 3

↓

Frame 4
```

This takes a long time.

Now imagine four CPU cores:

```text
Core 1 → Frame 1

Core 2 → Frame 2

Core 3 → Frame 3

Core 4 → Frame 4
```

All four frames are processed **simultaneously**.

This is Parallelism.

---

# How Does Parallelism Work?

Parallelism requires **multiple execution units**, such as:

- Multiple CPU cores
- Multiple processors
- GPU cores

Example:

```text
Core 1 → Task A

Core 2 → Task B

Core 3 → Task C
```

All tasks execute at the same instant.

---

# Single-Core vs Multi-Core

### Single-Core CPU

```text
Time →

Task A → ███     ███

Task B →     ███

CPU switches between tasks.
```

✔ Concurrent

❌ Not Parallel

---

### Multi-Core CPU

```text
Core 1 → █████

Core 2 → █████
```

✔ Concurrent

✔ Parallel

---

# Characteristics

- Multiple tasks execute simultaneously.
- Requires multiple execution units.
- Improves performance.
- Reduces execution time.
- Useful for compute-intensive workloads.


Only one step at a time.

All three activities happen at the same time.

# Concurrency vs Parallelism

| Concurrency | Parallelism |
|-------------|-------------|
| Tasks make progress together | Tasks execute simultaneously |
| May use one CPU core | Requires multiple execution units |
| Uses context switching on a single core | Uses multiple cores/processors |
| Focuses on managing tasks | Focuses on executing tasks |

---

# Relationship

Parallelism is a form of concurrency.

```text
Concurrency

├── Single-Core
│     └── Context Switching
│
└── Multi-Core
      └── Parallel Execution
```

Every parallel system is concurrent because multiple tasks are progressing together.

However, a concurrent system is **not necessarily parallel**.

---

# Important Terms

### Multi-Core Processor

A CPU containing multiple independent processing cores.

---

### Simultaneous Execution

Two or more instructions are executed at the exact same instant.

This is the defining property of Parallelism.

---

# GATE Points ⭐

- Parallelism means **simultaneous execution**.
- Requires multiple execution units (cores/processors).
- A single-core processor cannot achieve true parallelism.
- Parallelism improves performance for CPU-intensive workloads.
- Every parallel program is concurrent, but not every concurrent program is parallel.

✅ **Answer:** No

Which hardware feature is essential for true parallelism?
