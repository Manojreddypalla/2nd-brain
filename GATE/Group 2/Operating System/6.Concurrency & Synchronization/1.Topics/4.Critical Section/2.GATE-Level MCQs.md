# 🎯 GATE-Level MCQs

## Q1 ⭐

A Critical Section is the part of a program that:

A) Performs input only

B) Accesses shared resources

C) Executes after termination

D) Performs memory allocation only

<details> <summary>✅ Answer</summary>

**B**

A critical section is defined by access to shared resources.

</details>

---

## Q2 ⭐⭐

Which of the following is the primary purpose of protecting a Critical Section?

A) Increase CPU speed

B) Reduce memory usage

C) Prevent race conditions

D) Reduce context switches

<details> <summary>✅ Answer</summary>

**C**

Synchronization protects the critical section to avoid race conditions.

</details>

---

## Q3 ⭐⭐⭐ (GATE Style)

Which sequence correctly represents the structure of a process with respect to the Critical Section?

A)

Critical → Entry → Exit → Remainder

B)

Entry → Critical → Exit → Remainder

C)

Entry → Exit → Critical → Remainder

D)

Remainder → Exit → Critical → Entry

<details> <summary>✅ Answer</summary>

**B**

This is the standard structure used in operating systems.

</details>

---

## Q4 ⭐⭐⭐

Which of the following is **NOT** typically a Critical Section?

A)

```
count++;
```

B)

```
balance = balance - 100;
```

C)

```
printf("Hello");
```

D)

```
shared->temp = 30;
```

<details> <summary>✅ Answer</summary>

**C**

Assuming `printf("Hello");` doesn't access a shared resource in this context, it belongs to the remainder section.

</details>

---

## Q5 ⭐⭐⭐⭐ (Statement-Based)

Consider the following statements:

1. A Critical Section accesses shared resources.
2. Multiple threads may safely execute the same Critical Section simultaneously without synchronization.
3. The Entry Section requests permission to enter the Critical Section.

Which statements are correct?

A) 1 only

B) 1 and 2 only

C) 1 and 3 only

D) 1, 2 and 3

<details> <summary>✅ Answer</summary>

**C**

Statement 2 is false because simultaneous unsynchronized execution can cause race conditions.

</details>

---

## Q6 ⭐⭐⭐⭐ (Code-Based)

```
int x = 0;

// Thread A
x++;

// Thread B
x++;
```

Which line is the Critical Section?

A)

```
int x = 0;
```

B)

```
x++;
```

C)

The entire program.

D)

There is no Critical Section.

<details> <summary>✅ Answer</summary>

**B**

The increment accesses and modifies a shared variable.

</details>

---

## Q7 ⭐⭐⭐⭐⭐ (PYQ Style)

The Critical Section Problem is primarily concerned with:

A) Memory allocation

B) CPU scheduling

C) Coordinating concurrent access to shared resources

D) Virtual memory management

<details> <summary>✅ Answer</summary>

**C**

The objective is to safely coordinate concurrent access to shared resources.

</details>

---

## Q8 ⭐⭐⭐⭐⭐ (Classic Trap)

Two threads execute different functions.

Neither function accesses any shared variable or shared resource.

Which statement is correct?

A) A race condition must occur.

B) A Critical Section exists.

C) Synchronization is unnecessary.

D) Mutual exclusion is always required.

<details> <summary>✅ Answer</summary>

**C**

If there are no shared resources, there is no critical section to protect, so synchronization is not needed.

</details>

Think of every concurrent program like this:

```
Concurrency
      ↓
Shared Resource
      ↓
Critical Section
      ↓
Need Protection
      ↓
Synchronization
      ↓
Correct Execution
```
