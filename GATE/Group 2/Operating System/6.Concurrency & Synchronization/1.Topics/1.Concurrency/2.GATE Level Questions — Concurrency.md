# GATE Level Questions — Concurrency

## Question 1 ⭐ (Very Easy)

A single-core processor is executing two processes by rapidly switching between them.

Which concept is being demonstrated?

A) Parallelism

B) Concurrency

C) Deadlock

D) Mutual Exclusion

**Answer: B) Concurrency**

Reason:

Only one instruction executes at a time.

The OS switches rapidly between processes.

This is **Concurrency**, not Parallelism.

---

## Question 2 ⭐⭐

Which of the following statements about concurrency is TRUE?

A) Concurrency always requires multiple CPU cores.

B) Concurrency means multiple tasks make progress during the same period.

C) Concurrency guarantees simultaneous execution.

D) Concurrency eliminates context switching.

**Answer: B**

Explanation:

- A ❌ False (Single-core systems can be concurrent.)
    
- B ✅ Correct
    
- C ❌ That's Parallelism.
    
- D ❌ Context switching is what enables concurrency on a single-core CPU.
    

---

## Question 3 ⭐⭐⭐

Consider a single-core processor running three threads.

At any instant,

how many threads can actually execute instructions?

A) 0

B) 1

C) 2

D) 3

**Answer: B**

Only one instruction stream can execute on a single CPU core at any instant.

The others are waiting.

---

## Question 4 ⭐⭐⭐

A web browser is

- downloading a file
    
- playing audio
    
- rendering a webpage
    

all at the same time.

This is an example of

A) Deadlock

B) Concurrency

C) Paging

D) Thrashing

**Answer: B**

The browser has multiple tasks making progress together.

---

## Question 5 ⭐⭐⭐⭐

Which statement correctly differentiates concurrency from parallelism?

A) Concurrency means simultaneous execution,

Parallelism means interleaved execution.


B) Concurrency is impossible on a single-core CPU.


C) Parallelism always implies concurrency,

but concurrency does not always imply parallelism.


D) Concurrency and Parallelism are identical.

**Answer: C**

Parallel tasks are obviously making progress together.

But concurrent tasks may simply be interleaved using context switching.

This is one of GATE's favorite concepts.

---

# Question 6 ⭐⭐⭐⭐ (Memory Based)

Which OS mechanism enables concurrency on a single-core processor?

A)

Pipelining

B)

DMA

C)

Context Switching

D)

Caching

**Answer: C**

Without context switching,

a single-core processor could execute only one task from start to finish.

---

# Question 7 ⭐⭐⭐⭐⭐ (GATE Style)

A single-core processor executes two processes P₁ and P₂.

During execution, the processor repeatedly switches between the two processes before either process completes.

Which statement is correct?

A)

The processes execute in parallel.

B)

The processes execute concurrently.

C)

The processes are deadlocked.

D)

The processes are synchronized.

**Answer: B**

This is almost exactly how GATE frames questions.

---

# Question 8 ⭐⭐⭐⭐⭐ (Conceptual)

A system has four CPU cores.

Two independent programs are executing simultaneously,

each on a different core.

Which of the following is true?

A)

Only concurrency exists.

B)

Only parallelism exists.

C)

Both concurrency and parallelism exist.

D)

Neither exists.

**Answer: C**

They are executing at the same instant (Parallelism).

They are also making progress together (Concurrency).

---

# One PYQ-Style Trick Question ⭐⭐⭐⭐⭐

A single-core processor executes Process A for 5 ms,

then Process B for 5 ms,

then Process A again,

then Process B again.

This execution demonstrates

A)

Parallelism

B)

Concurrency

C)

Deadlock

D)

Mutual Exclusion

✅ **Answer: B**

This is a classic trap.

Many students see "multiple processes" and immediately choose Parallelism.

But there is only **one CPU core**, so only one process runs at any instant.
