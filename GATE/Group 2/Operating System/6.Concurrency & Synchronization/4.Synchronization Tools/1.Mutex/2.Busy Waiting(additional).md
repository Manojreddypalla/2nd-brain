## Busy Waiting

> **Busy waiting = a process keeps checking again and again instead of sleeping.**

Imagine a bathroom is occupied.

You could do two things:

**Busy waiting:**

> "Free now? No. Free now? No. Free now? No. Free now?..."

You stand at the door continuously checking. 😭

**Blocking:**

> "It's occupied. Call me when it's free."

You go sit somewhere and wait.

---

### In CPU terms

Suppose:

```cpp
while (lock == 1) {
    // keep checking
}
```

If `lock = 1`, the CPU repeatedly executes:

```text
Check lock → 1
Check lock → 1
Check lock → 1
Check lock → 1
...
```

The process is **waiting**, but it is still consuming CPU cycles.

That's why it's called:

> **Busy + Waiting = waiting while keeping the CPU busy.**

---

### Test-and-Set example

```cpp
while (TestAndSet(lock));
```

If another process owns the lock:

```text
Try → Failed
 ↑       ↓
 └─ Try again
```

This is also called **spinning**, and a lock that works this way is a **spinlock**.

### GATE memory trick

|Busy Waiting|Blocking|
|---|---|
|Keeps checking|Goes to sleep|
|Uses CPU|Frees CPU|
|Spinlock|Blocking mutex/semaphore|
|Good for very short waits|Better for longer waits|

**One line:**

> **Busy waiting = "Keep checking until I get it."**
