# Turnaround Time (TAT)

## Definition

**Turnaround Time (TAT)** is the **total time taken by a process from its arrival (submission) to its completion.**

In simple words:

> **Turnaround Time tells us how long a process stays in the system before it finishes.**

---

## Formula

$$
\boxed{
\text{Turnaround Time (TAT)}
=
\text{Completion Time (CT)}
-
\text{Arrival Time (AT)}
}
$$

where,

- **CT** = Completion Time
- **AT** = Arrival Time

---

## Why Do We Need Turnaround Time?

When a process enters the operating system, the user wants to know:

> **"How long will it take until my process finishes?"**

Turnaround Time answers this question.

It measures the **overall experience of a single process**, including:

- Waiting in the Ready Queue
- CPU Execution Time
- I/O Waiting Time
- Any other delays

---

## Timeline

```text
Arrival
   │
   ▼
+---------+---------+---------+
| Waiting | Running | Waiting |
+---------+---------+---------+
                              │
                              ▼
                         Completion
```

Everything between **Arrival** and **Completion** contributes to the Turnaround Time.

---

## Example 1

Suppose

```text
Arrival Time = 2 ms

Completion Time = 15 ms
```

Then,

$$
\text{TAT}
=
15-2
=
13\text{ ms}
$$

---

## Example 2

```text
Process arrives at 0 ms

Waits for 4 ms

Executes for 6 ms

Completes at 10 ms
```

```text
0          4         10
|----------|----------|
 Arrival    CPU       Completion
```

$$
TAT = 10 - 0 = 10\text{ ms}
$$

Notice:

The CPU executed for only **6 ms**, but the turnaround time is **10 ms** because it also includes the waiting time.

---

## Relation with Waiting Time

Turnaround Time consists of:

- Waiting Time
- CPU Burst Time
- I/O Time (if applicable)

If there is no I/O,

$$
\boxed{
TAT = WT + BT
}
$$

where,

- WT = Waiting Time
- BT = Burst Time (CPU Execution Time)

---

## High vs Low Turnaround Time

### Low Turnaround Time

- Process finishes quickly.
- Better user experience.
- Preferred by scheduling algorithms.

---

### High Turnaround Time

- Process remains in the system for a long time.
- Poor performance.
- Longer waiting before completion.

---

## Turnaround Time vs Waiting Time

| Turnaround Time | Waiting Time |
|-----------------|--------------|
| Total time spent in the system | Time spent waiting in the Ready Queue |
| Includes execution time | Does not include execution time |

Example:

```text
Waiting = 5 ms

CPU Burst = 8 ms
```

$$
TAT = 5 + 8 = 13\text{ ms}
$$

---

## Turnaround Time vs Throughput

| Turnaround Time | Throughput |
|-----------------|------------|
| Per-process metric | System-wide metric |
| Measures how long one process takes | Measures how many processes finish per unit time |

Example:

- TAT asks:
  > "How long did **this process** take?"

- Throughput asks:
  > "How many processes finished in one second?"

---

## Factors Affecting Turnaround Time

Turnaround Time increases when:

- Waiting Time increases.
- CPU Burst Time is long.
- Frequent I/O delays occur.
- Context switching overhead is high.

Turnaround Time decreases when:

- Waiting Time is reduced.
- CPU scheduling is efficient.
- CPU utilization is improved.

# GATE Corner ⭐

## Must Remember

- Turnaround Time = Total time from **Arrival** to **Completion**.
- It includes:
  - Waiting Time
  - CPU Execution Time
  - I/O Waiting Time (if any)
- Goal of scheduling algorithms is usually to **minimize Turnaround Time**.

---

## Formula

$$
\boxed{
TAT = CT - AT
}
$$

If no I/O exists,

$$
\boxed{
TAT = WT + BT
}
$$

---

## Common GATE Traps

❌ Turnaround Time ≠ Waiting Time

❌ Turnaround Time ≠ Response Time

❌ Turnaround Time ≠ Burst Time

---

$$

## Memory Trick 💡

Imagine ordering food at a restaurant.

```text
You place the order
        │
        ▼
Chef prepares food
        │
        ▼
Food is served
```

The **Turnaround Time** is the **total time from placing the order until receiving the food**.

It includes:
- Waiting for the chef.
- Cooking time.
- Any delays.

Similarly, in an operating system, Turnaround Time is the **total time from process arrival until its completion**.
