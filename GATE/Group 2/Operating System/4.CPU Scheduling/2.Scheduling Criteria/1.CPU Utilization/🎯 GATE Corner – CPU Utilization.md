# GATE Corner – CPU Utilization

## Definition

CPU Utilization is the percentage of time the CPU remains busy executing processes.

---

## Formula

CPU Utilization = (CPU Busy Time / Total Time) × 100%

---

## Objectives of CPU Scheduling

A good scheduling algorithm aims to:

- Maximize CPU Utilization
- Maximize Throughput
- Minimize Waiting Time
- Minimize Turnaround Time
- Minimize Response Time

---

## Ways to Improve CPU Utilization

✅ Multiprogramming

✅ Efficient Scheduling

✅ Switching to another ready process during I/O waits

---

## Common GATE Questions

### Q1. CPU Utilization is:

✅ Percentage of time the CPU is busy.

---

### Q2. Which OS feature improves CPU Utilization?

✅ Multiprogramming

---

### Q3. CPU Utilization decreases when:

✅ The CPU remains idle due to lack of ready processes.

---

## Common GATE Traps

❌ CPU Utilization = CPU Speed.

✔ CPU Utilization measures the fraction of time the CPU is actively working.

---

❌ 100% CPU Utilization always means the best scheduling.

✔ High utilization may still result in poor response time or unfair scheduling.
