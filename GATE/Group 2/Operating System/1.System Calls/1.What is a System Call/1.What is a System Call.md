# Module 1 — What is a System Call?

## Definition

> A **System Call** is a **programmatic interface** through which a **user process requests services from the Operating System Kernel**.

It acts as a **bridge between User Mode and Kernel Mode**.

---

# Why Do We Need System Calls?

User programs **cannot directly access**:

- Hardware
- Memory Management
- Process Creation
- File System
- I/O Devices

These are **privileged operations**.

Instead, they request the kernel using **System Calls**.

---

# Intuition

Imagine a customer in a restaurant.

```text
Customer
    │
    ▼
Waiter
    │
    ▼
Chef
```

- Customer → User Program
- Waiter → System Call
- Chef → Kernel

The customer **cannot enter the kitchen**.

Similarly,

A user program **cannot directly access the kernel**.

It must use a **System Call**.

# How It Works

### Step 1

User program needs an OS service.

Example:

```c
read(file);
```

↓

### Step 2

A System Call is invoked.

↓

### Step 3

CPU switches

```text
User Mode
      ↓
Kernel Mode
```

↓

### Step 4

Kernel performs the requested operation.

↓

### Step 5

Kernel returns the result.

↓

### Step 6

CPU switches back

```text
Kernel Mode
      ↓
User Mode
```

# Important Characteristics

- Interface between User Program and Kernel.
- Causes **User Mode → Kernel Mode** switch.
- Used for privileged operations.
- Implemented by the Operating System.
- Returns control back to the user process after execution.

# Key Points

- User programs cannot directly access hardware.
- System Calls provide controlled access to kernel services.
- Every System Call causes a mode switch.
- After execution, control returns to the user process.

# 🎯 GATE Corner

## Must Remember ⭐⭐⭐⭐⭐

- System Call = Interface between **User Program** and **Kernel**.
- System Calls execute in **Kernel Mode**.
- User programs execute in **User Mode**.
- A System Call causes a **mode switch**.
- Hardware is accessed only through the kernel.

---

## GATE Tricks ⚠️

### ❌ Wrong Statement

> A user program can directly access hardware.

**False**

---

### ❌ Wrong Statement

> System Calls execute in User Mode.

**False**

---

### ❌ Wrong Statement

> `printf()` is a System Call.

**False**

---

### ✅ Correct Statement

## Common MCQs

### Q1

A System Call provides an interface between

A. Compiler and Loader

B. User Program and Kernel

C. CPU and Memory

D. Process and Thread

✅ **Answer:** **B**

---

### Q2

System Calls execute in

A. User Mode

B. Kernel Mode

C. Supervisor Mode only

D. Interrupt Mode

✅ **Answer:** **B**

---

### Q3

Which of the following is a System Call?

A. printf()

B. scanf()

C. write()

D. strlen()

✅ **Answer:** **C**

---

### Q4

Which operation occurs during a System Call?

A. Mode Switch

B. Cache Flush

C. Context Switch

D. Process Scheduling

✅ **Answer:** **A**

> **Note:** A system call **may** lead to a context switch, but **every system call causes a mode switch**.
