# 1. What is an IP Address?

An **IP (Internet Protocol) Address** is a unique logical address assigned to every device on a network.

Think of it like your home address.

```text
House Address
↓

Finds your home

IP Address
↓

Finds your computer
```

Example:

```text
192.168.1.10
```

Without an IP address, devices cannot communicate over a network.

---

# 2. IPv4 Structure

IPv4 consists of **32 bits**.

```text
192.168.1.10

↓

11000000
10101000
00000001
00001010
```

It is divided into **4 octets**.

```text
192 . 168 . 1 . 10
 ↑      ↑     ↑    ↑
8 bits 8 bits 8 bits 8 bits
```

Total

```text
4 × 8 = 32 bits
```

---

# 3. Two Parts of an IP Address

Every IP address has two parts.

```text
Network Portion

Host Portion
```

Example

```text
192.168.1.10/24
```

```text
Network

192.168.1

Host

10
```

### Why?

Network identifies

> Which network?

Host identifies

> Which device inside that network?

# 5. What is CIDR?

## Full Form

**CIDR**

**Classless Inter-Domain Routing**

---

### Why was it introduced?

Old Internet

```text
Class A

/8

Huge

↓

Class B

/16

Medium

↓

Class C

/24

Small
```

Problem

Suppose company needs

```text
1000 IPs
```

Class C

```text
254
```

Too small

Class B

```text
65534
```

Huge waste

CIDR solved this by allowing

```text
/17

/18

/19

/20

/21

...

/31

/32
```

Now we can create networks of almost any size.

# 6. CIDR Notation

Example

```text
192.168.10.0/24
```

Meaning

```text
First 24 bits

↓

Network

Remaining 8 bits

↓

Hosts
```

General Formula

```text
Host Bits

=

32 − Prefix Length
```

# 10. Usable Hosts

Formula

```text
2^(Host Bits) − 2
```

Why minus 2?

One address is reserved for

```text
Network Address
```

One address is reserved for

```text
Broadcast Address
```

Example

```text
/24
```

Host bits

```text
8
```

Addresses

```text
2^8

=

256
```

Usable

```text
254
```

# 17. Common Interview Questions

### What does `/24` mean?

The first **24 bits** represent the network, and the remaining **8 bits** are used for hosts.

---

### Difference between Public and Private IP?

Private IPs are used inside local networks and are not directly reachable from the Internet. Public IPs are globally routable.

---

### Why does Docker use `172.x.x.x`?

Docker creates a private bridge network and assigns private IP addresses from that CIDR range.

---

### Why is CIDR important in AWS?

It defines the address space for VPCs and subnets, allowing flexible network design and efficient IP utilization.

---

### Why subtract 2 while calculating usable hosts?

One address is reserved as the **network address**, and one is reserved as the **broadcast address** (except for special cases like `/31` and `/32`).

**Key takeaway:** In DevOps, **CIDR is the language of networking**. Every cloud VPC, Docker bridge, Kubernetes pod network, VPN, and subnet is defined using CIDR notation. Understanding network bits, host bits, and subnet boundaries is essential for designing and troubleshooting modern infrastructure.
