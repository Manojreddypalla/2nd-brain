---

# What is Connectivity?

Connectivity asks:

> **Can we reach one node from another by following the edges?**

Unlike the shortest path problem, we **don't care about the distance or cost**—only whether a path exists.

---

# Example

```
A ── B ── C ── D
```

Question:

```
Can A reach D?
```

Answer:

```
Yes

Path:
A → B → C → D
```

---

# Another Example

```
A ── B

C ── D
```

Question:

```
Can A reach D?
```

Answer:

```
No
```

They belong to different connected components.

---

# Connected Component

A **Connected Component** is a group of nodes where every node can reach every other node.

Example

```
Component 1

A ── B ── C
```

```
Component 2

D ── E
```

```
Component 3

F
```

This graph has **3 connected components**.

---

# Common Algorithms

### 1. DFS (Depth-First Search)

- Explores one path completely before backtracking.
- Used to check if two nodes are connected.

Time Complexity:

```
O(V + E)
```

---

### 2. BFS (Breadth-First Search)

- Explores level by level.
- Also used for connectivity.

Time Complexity:

```
O(V + E)
```

---

### 3. Union-Find (Disjoint Set Union - DSU)

- Efficiently keeps track of connected components.
- Best when there are many connectivity queries.

Operations:

- `find()` → Find which component a node belongs to.
- `union()` → Merge two components.

Time Complexity (with optimizations):

```
Nearly O(1)
```

---

# When is Connectivity Used?

- Checking if two cities are connected.
- Social networks (Are two users connected?)
- Computer networks.
- Finding connected components.
- Detecting cycles (using Union-Find).
- Kruskal's Minimum Spanning Tree algorithm.

# Mental Model 🧠

Imagine islands connected by bridges.

```
Island A ─ Bridge ─ Island B ─ Bridge ─ Island C
```

Question:

> Can you travel from **A** to **C**?

If a chain of bridges exists → **Connected**

If no chain exists → **Not Connected**

---

# Key Takeaways

- Connectivity checks **whether a path exists**.
- It **does not** care about path length or edge weights.
- DFS and BFS are the most common search algorithms.
- Union-Find is ideal for repeated connectivity checks and dynamic graphs.
