# Articulation Point (Cut Vertex)

## Intuition

An **Articulation Point** is a node that acts as the **only gateway** connecting different parts of a graph.

> **If removing this node disconnects the graph, it is an Articulation Point.**

Think of it as a **junction** where all traffic must pass.

---

## Real-Life Analogy

Imagine three cities connected like this:

```text
City A ---- City B ---- City C
```

City **B** is the only way to travel from A to C.

If City B disappears:

```text
City A      City C
```

The network splits into two parts.

✅ **City B is an Articulation Point.**

---

# Example 1 (Articulation Point)

```text
A ----- B ----- C
```

Remove **B**:

```text
A      C
```

The graph becomes disconnected.

✅ **B is an Articulation Point.**

---

# Example 2 (Not an Articulation Point)

```text
    A
   / \
  B---C
```

Remove **A**:

```text
B ----- C
```

B and C are still connected.

❌ **A is NOT an Articulation Point.**

Remove **2**:

- Left triangle `{0,1}`
    
- Right diamond `{5,6,7,8}`
    
- Bottom `{3,4}`
    

All become disconnected.

✅ **2 is an Articulation Point.**

Remove **5**:

```text
2      6
        \
         7

       8
```

The right diamond can no longer connect to node 2.

✅ **5 is an Articulation Point.**

### Node **3**

Remove **3**:

```text
4
```

Node **4** becomes isolated.

✅ **3 is an Articulation Point.**

# Difference Between Bridge and Articulation Point

|Bridge|Articulation Point|
|---|---|
|Removes an **edge**|Removes a **vertex (node)**|
|Graph disconnects|Graph disconnects|
|Critical connection|Critical junction|

> **Articulation Point = Remove a city/junction → Network breaks.**

- 🚧 **Bridge = Critical Edge**
