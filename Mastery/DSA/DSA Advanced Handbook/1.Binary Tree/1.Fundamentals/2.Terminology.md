# 🌳 Binary Tree Fundamentals — Terminology

Before learning traversals and solving problems, you should know the language of binary trees. Almost every interview question uses these terms.

---

# 1. Root

## Definition

The **Root** is the **topmost node** of a binary tree.

- Every tree has **exactly one root**.
    
- The root has **no parent**.
    
- Every other node originates from the root.
    

### Example

```text
        A
       / \
      B   C
```

Root:

```text
A
```

### Properties

- First node of the tree.
    
- Starting point of every traversal.
    
- If the root is `NULL`, the tree is empty.
    

---

# 2. Parent

## Definition

A **Parent** is a node that has one or more children.

### Example

```text
        A
       / \
      B   C
```

Parent relationships

```text
A → Parent of B

A → Parent of C
```

Another example

```text
        A
       /
      B
     /
    D
```

```text
B → Parent of D
```

### Properties

- Every node except the root has exactly one parent.
    
- A parent may have:
    
    - One child
        
    - Two children
        
    - No children (leaf)
        

---

# 3. Child

## Definition

A **Child** is a node directly connected below a parent.

Example

```text
        A
       / \
      B   C
```

Children of A

```text
B

C
```

Children of B

```text
None
```

### Types

- Left Child
    
- Right Child
    

Example

```text
        A
       / \
      B   C
```

```text
B = Left Child

C = Right Child
```

---

# 4. Sibling

## Definition

Nodes having the **same parent** are called siblings.

Example

```text
        A
       / \
      B   C
```

B and C are siblings because

```text
Parent(B) = A

Parent(C) = A
```

Another example

```text
          A
         / \
        B   C
       / \
      D   E
```

```text
D and E are siblings
```

---

# 5. Leaf Node

## Definition

A **Leaf Node** is a node with **no children**.

Example

```text
          A
         / \
        B   C
       /
      D
```

Leaf nodes

```text
C

D
```

### Properties

- Degree = 0
    
- Last nodes of every branch
    
- DFS often stops at leaves
    

---

# 6. Ancestor

## Definition

An **Ancestor** is any node that lies on the path from the root to a node.

Example

```text
          A
         /
        B
       /
      C
     /
    D
```

Ancestors of D

```text
A

B

C
```

Notice

```text
Root is also an ancestor.
```

---

# 7. Descendant

## Definition

A **Descendant** is any node reachable below a node.

Example

```text
          A
         /
        B
       /
      C
     /
    D
```

Descendants of A

```text
B

C

D
```

Descendants of B

```text
C

D
```

---

```text
A

↓

B

C

D
```

For node C

```text
Ancestor

A

B
```

```text
Descendant
```

# 8. Height

## Definition

The **Height** of a node is the number of nodes on the longest path from that node to its deepest leaf.

Example

```text
        A
       /
      B
     /
    C
```

Height

```text
C = 1

B = 2

A = 3
```

### Remember

Height goes

```text
Node

↓

Leaf
```

The **height of the tree** is the height of the root.

---

# 9. Depth

## Definition

The **Depth** of a node is the distance from the root to that node.

Example

```text
        A
       /
      B
     /
    C
```

Depth

```text
A = 0

B = 1

C = 2
```

### Remember

Depth goes

```text
Root

↓

Node
```

---

# Height vs Depth

```text
        A
       /
      B
     /
    C
```

For node B

Depth

```text
A → B

Depth = 1
```

Height

```text
B → C

Height = 2
```

---

# 10. Level

## Definition

The **Level** of a node is its position from the root.

Most interview platforms use

```text
Level = Depth + 1
```

Example

```text
        A
       / \
      B   C
     /
    D
```

|Node|Depth|Level|
|---|--:|--:|
|A|0|1|
|B|1|2|
|C|1|2|
|D|2|3|

### Easy Formula

```text
Level = Depth + 1
```

---

# 11. Degree

## Definition

The **Degree** of a node is the number of children it has.

Example

```text
        A
       / \
      B   C
     /
    D
```

|Node|Degree|
|---|--:|
|A|2|
|B|1|
|C|0|
|D|0|

### Maximum Degree

For a binary tree

```text
Maximum Degree = 2
```

because a node can have at most two children.

---

# 12. Subtree

## Definition

A **Subtree** is a tree formed by a node and **all of its descendants**.

Example

```text
          A
         / \
        B   C
       / \
      D   E
```

The subtree rooted at B is

```text
        B
       / \
      D   E
```

The subtree rooted at C is

```text
C
```

Every node in a tree is the root of its own subtree.

# 📋 Summary Table

|Term|Meaning|Easy Memory|
|---|---|---|
|Root|Topmost node|Starting point|
|Parent|Node above another|Gives children|
|Child|Node below a parent|Receives from parent|
|Sibling|Same parent|Brothers/Sisters|
|Leaf|No children|End of a branch|
|Ancestor|Above a node|Parent, Grandparent, ...|
|Descendant|Below a node|Child, Grandchild, ...|
|Height|Node → Deepest Leaf|Look **down**|
|Depth|Root → Node|Look **up** from the node to the root|
|Level|Position from root|`Depth + 1`|
|Degree|Number of children|0, 1, or 2|
|Subtree|Node + all descendants|Smaller tree inside a tree|
