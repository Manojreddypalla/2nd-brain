# 🌳 Chapter 1 — Binary Tree Representation

---

# 1. What is a Binary Tree?

A **Binary Tree** is a hierarchical data structure where **each node can have at most two children**:

- Left Child
    
- Right Child
    

Unlike arrays or linked lists, data is stored in **parent-child relationships** rather than sequential order.

```
         A
        / \
       B   C
      / \   \
     D   E   F
```

---

# 2. Why do we need Trees?

Arrays are good for sequential access.

Linked Lists are good for insertion/deletion.

But many real-world problems are naturally hierarchical:

- File systems
    
- Organization charts
    
- HTML DOM
    
- Expression trees
    
- Decision trees
    
- Database indexes (B-Trees)
    
- Binary Search Trees
    

Trees allow efficient searching, hierarchical organization, and recursive processing.

---

# 3. Binary Tree Terminology

```
          A
        /   \
       B     C
      / \
     D   E
```

|Term|Meaning|
|---|---|
|Root|Top-most node|
|Parent|Node having children|
|Child|Node connected below another node|
|Leaf Node|Node with no children|
|Internal Node|Node having at least one child|
|Ancestor|Any node on the path to the root|
|Descendant|Any node below a node|
|Sibling|Nodes sharing the same parent|
|Edge|Connection between two nodes|
|Level|Distance from root (root = level 0)|
|Depth|Number of edges from root|
|Height|Longest path from node to a leaf|

---

# 4. Structure of a Node

Each node stores:

```
+----------------------+
| Data                 |
+----------------------+
| Left Pointer         |
+----------------------+
| Right Pointer        |
+----------------------+
```

Memory layout:

```
TreeNode

 ├── data
 ├── left
 └── right
```

---

# 5. C++ Representation

```cpp
struct TreeNode {

    int val;
    TreeNode* left;
    TreeNode* right;

    TreeNode(int x) {
        val = x;
        left = nullptr;
        right = nullptr;
    }
};
```

Equivalent constructor initialization:

```cpp
struct TreeNode {

    int val;
    TreeNode* left;
    TreeNode* right;

    TreeNode(int x)
        : val(x), left(nullptr), right(nullptr) {}
};
```

---

# 6. How Nodes are Connected

```
TreeNode* root = new TreeNode(1);

root->left = new TreeNode(2);
root->right = new TreeNode(3);

root->left->left = new TreeNode(4);
root->left->right = new TreeNode(5);
```

Creates

```
        1
       / \
      2   3
     / \
    4   5
```

# 7. Types of Binary Trees (Overview)

## Full Binary Tree

Every node has either:

- 0 children
    
- 2 children
    

```
      A
     / \
    B   C
       / \
      D   E
```

---

## Perfect Binary Tree

Every level is completely filled.

```
         A
       /   \
      B     C
     / \   / \
    D  E  F  G
```

Properties:

- Total nodes = (2^{h+1}-1)
    
- Leaves = (2^h)
    

---

## Complete Binary Tree

Every level is full except possibly the last.

The last level is filled **from left to right**.

```
         A
       /   \
      B     C
     / \   /
    D  E  F
```

Used in:

- Binary Heap
    
- Priority Queue
    

---

## Balanced Binary Tree

For every node,

```
|height(left)-height(right)| ≤ 1
```

Balanced trees keep operations efficient.

---

## Degenerate Binary Tree

Looks like a linked list.

```
1
 \
 2
  \
   3
    \
     4
```

Worst-case height = **n**

---

# 8. Binary Tree Storage

## Linked Representation (Most Common)

```
Node

↓

Left Pointer

↓

Right Pointer
```

Advantages:

- Dynamic size
    
- No wasted memory
    
- Easy insertion/deletion
    

---

## Array Representation

Mostly used for heaps.

If index = **i**

```
Left Child = 2*i + 1

Right Child = 2*i + 2

Parent = (i-1)/2
```

Example:

```
Array

Index

0 1 2 3 4 5

Value

1 2 3 4 5 6
```

represents

```
        1
       / \
      2   3
     / \  /
    4  5 6
```

|Operation|Complexity|
|---|---|
|Create Node|**O(1)**|
|Connect Nodes|**O(1)**|
|Traverse Entire Tree|**O(n)**|
|Space Required|**O(n)**|

# 10. Common Mistakes

❌ Confusing **Height** and **Depth**

❌ Thinking every tree is complete

❌ Using array representation for sparse trees (wastes memory)

❌ Forgetting to initialize pointers to `nullptr`

❌ Accessing `root->left` when `root == nullptr`
