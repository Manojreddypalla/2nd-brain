# Every topic follows one template

For consistency and deep understanding:

1. **Intuition** — Why does this algorithm or data structure exist?
2. **Mental model** — Visual way to think about it.
3. **Internal working** — Memory, recursion stack, pointers, state transitions.
4. **Brute-force approach** — The natural first solution.
5. **Optimization journey** — How to derive the efficient solution.
6. **Dry run** — Step-by-step execution on an example.
7. **Implementation** — Clean C++ code.
8. **Complexity analysis** — Time and space trade-offs.
9. **Recognition patterns** — Clues that this technique applies.
10. **Common mistakes** — Bugs and misconceptions.
11. **Variations** — Related problems and extensions.
12. **Interview questions** — Common follow-ups.
13. **Practice ladder** — Easy → Medium → Hard.c
