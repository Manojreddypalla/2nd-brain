# 🔥 Topics that become **new** when you enter Computer Vision

These are the subjects unique to CV that most general ML/software backgrounds have not covered deeply:

### Digital Image Processing

- Image representation
    
- Pixels & channels
    
- RGB, HSV, LAB
    
- Histograms
    
- Image filtering
    
- Thresholding
    
- Morphological operations
    
- Edge detection
    
- Fourier Transform (FFT)
    

### OpenCV

- Image I/O
    
- Video processing
    
- Geometric transformations
    
- Contours
    
- Feature detection (SIFT, ORB, FAST)
    
- Camera calibration
    
- Optical flow
    

### Classical Computer Vision

- Hough Transform
    
- Harris Corner Detection
    
- RANSAC
    
- Homography
    
- Stereo Vision
    
- Epipolar Geometry
    
- Structure from Motion (SfM)
    
- SLAM
    

### Modern Computer Vision

- Image Classification
    
- Object Detection
    
- Segmentation
    
- Pose Estimation
    
- OCR
    
- Object Tracking
    
- Vision Transformers (ViT)
    
- CLIP
    
- Segment Anything (SAM/SAM2)
    
- Vision-Language Models (LLaVA, BLIP, Florence, PaliGemma)
    
- 3D Vision (NeRF, Gaussian Splatting)
    
- Edge deployment (TensorRT, ONNX, OpenVINO)
