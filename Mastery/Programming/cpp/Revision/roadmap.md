```text

Linked List
Stack
Queue
```

# Why this order?

Notice how each phase depends on the previous one:

```text
Programming Foundations
        ↓
Linear Data Structures
        ↓
Searching & Sorting
        ↓
Recursion
        ↓
Trees
        ↓
Hashing & Heap
        ↓
Graphs
        ↓
Greedy
        ↓
Dynamic Programming
        ↓
Advanced Algorithms
```

For example:

- Arrays teach traversal and indexing.
    
- Linked Lists introduce pointers.
    
- Stacks and Queues build on linked lists.
    
- Recursion prepares you for trees.
    
- Trees prepare you for DFS and recursion on graphs.
    
- Graphs make use of queues, stacks, heaps, and hashing.
    
- Dynamic Programming relies on recursion and arrays.
    

Each phase feels like a natural extension of the previous one instead of a completely new subject.
