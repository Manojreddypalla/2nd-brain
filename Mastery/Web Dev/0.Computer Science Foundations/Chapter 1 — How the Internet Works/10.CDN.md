# CDN (Content Delivery Network)

> **Interview Importance:** ⭐⭐⭐⭐⭐  
> **One-line definition:** A **CDN** is a network of servers distributed around the world that stores copies of static content and serves users from the nearest location.

---

# Full Form

**CDN = Content Delivery Network**

- **Content** → Images, CSS, JavaScript, videos, fonts, files
    
- **Delivery** → Sends content to users
    
- **Network** → Many servers around the world
    

---

# Why Do We Need a CDN?

Imagine your website's server is only in **Mumbai**.

Users:

```text
USA --------\
Europe ------> Mumbai Server
Japan ------/
```

Everyone has to travel all the way to Mumbai.

Result:

- ❌ Higher latency
    
- ❌ Slower page loads
    
- ❌ More load on the origin server
    

---

# Solution: CDN

A CDN places copies of your files on servers worldwide.

```text
                Origin Server
                   (Mumbai)
                      │
      ┌───────────────┼───────────────┐
      │               │               │
   CDN India      CDN Europe      CDN USA
```

Now:

- Indian users → CDN India
    
- European users → CDN Europe
    
- US users → CDN USA
    

The content comes from the nearest location.

# What Does a CDN Store?

Mostly **static content**:

- ✅ Images
    
- ✅ CSS
    
- ✅ JavaScript
    
- ✅ Fonts
    
- ✅ Videos
    
- ✅ PDFs
    
- ✅ Downloads
    

Usually **not**:

- User login
    
- Shopping cart
    
- Database queries
    
- Personalized dashboard
    

These dynamic requests still go to your backend.

# Request Flow

Without CDN:

```text
Browser
    │
    ▼
Origin Server
    │
    ▼
Image
```

With CDN:

```text
Browser
    │
    ▼
Nearest CDN
    │
    ▼
Image
```

If the CDN doesn't have the file yet:

```text
Browser
    │
    ▼
CDN
    │
    ▼
Origin Server
    │
    ▼
Returns File
    │
    ▼
CDN Caches It
    │
    ▼
Browser
```

Future users get it directly from the CDN.

---

# Cache

The CDN stores frequently requested files.

Example:

```text
logo.png
```

First request:

```text
Origin Server

↓

CDN stores logo.png
```

Next request:

```text
CDN

↓

Returns logo.png

(No need to contact origin)
```

This is called a **cache hit**.

If the CDN doesn't have the file:

```text
CDN

↓

Origin Server

↓

Cache file
```

This is a **cache miss**.

# CDN vs Origin Server

|CDN|Origin Server|
|---|---|
|Stores cached copies|Stores the original content|
|Distributed worldwide|Usually one or a few locations|
|Serves static content quickly|Generates or stores the original data|
|Reduces latency|Source of truth|

# Interview Questions

### What is a CDN?

A globally distributed network of servers that caches and delivers content from locations close to users.

---

### What kind of content is usually served by a CDN?

Static content such as images, CSS, JavaScript, fonts, videos, and downloadable files.

---

### What is a cache hit?

The requested file is already stored on the CDN and is served directly.

---

### What is a cache miss?

The CDN doesn't have the file, so it fetches it from the origin server, caches it, and then serves it.

# 🧠 Mental Model

Imagine a popular book.

Without a CDN:

```text
Everyone travels to one central library.
```

With a CDN:

```text
Copies of the book are placed in libraries across many cities.

People borrow from the nearest library.
```

The **original book** stays in the central library (the **origin server**), while the **copies** are served from nearby libraries (the **CDN**). This reduces travel time and keeps the central library from getting overwhelmed.
