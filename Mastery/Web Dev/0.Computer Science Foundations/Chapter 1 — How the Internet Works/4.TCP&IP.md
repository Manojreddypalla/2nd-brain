# TCP/IP (Transmission Control Protocol / Internet Protocol)

> **One-line definition:**  
> TCP/IP is the **suite of networking protocols** that allows computers to communicate over the Internet.

Think of it like a postal service:

- **IP** = Finds the correct address.
    
- **TCP** = Makes sure the package arrives completely and in the right order.
    

---

# Why do we need TCP/IP?

Suppose your browser requests:

```text
https://github.com
```

The browser must:

1. Find GitHub's IP address (DNS).
    
2. Send data to that IP (**IP**).
    
3. Ensure all data arrives correctly (**TCP**).
    

Without TCP/IP, the Internet wouldn't work.

---

# The Two Main Parts

## 1. IP (Internet Protocol)

**Job:** Deliver packets to the correct destination.

Think of IP as the **address on an envelope**.

Example:

```text
Source IP
192.168.1.10

↓

Destination IP
140.82.121.4 (GitHub)
```

IP answers:

> **"Where should this packet go?"**

### Important

- IP does **not** guarantee delivery.
    
- It doesn't know if packets arrive or are lost.
    
- It only routes packets toward the destination.
    

---

## 2. TCP (Transmission Control Protocol)

**Job:** Ensure reliable communication.

Think of TCP as a courier that:

- Checks every package is delivered.
    
- Resends lost packages.
    
- Delivers them in the correct order.
    

TCP provides:

- Reliable delivery
    
- Ordered delivery
    
- Error checking
    
- Retransmission if needed
    

TCP answers:

> **"Did all the data arrive correctly?"**

# TCP/IP Model

Unlike the 7-layer OSI model, TCP/IP uses **4 layers**.

```text
Application Layer
HTTP, HTTPS, DNS, FTP

↓

Transport Layer
TCP, UDP

↓

Internet Layer
IP, ICMP

↓

Network Access Layer
Ethernet, Wi-Fi
```

You don't need to memorize every protocol now—understand what each layer is responsible for.

---

# OSI vs TCP/IP

|OSI|TCP/IP|
|---|---|

# Interview Questions

### What is TCP/IP?

A suite of networking protocols that enables devices to communicate over the Internet.

### What is the difference between TCP and IP?

|TCP|IP|
|---|---|
|Reliable delivery|Packet routing|
|Connection-oriented|Connectionless|
|Ensures order and retransmission|Finds the destination|

### Is HTTP part of TCP/IP?

Yes. HTTP is an **Application Layer** protocol that typically runs over TCP.

## 💡 Mental Model

Imagine sending a parcel:

- **IP** writes the destination address and finds the route.
    
- **TCP** makes sure every box arrives, in order, without anything missing.
    
- **HTTP** is the message inside the boxes ("Give me the homepage.").
    

Together, they make reliable web communication possible.
