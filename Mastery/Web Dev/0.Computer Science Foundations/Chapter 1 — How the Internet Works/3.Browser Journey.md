# Step 1. User Enters URL

Example:

```
https://www.amazon.com
```

The browser first checks:

- Browser cache
    
- Operating System DNS cache
    
- Local hosts file
    

If nothing is found, it performs a DNS lookup.

**Connects to:** DNS

---

# Step 2. DNS Lookup

The browser asks:

> "What is the IP address of amazon.com?"

Example:

```
amazon.com
      ↓
54.xx.xx.xx
```

The browser cannot communicate using domain names; it needs an IP address.

**Connects to:** DNS, Networking

---

# Step 3. TCP Connection

Using the IP address, the browser establishes a TCP connection (typically with the **3-way handshake**).

This provides reliable communication.

**Connects to:** TCP, Computer Networks

---

# Step 4. TLS Handshake (HTTPS)

If the URL uses HTTPS:

- Server sends its certificate.
    
- Browser verifies it.
    
- Encryption keys are negotiated.
    

Now the connection is encrypted.

**Connects to:** HTTPS, SSL/TLS, Cybersecurity

---

# Step 5. HTTP Request

The browser sends an HTTP request.

Example:

```http
GET /
Host: amazon.com
```

This asks the server for the homepage.

**Connects to:** Request–Response Cycle, HTTP

---

# Step 6. Server Processing

The request may go through:

```
Load Balancer
      ↓
Reverse Proxy
      ↓
Application Server
      ↓
Database / Cache
```

The backend generates the response.

**Connects to:** DevOps, Backend, Databases

---

# Step 7. HTTP Response

The server replies with:

- HTML
    
- CSS
    
- JavaScript
    
- Images
    
- Fonts
    
- Status Code (200, 404, etc.)
    

Example:

```http
HTTP/1.1 200 OK
Content-Type: text/html
```

**Connects to:** HTTP

---

# Step 8. HTML Parsing

The browser reads the HTML and creates the **DOM (Document Object Model)**.

Example:

```html
<body>
  <h1>Hello</h1>
</body>
```

↓

```
Document
   │
 body
   │
  h1
```

**Connects to:** HTML, DOM

---

# Step 9. CSS & JavaScript

The browser discovers:

```html
<link href="style.css">
<script src="app.js">
```

It sends additional HTTP requests to download them.

A single webpage often results in dozens or hundreds of requests.

**Connects to:** CSS, JavaScript, HTTP

---

# Step 10. Build DOM + CSSOM

The browser builds:

- **DOM** → HTML structure
    
- **CSSOM** → CSS rules
    

These are combined to determine how the page should look.

**Connects to:** Browser Rendering

---

# Step 11. Render Tree

The browser combines the DOM and CSSOM into a **Render Tree**, which contains only the visible elements to be displayed.

---

# Step 12. Layout (Reflow)

The browser calculates:

- Width
    
- Height
    
- Position
    
- Spacing
    

It decides exactly where every visible element belongs.

---

# Step 13. Paint

The browser draws:

- Text
    
- Colors
    
- Borders
    
- Images
    
- Shadows
    

Pixels finally appear on the screen.

---

# Step 14. JavaScript Execution

JavaScript now runs.

It can:

- Fetch APIs
    
- Handle clicks
    
- Update the DOM
    
- Animate the page
    

This is what makes websites interactive.

**Connects to:** JavaScript, APIs, Event Loop

# Interview Questions

### What happens when you type a URL in the browser?

Expected high-level answer:

1. Browser checks cache.
    
2. DNS resolves the domain to an IP address.
    
3. TCP connection is established.
    
4. TLS handshake (for HTTPS).
    
5. HTTP request is sent.
    
6. Server processes the request.
    
7. HTTP response is returned.
    
8. Browser parses HTML.
    
9. Downloads CSS/JS.
    
10. Builds DOM/CSSOM.
    
11. Creates Render Tree.
    
12. Layout and Paint.
    
13. Page becomes interactive.
